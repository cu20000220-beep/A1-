# A1 FASHION

공개 사이트: https://a1fashion.pages.dev

전신 사진의 기기 내 AI 기준점 추정, 취향별 스타일 탐색과 외부 쇼핑몰 검색 연결을 제공하는 출시 전 기능 미리보기입니다. 현재 의류를 직접 판매하거나 실제 체험 이용권·유료 구독을 발급하지 않습니다. 정책은 7일 무료 체험 후 구독 필수로 정했으며 월 구독료·혜택은 미정입니다. 실제 인증·기간 제한·결제 연결은 아직 완료되지 않았습니다.

## 실행

```sh
cd /workspace/A1-
python3 -m http.server 8000 --bind 127.0.0.1
```

정적 HTML/CSS/JavaScript이며 패키지 설치·유료 API·계정·결제 연결 없이 현재 기능을 실행할 수 있습니다. 자산 경로는 상대 경로로 구성해 사이트 루트와 프로젝트 하위 경로에서 동작합니다.

## 현재 제공하는 기능

- 사진에서 Google MediaPipe AI가 어깨·골반·무릎·발목 기준점을 실제로 추정합니다. 사진은 기기 안에서만 처리하며 서버로 전송하지 않습니다.
- 기준점의 2D 간격과 사용자가 선택한 성별 컬렉션·스타일·예산을 적용해 참고용 예시 스타일을 제안합니다. 추천 규칙과 AI 추론은 구분합니다.
- 추천 검색어로 쿠팡·Temu·네이버쇼핑 검색 결과를 엽니다. 이는 실제 외부 상품 목록을 받아 개별 제품을 매칭하는 기능이 아닙니다. 사진·신체 수치·파일 이름을 검색 URL에 넣지 않습니다. 외부몰의 가격 필터는 자동 적용되지 않습니다.
- 성별·카테고리·가격·스타일 검색/필터, 가격 정렬, 예시 상품 상세, 이 브라우저에 보관되는 찜, 목 아래 착장 참고 사진 선택을 제공합니다.
- 사진과 분석값은 메모리에서만 처리합니다. 결과는 얼굴 영역을 제외하며, 원본 캔버스와 AI 컨텍스트를 정리합니다. 지우기/페이지 이동 시 결과를 삭제합니다. 브라우저 저장소에는 찜한 카탈로그 ID만 기록합니다.
- 현재 기능 미리보기는 회원가입·카드 등록 없이 열 수 있지만 체험 시작으로 기록되지 않습니다. 7일 체험/구독 카드에는 연결 준비 중임을 표시합니다. 실제 회원별 기간 제한·유료 가입·정기 청구는 활성화하지 않았으며, 브라우저 플래그나 로컬 날짜만으로 가짜 구독 제한을 만들지 않습니다.

## 실제로 제공하지 않는 것

- 자체 의류 재고·주문·결제·배송·재판매. 기존 자사 의류 우선 계획은 보류했으며 실제 자사 상품은 등록되지 않았습니다.
- 실제 외부 상품/가격/재고 피드와 그에 대한 개별 제품 자동 매칭, 제휴 계약 또는 주문 연동.
- 정확한 신체 치수·체형 판정·허리둘레·체중·건강·옷 사이즈 예측, 의류 합성이나 AI 상담 채팅.
- 멤버십에서 검토 중인 취향 프로필·정기 코디·실제 상품 정보 탐색. 화면에서 아직 제공되지 않는 혜택으로 표시합니다.

한 명이 정면으로 서서 어깨부터 발목까지 보이는 사진을 사용합니다. 모델은 단일 인물용이며 여러 사람을 세거나 검증하지 않습니다. 낮은 신뢰도·잘린 신체·불안정한 구도에서는 결과를 만들지 않습니다. 카메라 각도·옷·자세의 한계는 남습니다. WebGL이 필요하며 실행 불가 시 오류를 안내합니다. Chromium 실제 추론과 iPad 크기 화면 검증을 실제 iPad Safari 기기 검증으로 설명하지 않습니다.

## 구독 수익 모델과 역할

고객이 향후 A1에 지불하는 것은 옷 구매 수수료가 아닌 스타일 큐레이션 이용료입니다. 의류 주문·결제·배송·상품 반품은 선택한 판매처에서 처리하며, 향후 A1 구독의 취소·환불·회원정보 처리는 A1 서비스가 준비해야 합니다. 디지털 구독에도 판매자·결제 제공자의 요건과 거래 비용이 생길 수 있으므로 의류 판매를 중단했다고 모든 조건이 해결되었다고 설명하지 않습니다.

유료 출시 전 가격·반복 제공 가능한 혜택·이용/해지/환불 정책·운영 요건을 확정하고 인증/구독 권한을 서버에서 검증해야 합니다. 현재 정적 사이트의 클라이언트 코드에 비밀키나 결제 성공 플래그를 추가하는 방식은 사용하지 않습니다. 자세한 범위는 [서비스 운영 안내](docs/PRODUCT-CATALOG.md)를 참고하세요.

## 코드 구조

- `assets/products.js`: 현재 참고용 예시 카탈로그. 과거 자사 상품 전역 변수를 읽거나 자사 우선으로 전환하지 않습니다.
- `assets/app.js`: 검색·상세·찜·착장 참고 UI.
- `assets/style-advisor.js`: 기준점 품질 검증, 2D 간격 계산, 조건을 지키는 출처 중립 상품 매칭.
- `assets/shop-search.js`: 고정된 판매처 도메인과 검증된 의류/취향 문자열로 검색 링크 생성.
- `assets/ai-studio.js`: 사진 선택·실제 로컬 추론·결과 삭제·스타일/검색 제안.
- `assets/vendor/mediapipe/`: 무결성을 확인한 공식 `@mediapipe/pose@0.5.1675469404` Lite 모델/런타임. Apache-2.0 라이선스와 출처·체크섬을 보존합니다. 첫 실행 약 12MB, 배포 파일 약 18.5MB.
- `assets/photos/`: 사이트에 포함한 사진. 출처는 `assets/PHOTO-CREDITS.md`, 방문자 안내는 `credits.html`.
- `assets/catalog-rules.js`: 출처/상세 안내와 보존된 카탈로그 검증 도구. 과거 자사 상품 검증은 현재 스토어 등록 기능이 아닙니다.
- `assets/own-products.js`: 보류된 과거 계획의 빈 파일. 현재 페이지가 로드하지 않습니다.

## 검증

Playwright/Chromium이 설치된 개발 환경에서 서버를 실행한 후:

```sh
node tests/smoke.cjs
A1_CHECK_PHOTOS=1 node tests/smoke.cjs
node tests/advisor.cjs
node tests/shop-search.cjs
node tests/ai-studio.cjs
node tests/discovery-browser.cjs
node tests/membership-policy.cjs
```

`CHROMIUM_PATH`, `A1_TEST_URL`로 실행 파일/검증 URL을 지정할 수 있습니다. 기본 주소는 `http://127.0.0.1:8000/`입니다. 실제 추론 테스트는 모델이나 기준점을 조작하지 않으며 헤드리스 환경의 소프트웨어 WebGL을 사용합니다. 필터·찜·상세·이미지 오류·개인정보 비전송·삭제·다운로드 실패/취소·추천 제약·실제 기간 제한이 연결되지 않은 미리보기/미출시 체험·구독 상태·320/390/820/1440px 화면을 검증합니다. `tests/catalog.cjs`는 현재 활성화되지 않은 보존 검증 도구의 테스트입니다.

## 배포와 새 주소

`node scripts/build-site.cjs`는 외부 의존성 설치 없이 `dist/`에 실행 파일만 복사하고 Git 이력·테스트·개발 문서를 제외합니다. [Cloudflare Pages 설정](docs/CLOUDFLARE-PAGES.md)의 명령과 출력 폴더를 사용합니다. Cloudflare Pages의 a1fashion 프로젝트 배포 성공과 https://a1fashion.pages.dev 주소를 사용자 완료 화면 및 연결된 GitHub 배포 체크에서 확인했습니다. 새 주소는 GitHub·개인 계정 이름을 포함하지 않습니다. 기존 GitHub Pages 배포와 별개의 주소이며 회원/결제/7일 이용권 연결 상태와도 별개입니다. 작업 환경의 네트워크 정책으로 새 호스트 직접 접속이 차단되어 원격 화면 테스트는 미실행이며, 배포 파일의 실제 AI·모바일·주요 기능 검증 결과와 구분합니다.

7일 체험의 서버 판정 코드는 `server/membership-policy.mjs`에 준비했으며 현재 정적 빌드에는 포함하지 않습니다. 정책 코드와 실제 회원/결제 배포 상태는 다릅니다. [연결 요건](server/README.md)을 참고하세요.
