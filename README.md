# A1 FASHION

여성·남성·유니섹스를 위한 무료 정적 스타일 탐색 데모입니다. 전신 사진의 AI 기준점 추정과 스타일 추천을 기기 안에서 실행합니다. GitHub Pages의 프로젝트 경로(`/A1-/`)에서 동작하도록 모든 자산 경로를 상대 경로로 구성했습니다.

## 실행

```sh
cd /workspace/A1-
python3 -m http.server 8000 --bind 127.0.0.1
```

Node 빌드, 유료 API, 서비스 계정, 데이터베이스, 결제 연결은 필요하지 않습니다. 배포 파일은 `index.html`, `credits.html`, `assets/`입니다. 외부 CDN·웹폰트에 의존하지 않습니다.

## 기능과 한계

- 성별·카테고리·가격·스타일의 조합 필터, 키워드 검색, 가격 정렬
- 키보드로 닫을 수 있는 상품 상세 창과 브라우저 로컬 찜 목록
- 모바일·태블릿·데스크톱 대응, 이미지 실패 시 자체 대체 이미지
- 목 아래 실제 착장 참고 사진을 선택하는 스타일 참고 기능
- 사용자가 선택한 전신 사진에서 Google MediaPipe AI가 어깨·골반·무릎·발목 기준점을 실제로 추정합니다. 2D 기준점의 간격 비율을 계산하고, 사용자가 고른 컬렉션·스타일·예산을 적용해 규칙 기반으로 최대 4개 상품을 제안합니다.
- AI 모델은 분석 버튼을 누른 뒤에만 불러옵니다. 첫 실행 시 약 12MB를 다운로드하며, SIMD 및 비-SIMD 실행 경로를 포함한 전체 모델 배포 파일은 약 18.5MB입니다. 유료 API·토큰·백엔드는 필요하지 않습니다.
- 예시 상품·가격·소재·사이즈이며 실제 판매 정보가 아닙니다. 사진 속 제품과 일치하지 않을 수 있습니다.
- 사진 한 장에서 보이는 기준점 비율은 정확한 체형 판정이나 신체 치수가 아닙니다. 실제 AI 의류 합성·허리둘레/체중/건강 판정·정확한 사이즈 예측·AI 상담 채팅·회원가입·구매 기능은 제공하지 않습니다.
- 선택한 사진과 분석값은 서버 전송·localStorage 저장 없이 메모리에서만 처리합니다. 결과에는 얼굴 영역을 제외한 사진을 표시합니다. 분석 완료 후 원본 캔버스를 비우고 AI 실행 컨텍스트를 닫습니다. 사진·결과 지우기 또는 페이지 이동 시 결과도 삭제합니다.
- 찜 목록만 이 기기의 이 브라우저에 저장됩니다. 추적 코드는 없습니다. 비공개 모드나 저장 차단 환경에서는 찜이 이번 방문에서만 유지될 수 있습니다.
- 한 명이 정면으로 서서 어깨부터 발목까지 보이는 사진을 사용하세요. 모델은 단일 인물용이며 여러 사람을 세거나 검증하지 않습니다. 잘린 신체·낮은 기준점 신뢰도·기울어진 구도에서는 결과를 만들지 않습니다. 일반 사진이 가진 원근·옷·자세의 한계는 제거할 수 없습니다.
- WebGL이 필요합니다. 브라우저나 GPU에서 실행할 수 없으면 안내 메시지를 보여주며 가짜 결과로 대체하지 않습니다. Chromium에서 실제 모델 추론을 검증했고, iPad 크기의 화면 검증은 실제 iPad Safari 기기 검증과는 다릅니다.

## 구조 / 추후 확장

- `assets/products.js`: 안정적인 상품 ID를 가진 정적 카탈로그·사진 메타데이터·착장 참고 데이터. 추후 상품 DB/API 어댑터로 교체할 경계입니다.
- `assets/app.js`: 화면 상태·필터·상세·찜 저장 어댑터. 추후 회원별 찜 API로 교체할 수 있습니다.
- `assets/style.css`: 반응형 디자인 및 접근성·동작 줄이기 설정.
- `assets/ai-studio.js`: 사진 선택·기기 내 AI 추론·결과 삭제·추천 UI. 사진 전체를 서버로 보내는 로직은 없습니다.
- `assets/style-advisor.js`: 신뢰도·구도 검증, 2D 간격 계산, 선택 조건을 지키는 결정적 상품 매칭. ML 추론과 규칙 기반 추천을 분리했습니다.
- `assets/vendor/mediapipe/`: 공식 npm `@mediapipe/pose@0.5.1675469404`에서 무결성을 확인해 포함한 Lite 모델 및 런타임. Apache-2.0 라이선스와 출처·체크섬 기록을 함께 보관합니다. 외부 CDN에 의존하지 않습니다.
- `assets/photos/`: 배포에 포함할 사진. 출처·이용 안내는 `assets/PHOTO-CREDITS.md`에 기록합니다.
- 외부 쇼핑몰 제휴를 추가할 때 실제 판매처·가격 갱신·제휴 표시를 데이터 모델에 별도로 추가하세요.
- 실제 AI 가상 피팅을 추가할 때는 별도 서버에서 인증·동의·사진 보관 정책·비용 한도를 구현해야 합니다. 비밀키를 정적 JavaScript에 넣지 마세요. 현재 버전은 이런 서비스를 호출하지 않습니다.

## 검증

개발용 Playwright와 Chromium이 있는 환경에서 서버를 실행한 후:

```sh
node tests/smoke.cjs
A1_CHECK_PHOTOS=1 node tests/smoke.cjs
node tests/advisor.cjs
node tests/ai-studio.cjs
```

`CHROMIUM_PATH`와 `A1_TEST_URL`로 브라우저 실행 파일과 테스트 주소를 지정할 수 있습니다. 테스트는 필터·검색·정렬·빈 결과·찜 저장·상세 창·착장 선택·320/390/820/1440px 화면·이미지 오류 처리를 확인합니다. 사진 포함 검증은 실제 사진이 모두 로드되고 대체 이미지가 없는지도 확인합니다. 스크린샷은 `/tmp/a1-{width}.png`에 저장합니다. 테스트 도구는 사이트 운영에 필요하지 않습니다.

`tests/advisor.cjs`는 Node 기본 테스트 러너로 기준점 품질·비율·추천 조건을 확인합니다. `tests/ai-studio.cjs`는 Playwright/Chromium에서 로컬 모델을 실제 실행하며, 추론 결과를 조작하거나 가짜 기준점을 주입하지 않습니다. 다운로드 재시도, 사람이 없는 사진 거절, 조건별 추천, 삭제, 외부 요청·사진 저장 여부, WebGL 미지원 안내를 검증합니다. 기본 테스트 주소는 `http://127.0.0.1:8001/A1-/`이므로 다른 서버에서는 `A1_TEST_URL`을 지정하세요. 헤드리스 테스트는 소프트웨어 WebGL을 사용합니다.

## 배포

저장소 반영은 사용자 승인 후 진행합니다. GitHub Pages 설정이 `main` 브랜치 루트 배포라면 반영 후 자동 배포됩니다. GitHub Actions 배포 설정이면 해당 워크플로 결과를 확인해야 합니다. 코드 반영 성공과 실제 Pages 배포 성공은 별도로 확인합니다.
