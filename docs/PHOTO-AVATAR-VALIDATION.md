# 사진 분석 → 개인화된 상대 비율의 3D 아바타

## 실제 구현과 범위

기존 MediaPipe 분석과 `a1:analysis-ready` 이벤트를 그대로 재사용합니다. 결과 아래 **내 체형으로 3D 아바타 만들기** 버튼과 기본 해제된 비율 사용 동의를 제공합니다. 동의하면 `/avatar-lab.html`의 정적 UI 템플릿만 가져와 **현재 문서**에 삽입하고, 메모리의 두 비율을 3D 인체·시험 의류의 정점 계산에 적용합니다. 다른 페이지로 사진/분석값을 옮기지 않으며 별도 가입/권한/요금이 없습니다.

사진상 비율이 서로 다르면 실제 인체·의류 메시와 화면 픽셀이 달라집니다. 독립적인 기본 아바타에 이름만 붙인 기능이 아닙니다. 다만 실제 신체를 정확하게 복원한 모델이 아니라, 두 비율만 반영한 단순화된 참고 아바타입니다.

## 사진에서 얻는 값과 얻지 못하는 값

| 항목 | 근거/처리 |
| --- | --- |
| 어깨/골반 기준점 간격 비율 | 기존 11/12·23/24 기준점으로 계산. 기준점 간격이지 실제 외곽 너비/둘레가 아님 |
| 다리/몸통 기준점 길이 비율 | 기존 23/24·25/26·27/28과 어깨 중심 기준 계산. 실제 다리 길이 cm 아님 |
| 허리·몸 실루엣 | **제공되지 않음**. 기존 분석은 segmentation off이며 허리 기준점/윤곽 분할 없음 |
| 키·가슴/허리/골반둘레·실제 어깨너비·깊이 | 사진에서 계산하지 않음. 기본 예시값 또는 사용자가 직접 입력한 보정값으로 구분 |
| 얼굴·피부·정확한 표면·정확한 사이즈 | 복원/예측하지 않음 |

기준점 visibility ≥ .6와 기존 정면/기울기/경계/비율 검사를 재사용합니다. 이는 신체 측정 정확도 확률을 뜻하지 않습니다. 사진의 옷·자세·카메라 원근이 결과에 영향을 줍니다.

### 형상 연결

`G.photoReference()`는 정확히 두 유한 비율만 허용합니다. 어깨 상대 배율은 `clamp(shoulderHipRatio / 1.35, .78, 1.25)`, 다리 상대 배율은 `clamp((legTorsoRatio / 1.7)^.35, .88, 1.12)`입니다. 기준값은 이 프로토타입의 시각적 보정 상수이며 인구 통계·의학적 표준·실측 모델이 아닙니다.

cm 필드를 사진에서 역산해 채우지 않습니다. 기본/직접 입력한 골격 위에 제한된 무차원 변형을 적용하며 허리/가슴둘레/깊이를 새로 추정하지 않습니다. 기본 cm 표시에는 **기본 예시값 · 사진 측정 아님**, 사용자가 수정한 항목에는 **사용자 보정값**을 표시합니다. 보정값도 실제 정점을 바꿉니다. 연결된 보간 링 몸통과 분절된 팔/다리로 이전의 분리된 타원 몸통 실루엣을 개선했습니다.

## 사용 흐름

1. 최신 Preview 홈에서 사진 선택 → 기존 무료 사진 분석.
2. 결과의 비율 적용 동의 체크 → **내 체형으로 3D 아바타 만들기**. 기본 cm를 다시 입력할 필요 없음.
3. 실제 메시를 바로 표시. LAB-A/B/C 변경은 즉시 인체 위에 반영되며 착용 전후 비교 제공.
4. 별도 사진 표시 동의를 체크하면, 어깨 위쪽을 잘라낸 기존 `#ai-canvas` 분석 이미지를 아바타 옆에 표시. 원본 전체 사진을 다시 저장하지 않으며 얼굴 익명화를 보장하지 않음.
5. 키·가슴·허리·골반·어깨·다리 길이·시각 프리셋 보정. 정면/측면/후면, 회전·확대·핀치 지원. 모바일은 큰 세로 화면으로 배치.
6. 비율 부족/분석 전에는 **기본 아바타 열기 · 수동 보정** 경로 사용. 사진 기반으로 표시하지 않음.
7. **사진·분석·아바타 모두 지우기**는 기존 사진 삭제 이벤트와 연결해 분석 이미지·두 비율·비교 캔버스·수동 값·임시 형상·동의를 함께 초기화.

## 개인정보와 수명

- 비율 적용과 사진 비교 동의는 각각 기본 해제. 비율만 동의해도 사진은 복사/표시하지 않음.
- 전달 매체는 같은 문서의 이벤트/메모리뿐. URL, sessionStorage/localStorage, postMessage, API/외부 서비스, 로그·분석 도구에 사진/비율/치수를 쓰지 않음. 기존 언어 설정만 저장.
- 템플릿 GET은 본문/사진/수치 없이 `credentials:omit`, `redirect:error`, `cache:no-store`. 템플릿의 script는 가져오지 않으며 사전 로드된 동일 출처 코드만 사용.
- 삭제·사진 교체·비율 동의 철회는 revision을 증가시키고 인체/의류 GPU 버퍼를 기본 형상으로 덮어쓰며, 입력·비율·비교 캔버스를 초기화하고 연구 화면을 숨김. 페이지 이탈 시 GPU 자원을 해제.
- 지연된 템플릿 응답은 현재 revision과 동의를 재확인한 뒤에만 mount. 로딩 중 삭제/철회 시 복원되지 않으며, 철회 후 재동의한 최신 요청은 정상 처리.
- Preview API 미들웨어·서버 구독/소유권·Firebase/회원/운영 DB·결제/유료 API/Cloudflare 환경 설정은 변경하지 않음.

## 검증과 실제 증거

- geometry 단위 검사: 서로 다른 두 비율이 인체와 모든 의류의 실제 정점을 바꿈, 수동 보정도 반영, 잘못된 비율/추가 필드 거부, 경계 치수에서도 유한한 3D 메시. 비율 매퍼가 cm를 생성하지 않음.
- KO/EN × 820×1180 / 1180×820 / 390×844: 기존 분석 계산 → 동의 차단 → 다른 형상/픽셀 → 수동 출처·의류·정면/측면/후면 → 별도 사진 동의/철회 → 비율 철회 → 다른 분석 → 전체 삭제.
- 두 시험 체형은 같은 저장소 예시 사진에 서로 다른 **고정 자세 기준점 fixture**를 넣은 재현 검사입니다. 서로 다른 실제 사람 두 명을 정확히 복원한 증거로 사용하지 않습니다.
- 지연 템플릿의 삭제/철회/재동의 경쟁 상태 별도 검사. 기존 독립 3D 조작·터치 핀치, 홈 추천/비교/2D/삭제 흐름 회귀 유지.
- 실제 최신 Preview에서 실제 MediaPipe 모델의 사진 분석 → 동의 → 상대 형상 변화·사진 비교·의류·보정·삭제는 PR #4 본문에 별도 기록.
- Linux 터치 Chromium 검사는 실제 iPad Safari 합격이 아님. 실제 iPad Safari 최종 확인 전 PR #4 병합 금지.

## 미완료 기능

허리 윤곽/몸 분할, 정확한 사진 기반 3D 복원, 실제 판매 상품 데이터, 자연스러운 AI 사진 합성, 실제 의류의 소재/패턴·물리 시뮬레이션·사이즈 보장은 미완료입니다. 실제 공급원·이미지/3D 권리·외부 사진 처리·비용 승인은 [기존 계획](PRODUCT-FITTING-PLAN.md)을 따릅니다. 이번 기능은 외부 유료 API 없이 동작하며 기존 무료 정책을 유지합니다.
