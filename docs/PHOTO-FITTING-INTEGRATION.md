# 사진 분석 → 자연형 GLB → 로컬 의류 사진 2D 피팅

2026-11-17. PR #4 `feature/product-fitting-lab`, 시작점 `0072b24`. 새로운 모델 생성·조사 없이 기존 자연형 GLB와 실제 의류 사진용 2D 엔진을 연결한다. main 병합·Production 배포·운영 데이터 변경은 하지 않는다.

## 수정 원인과 실제 지원 범위

기존 `avatar-photo-bridge.js`는 `/avatar-lab`의 `#avatar-root`와 `initializeAvatarLab()`을 실행했다. 개선된 GLB는 독립 `gltf-proof.js`에만 있어 분석 뒤 버튼으로는 실행되지 않았다. 기본 경로를 `/gltf-proof`의 `#gltf-proof-root`로 바꾸고 기존 glTF 모듈을 같은 문서에서 한 번만 시작한다. 기본 모델은 기존 `assets/natural-avatar/sample.glb`이며, 얼굴·피부·눈·머리카락·원본 의상과 73관절을 가진 공식 샘플이다. 원본 모델·라이선스·해시는 바꾸지 않았다.

주 분석 화면과 product-lab은 예전 인체 코드·에셋을 선로딩하지 않는다. 분석 뒤 복제한 GLB 선택기에서는 예전 모델 선택지를 제거한다. 기존 WebGL1 인체 코드·모델·독립 `avatar-lab` 페이지는 그대로 보존한다. GLB 실패 시 예전 마네킹을 자동으로 띄우지 않고 원인·재시도·2D 경로를 제공한다.

**현재 GLB에는 사진의 어깨/골반·다리/몸통 비율을 적용하는 검증된 body morph 매핑이 없다. 이번에 GLB 형상에 적용하는 분석값은 0개다.** 사용자가 직접 동의하면 두 비율을 같은 화면의 참고값으로만 표시한다. 철회하면 즉시 숨기고 지운다. 버튼·동의 문구도 이 범위를 명시한다. 형상 변경·실제 신체 치수·같은 사람의 3D 복원이라고 표현하지 않는다. 사진·동의 없이 기본 자연형 GLB를 보는 버튼도 제공한다.

## 같은 페이지의 기존 2D 엔진 재사용

- `lab-entry.js`는 실제 의류 사진 피팅 대상 `#lab-local-photo-fitting`을 직접 연다. 시험용 도식이 선택돼 있어도 이 버튼을 도식 피팅으로 돌리지 않는다.
- GLB 화면의 `내 사진으로 피팅하기 · 로컬 2D`는 기존 product-lab 템플릿과 `product-lab.js`를 재사용한다. 분석 사진 재선택이나 다른 페이지로 사진 전달은 없다.
- 스타일 스튜디오에서도 `사진 선택·체형 분석` / `내 사진 2D 피팅 열기`로 같은 분석·2D 엔진을 한 번만 마운트한다. 새로운 시안이나 피팅 엔진을 만들지 않는다.
- 기존 `ai-studio.js`가 유지하는 얼굴 제외 `#ai-clean-canvas`를 2D 엔진이 직접 읽는다. 원본 전체 얼굴 사진은 기존 정책대로 분석 후 폐기한다.
- 의류 이용권 확인과 개인 사진 2D 사용 동의는 각각 직접 선택한다. 위치·크기·회전·투명도와 의류 숨기기/전후 비교는 기존 캔버스 조작을 유지한다.
- 2D 결과는 **사진 겹치기**다. 자연스러운 AI 착용 합성·자동 가림/주름·사이즈 예측이 아니다. GLB의 원본 의상 한 벌과 선택한 의류 이미지는 별개다. 호환 3D 상품 의상이 없는 상품에 3D 착용을 약속하지 않는다.

## 검색·무료 정책·개인정보

2D 피팅 아래의 공식 검색은 기존 `A1ShoppingQuery.parse/links`와 `A1Preview.retailerActions`를 재사용한다. 무신사·29CM·네이버쇼핑·쿠팡의 고정된 HTTPS 검색 경로, 검색어 복사·공식 홈페이지·Safari 안내를 유지한다. 사용자 입력에서 허용된 의류 단어만 추출하며 사진·비율·파일명은 검색 URL에 넣지 않는다. 예산은 판매처 필터에 자동 적용되지 않는다고 안내한다. 의류 사진에서 특정 상품을 식별했다고 표시하지 않으며 실제 상품·가격·개별 구매 URL을 만들지 않는다.

사진·분석값을 URL/이벤트 사진 payload/서버/외부 API/영구 저장소로 보내지 않는다. 동의가 철회되거나 사진이 교체·삭제되면 관련 canvas·의류·동의·비율 참고값·GPU를 정리한다. 지연 템플릿·GLB 요청은 취소/세대 검사를 통과하지 못하면 화면과 자료를 되살리지 않는다. 무관한 기존 저장소 항목은 지우지 않는다.

스타일 스튜디오의 CSP에는 **기존 로컬 MediaPipe WASM 실행을 위한 `wasm-unsafe-eval`만** 추가한다. 외부 스크립트·API 호스트는 추가하지 않으며 `connect-src 'self'`, 기존 `/avatar-lab`의 `connect-src 'none'`, Preview `/api/*` 503 격리를 보존한다. Preview 분석 완료 문구의 불필요한 구독 요구도 수정한다. 운영 서버의 구독 권한 검사는 변경하지 않는다.
