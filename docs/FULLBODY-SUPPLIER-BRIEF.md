# 전신 디지털 휴먼 + 첫 의류 납품 요청서

검토용 초안이며 외부로 보내지 않았습니다. 공급자 선정·계정 신청·약관 동의·결제·주문에 대한 승인이 아닙니다. [후보/권리 검토](FULLBODY-ASSET-REVIEW.md)와 [런타임 수용 조건](FULLBODY-RUNTIME-REQUIREMENTS.md)을 함께 확인합니다.

## 전달할 프로젝트 설명

> A1 FASHION은 소비자 무료 베타 의류 비교·추천·가상 피팅 웹 서비스입니다. 직접 상품을 판매하거나 결제를 대행하지 않습니다. 첫 도입 범위는 하나의 일관된 전신 인체와 실제 재단 구조의 별도 티셔츠 한 개입니다. 사용자는 전신을 회전하고 입력 치수/별도 동의한 체형 참고값으로 허용 범위에서 체형을 조절하며 의류를 갈아입습니다. 사용자 사진은 공급자나 외부 AI에 전달하지 않습니다.

## 공급자에게 필요한 서면 답변

- 무료 베타와 향후 상업 서비스에서 GLB/텍스처를 브라우저에 전송·캐시하여 표시하고, 인체/의류를 체형 morph로 바꾸는 것을 허용하는지 확인합니다. 영상 출력·게임 포함권만 답변하지 말고, 파일이 클라이언트에 전달되어 추출 가능하다는 웹 구조에 대한 허용 조건을 명시해주세요.
- SaaS/아바타 편집·부분 파생·LOD/압축/변환·별도 의류 교체 권한, 공개 저장소에 포함 가능한 범위, 이용자 생성 파생물과 서비스 종료 시 처리 조건을 구분해주세요. 원본 저장소 공개가 허용되지 않으면 비공개 제작 원본과 적법한 서비스 전달본의 범위를 구분해주세요.
- 얼굴·몸·피부·눈·머리카락·의류·모든 맵의 권리자/원출처·라이선스 버전·표시 의무·제3자 제한과 인물 likeness/model release 범위를 제공해주세요.
- 인원/매출/이용량/기간/국가/용도 제한, 서비스 내 아바타 커스터마이징에 필요한 별도 계약, 비용·갱신·철회/삭제 조건을 제시해주세요. 무료 소비자 이용이 공급원 비용 면제를 의미한다고 전제하지 않습니다.

## 첫 납품 세트

1. 같은 인물/제작 체계의 얼굴·목·몸·손·발·눈·모발이 연결된 전신. A/T-pose, 미터 단위, 축·rest pose와 topology 문서. 옷 안의 온전한 인체도 필요합니다.
2. 별도 티셔츠 메시와 기준 재단/봉제·사이즈·원단/두께 자료. 인체와 같은 skeleton/bind, body morph에 대응하는 garment morph/보정 또는 사전 drape 데이터. 교체할 수 없는 clothed scan은 이 항목을 충족하지 않습니다.
3. 모바일용 hair cards/눈/피부/원단 PBR 맵, UV·tangent·색공간, alpha 모드·LOD, 필수 glTF 확장 목록. 원 제작 툴의 사적 노드/런타임 없이는 표시되지 않는 기능을 별도 명시해주세요.
4. 키·어깨·가슴·허리·골반·다리 입력의 지원 범위와 morph 대응표, 범위 밖 실패 처리. 실제 원단 물리·상품 사이즈 보증을 하지 않는 시각 미리보기일 경우 그 한계를 명시합니다.
5. GLB/GLTF 전달본과 수정 가능한 제작 원본, 파일별 해시·크기·재질/삼각형/뼈대/morph 수·텍스처 메모리 추정. 신체와 의류의 대응 관계를 파일 버전/해시로 고정합니다.

## 검수 자료

공급자 원본 뷰어/렌더와 브라우저 출력의 정면·측면·후면·얼굴·손·모발·의류 근접 화면을 비교합니다. iPad Safari 세로/가로의 실제 기기/OS, 360도 회전·핀치·의류/체형 변경·메모리·context loss를 확인할 수 있어야 합니다. 사전 데스크톱 렌더나 클릭 시간만으로 iPad 표시 FPS가 확보됐다고 판단하지 않습니다.

도입 승인 전 확인 순서는 **권리 → 실제 파일/rig·morph·재질 호환 → 격리 브라우저 품질 → 실제 iPad 성능/기존 서비스 회귀**입니다. 모든 항목이 확인된 뒤에만 PR #4에서 작은 단위로 통합하며, main/Production은 별도 승인 대상입니다.
