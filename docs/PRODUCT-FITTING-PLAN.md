- 결제·구독 연동 완성과 운영자의 별도 유료 전환 승인 전에는 모든 이용자에게 기능을 구독료 없이 제공합니다. FREE/GENERAL/PREMIUM의 기존 운영 검증은 보존하되 무료 베타에서는 사용자 등급을 기능 잠금으로 사용하지 않습니다.
- 기존 무료 베타/PR #1·#3의 공개를 이 연구실 때문에 기다릴 필요가 없습니다. 새 화면은 표준 Preview에서만 직접 열리는 `/product-lab.html`이며 기존 메뉴·분석·삭제·상담·쇼핑 흐름을 교체하지 않습니다.
- 실제 데이터가 없는 기본 상태는 **실제 상품 준비 중**입니다. 사용자가 명시적으로 시험 버튼을 누른 경우에만 **가상 상품**을 표시합니다. 개별 실제 구매 URL은 만들지 않으며 시험 금액을 실제 가격으로 표시하지 않습니다.
- 이번 작업에서 키 발급·외부 API 호출·유료 가입·GPU 실행·모델 다운로드·실제 이미지 생성·결제/발송/Cron 활성화·회원/운영 DB/Firebase/구독 기록 변경·운영 마이그레이션·main 병합·Production 배포를 하지 않습니다.

## 2. 이번 구현 범위

- 별도 연구 화면: 사진 → 기존 분석 → 스타일/선택적 성별 컬렉션/예산/통화/색상/용도/사용자가 확인한 사이즈/피할 디자인 → 추천 이유·위험·출처·비교 → 별도 이미지 사용 동의 → 로컬 2D 배치 → 공식 검색.
- `assets/product-matching.js`: 동일 조건에 재현 가능한 점수·제외 사유·확인 필요 사항을 반환하는 순수 규칙 엔진. 사진이나 회원 정보를 받지 않음. 동의하지 않은 비율은 결과에서 제거.
- `server/product-matching.mjs`: 새 HTTP 엔드포인트 없이 기존 승인 카탈로그를 읽고 점수를 조립하는 **내부 함수**. 승인 기본값 false, DB 읽기도 비활성. `allowLiveCatalog`는 향후 신뢰된 서버 코드만 제공하며 요청 JSON을 그대로 전달하면 안 됨. 이 함수는 인증/권한 검사를 대체하지 않음.
- 가상 의류 3개는 원본 A1 도식 SVG와 명시적인 시험 금액/시간으로만 표시. 스크래핑·실제 판매 상품 수집은 없음.
- 분석 비율 사용 동의와 이미지 2D 배치 동의는 서로 분리하고 기본 해제. 철회·사진 교체·삭제·페이지 이탈 시 캔버스/비율/선택/비교/조건을 초기화.
- 피팅은 **분석 결과의 얼굴 제외 이미지 위에 가상 도식을 놓는 위치/크기 실험**이다. 원본 인물 사진에 실제 의류를 자연스럽게 합성한 결과가 아니며, 생성형 AI/착용감/사이즈 보장이 아님.
- 새 페이지 CSP는 self 정적 자산/기존 로컬 모델·blob 이미지로 제한. 외부 이미지 URL·외부 생성 API·사진 저장 기능은 구현하지 않음. 분석 사진·조건·결과는 메모리/캔버스만 사용하고 저장소에는 기존 언어 선택만 남김.

## 3. 실제 상품 추천 구현 방법

승인된 공급원 → 서버 비밀키/공식 피드 → 정규화·출처/권리 검증 → 격리 카탈로그 스냅샷 → 기존 `loadVerifiedCatalog` → `rankApprovedCatalog` → 실제 상품 카드 → 동일/유사 상품 구분 → 별도 승인된 피팅.

### 제안 데이터 계약 v2 (설계, 미적용)

| 필드 | 검증/용도 |
| --- | --- |
| provider·providerProductId·seller·productId·variantId·GTIN/SKU | 공급자/판매자/변형을 분리. 이름 유사성만으로 동일 상품 확정 금지 |
| name·brand·category·genderCollection·styles·colors·occasion·designTags | 공식 자료에서 확인된 속성만 사용. 없는 정보는 unknown. 자동 추출 속성은 출처·확신도 별도 표시 |
| priceMinor·currency·shipping/tax/duty·stock | 원 통화/단위 유지. 배송/세금 미확인을 0으로 계산하지 않음. 검증 환율 없으면 통화 간 최저가 비교 금지 |
| sizeLabels·sizeSystem·sizeChartUrl·garmentMeasurements | 사용자가 입력한 표기와 비교하되 브랜드/국가별 M을 동등한 실제 치수로 가정하지 않음 |
| image.displayUrl·imageSource·display/cache/transform/externalAI 권리 | 이미지 표시 허가와 변형/외부 AI 전송 허가는 별도. 이미지가 공개됐다는 이유로 피팅에 쓰지 않음 |
| productUrl·sourceUrl·termsVersion·approvalRef | HTTPS 허용 판매처, 직접 상품 URL/제휴 URL 검증, 비밀값 제거, 추적 고지 |
| checkedAt·expiresAt·minimumRefresh·retentionUntil | 자료 만료 시 숨김. 제공자별 갱신/삭제 정책을 반영 |

기존 DB를 덮어쓰거나 schema/migration을 적용하지 않았습니다. 이 계약의 새 이미지/속성 필드는 승인된 격리 DB/자료 파일에서 먼저 검증한 뒤 별도 운영 변경으로 검토해야 합니다. 이미지 사용 권한이 없는 상품은 추천에 텍스트만 표시하거나 제외하고, 피팅은 잠금 대신 준비 중으로 정확히 안내합니다.

### 점수와 추천 이유

현재는 규칙 기반 **조건 일치 점수**입니다. 실제 착용 확률·AI 신체 치수 추정치가 아닙니다.
예산을 넘는 상품, 다른 통화, 확인된 품절/미확인 재고, 만료/미승인 출처, 확인된 사이즈 불일치·피할 디자인은 제외합니다.
기본 예산 20, 요청한 스타일 25·색상 10·용도 15·표기 사이즈 15·컬렉션 5·동의한 사진상 참고 규칙 10의 가중치를 사용합니다. **요청한 항목의 가중치 합**으로 나누어 0–100으로 표시하므로 미선택 조건이 좋은 품질을 뜻하지 않습니다. 동의하지 않은 몸 비율은 분모/분자 모두에서 제외합니다.
자료가 없는 사이즈/용도/디자인은 확인 필요 경고입니다. 비율로 S/M/L·허리·키·체중을 만들어내지 않습니다. 현재 기존 카탈로그에 없는 의류 디자인 속성은 매칭 근거로 생성하지 않습니다.
각 상품에 조건 일치 이유와 사이즈표/실측 확인·착용 보장 없음·배송/세금 별도 경고를 표시합니다. 유사 상품 후보의 조건 비교와 동일 변형의 최저가 비교를 구별합니다.

[FASHN 보관 문서](https://docs.fashn.ai/api-overview/data-retention-privacy)는 기본 출력 CDN 보관, 짧은 base64 출력 유효 기간, 자동 삭제되지 않는 요청 기록과 별도 삭제 요청 방식을 구분합니다. 입력을 저장하지 않는다는 문구만으로 전체 로그/출력 무보관을 주장하면 안 됩니다. Google Shopping의 소비자용 사진 정책을 Cloud API 계약에 그대로 적용하지 않습니다.

### 미래 외부 피팅의 승인 흐름

선택한 실제 상품의 변형/외부 AI 이미지 권리 확인 → 목적·공급자·리전·수신 항목·보관/삭제 설명 → 기본 해제된 **외부 전송 동의** → 인증된 격리 처리 → 요청 수/일/월 비용 원자적 예약 → 한 번 호출 → 결과에 시뮬레이션 표시 → 입력/결과의 승인된 보관 기한 삭제.
동의 철회·파일 교체·탈퇴·제공자 실패·취소/불확실한 청구 시 정책을 따로 검토하며, 네트워크 재시도로 자동 비용을 늘리지 않습니다. 로그에는 사진/base64/원본 URL/분석 수치/이메일을 남기지 않는 설계를 우선합니다. 안전장치를 만드는 것과 운영자 승인 없이 외부 API를 켜는 것은 별개입니다.

## 6. 무료 범위와 비용 통제

현재 무료: 기기 내 분석, 조건 입력·규칙 점수·이유·비교, 명시적 시험 데이터, 로컬 도식 배치, 공식 검색/복사, 한/영·비로그인. 호스팅 무료 한도는 실제 계정 기준입니다.
승인 전 준비 중: 실제 상품 피드 연결, 실제 상품 이미지 피팅, 서버 저장/공유, 외부 생성 API, 자동 수집/갱신. 유료 API·GPU·저장/전송·데이터 계약/한도 초과가 비용 원인이 될 수 있습니다.
현재 새 이미지 API 어댑터/키·상품 수집 엔드포인트·스케줄·결제·청구 코드가 없고, 새 서버 조립 함수는 승인 기본값 false로 카탈로그 DB 조회도 하지 않습니다. Production 플래그와 기존 구독 기록을 변경하지 않았습니다.
