# 서버 정책에 따른 무료 베타 공개 기능 연결

2026-11-19, PR #4 `feature/product-fitting-lab`, 기준 `6ce8377`.

## 발견한 출시 차단과 이번 연결

기존 PR #4의 신규 검색·상품 사진·분석 후 2D 기능은 `A1Preview`가 있는 Preview 호스트에서만 시작됐다. 운영 서버에 `A1_FREE_BETA_MODE=true`를 설정하는 것만으로는 이 기능들이 Production에 나타나지 않았다. 따라서 원본 이미지 CDN 허용만 남았다는 이전 설명은 불충분했다.

이번 코드는 Preview의 호스트 보호를 없애지 않고, 기존 순수 브라우저 기능을 `local-fashion-core.js`로 분리해 재사용한다. `public-beta-bootstrap.js`는 공식 운영 호스트 `https://a1fashion.pages.dev`에서 **자체 요청한 `/api/policy`**의 정상 JSON 응답을 확인한 뒤 공개 로컬 기능을 초기화한다. 실제 운영 설정·배포를 실행했다는 뜻이 아니다.

- 응답은 `freeBetaMode:true`, `billingEnabled:false`, `accountRequiredForSaving:true`인 정확한 정책 형식이어야 한다. 잘못된 형식·MIME·URL·리디렉션·네트워크 실패·5초 시간 초과는 활성화하지 않는다.
- 쿠키·localStorage·쿼리·클라이언트 정책 이벤트를 활성화 근거로 쓰지 않는다. Production에는 `A1Preview` 객체를 만들지 않는다. `A1PublicBeta`는 서버 권한이 아닌 로컬 공개 화면의 초기화 상태다.
- 실제 회원·유료 API 권한은 계속 서버가 검사한다. 사용자가 자신의 JavaScript/DOM을 임의 수정할 수 없다고 주장하지 않는다. 화면 조작으로 서버의 회원별 데이터·구독·유료 기능을 얻을 수 없도록 기존 검증을 유지한다.
- Preview에서는 bootstrap이 정책 API를 호출하지 않는다. 기존 Preview `/api/*`503 보호와 회원·DB·실제 AI 미연결을 유지한다.
- 정책이 늦게 도착해도 분석 완료를 놓치지 않도록 현재 화면의 두 비율만 메모리에서 보관·재전달한다. 사진을 복제하거나 URL·영구 저장소·외부 서버에 넣지 않는다. 각 추천/사진 사용 동의는 별도로 유지한다. 지우기·철회·계정 변경·페이지 이탈은 지연 자료를 폐기하며 BFCache 복귀는 정책을 새로 확인한다.

순수 helper는 결제·회원·유료 AI 권한을 부여하지 않는다. 무료 베타 종료 시 서버 플래그가 꺼지면 다음 API 요청부터 기존 구독 검사로 돌아가며, 이미 열린 로컬 화면을 유료 권한의 증거로 쓰지 않는다. 새 페이지는 서버 정책을 다시 확인한다. 결제 연결·정식 유료 전환은 별도 검증과 운영자의 명시적 승인이 필요하다.

## 상품 자료 정리

요청한 유니클로 NAVY 옵션과 추출된 다른 제품/BEIGE 본문이 일치하는지 끝내 확인하지 못해 해당 후보를 공개 목록에서 제외했다. 실제 공식 29CM 상품 `4145774` 리 여성 네이비 카디건으로 교체하고, 그 페이지의 대표 이미지와 네이비 옵션 링크 관계를 기록했다.

공식 상품 후보 **10개**, 공식 이미지 참조 **10개**, 실제 원본 로컬 복제 **0개**다. 새 카디건은 오래된 가격·할인 표기와 사이즈 불확실성을 반영해 가격 `null`, 사이즈 빈 목록, 재고 `unknown`으로 유지한다. 나머지 상품의 확인 시각·가격·재고를 새로 확인한 것처럼 갱신하지 않았다. [공식 출처 기록](validation/public-beta/tenth-product-source.json)을 보관한다.

두 CDN 호스트 `image.msscdn.net`, `img.29cm.co.kr`는 현재 Codex 환경에서 미허용이다. 원본 접속을 반복하거나 우회하지 않았다. 승인된 원본을 확보하면 기존 로컬 저장·검증 도구로 같은 출처에 저장하고 실제 상품 사진 피팅 품질을 확인해야 한다.

## 검사 근거와 남은 조건

- 전체 단위·서버 권한·개인정보·비용·파일 검사 **388개 통과**. 기존 Preview 호스트 차단 검사를 약화시키지 않았다.
- [격리 Production 호스트 브라우저 검사](validation/public-beta/isolated-production-browser.json) **14개 통과**. 실제 운영 사이트에 접속하지 않고 로컬 응답으로 격리한다. 정책·DEMO·회원/개인 자료 핸들러는 실제 코드를 호출하며 실제 회원·DB·외부 서비스는 사용하지 않는다. 결과와 정확한 범위는 함께 저장한 검증 기록을 따른다.
- 이미지 픽셀 검사는 명시적 비공개 fixture다. 실제 판매처 원본·CORS·원본 사진의 착용 품질이나 실제 iPad Safari 인증을 대신하지 않는다.
- 기존 Preview 검색·상담·이미지/로컬2D 회귀 검사와 배포된 Preview의 실제 분석·GLB/2D 실행을 구분해 확인한다.
- 빌드118파일·공개 노출 검사119파일 통과. 정책 연결 JS와 검증된 공개 자산만 배포하며 검사 도구·서버 비밀값·미등록 이미지를 공개하지 않는다.

아직 실제 상품 원본 확인·실기기 확인·통합 브랜치의 최종 검토·필수 GitHub 검사/복구 지점 및 운영 설정 확인·명시적 main/Production 승인이 필요하다. 이번 개발 성공만으로 Production GO를 선언하지 않는다.

main 병합·Production 배포·Cloudflare 로그인/운영 변수 변경·운영 Firebase/DB/회원/구독 기록 변경·실제 결제/유료 API/발송/Cron·개인 사진의 외부 전송을 실행하지 않는다. PR #4는 Draft·미병합을 유지한다.


## 승인 후 필요한 운영 설정 — 이번에는 적용하지 않음

먼저 PR #4→기존 통합 경로의 충돌·회귀·필수 검사를 마치고, 운영자의 명시적인 통합/main/Production 승인을 받아야 한다. Cloudflare Pages의 기존 프로젝트 `a1fashion`, Production 브랜치 `main`, 빌드 `node scripts/build-site.cjs`, 출력 `dist`를 유지한다. 새로운 프로젝트·유료 서비스·DB를 만들지 않는다.

Production의 서버 변수는 문자열 `A1_FREE_BETA_MODE=true`가 핵심이다. 브라우저 변수·쿠키·localStorage로 대체하지 않는다. 실제 GPT는 `A1_AI_MODE=demo` 또는 미설정, LIVE 승인·상품 피드·발송·Cron·결제는 비활성 상태를 확인한다. 새로운 AI/상품/발송 비밀키를 넣거나 기존 Firebase/DB/회원 설정을 지우지 않는다. Preview 변수에 Production 비밀값을 복제하거나 `/api/*`503 보호를 제거하지 않는다.

기존 정상 Production 복구 지점 `main/67d229a`, 배포 접두사 `42f5e950`는 이전 사용자 기록이다. 현재 성공 상태·전체 ID·Rollback 가능 여부를 Cloudflare에서 다시 확인한 것은 아니므로 운영자가 실제 배포 전에 확인해야 한다. 실패 시 확인된 이전 성공 Production 배포로 코드 Rollback하며 운영 DB 역마이그레이션·회원 복원·강제 push를 자동 실행하지 않는다.
