# A1 무료 로컬 3D 아바타 프로토타입과 완료 기준

## 실제 구현 범위

`avatar-lab.html`에서 WebGL 삼각형 메시·깊이 검사·법선 조명으로 인체와 선택한 시험 의류를 렌더링합니다. 2D 사진/그림을 회전시키는 화면이나 완료 버튼이 아닙니다. 몸통·머리·목·팔·다리·발과 의류 몸통/소매를 코드로 생성합니다. 외부 모델·텍스처·학습 데이터·사진을 사용하지 않습니다.

직접 입력한 키·가슴/허리/엉덩이둘레·어깨너비·안쪽 다리 길이와 시각 프리셋을 기하학적 비율에 반영합니다. 단순 타원체를 조합한 마네킹으로 신체 치수의 정확한 표면 복원이나 실제 착용감을 주장하지 않습니다. 사진에서 치수를 자동 추정하거나 원본 사진·체형 분석 비율을 자동 반입하지 않습니다.

- 무료·비로그인·표준 Pages Preview 전용. 직접 주소와 홈 분석 후 3D 버튼으로 접근.
- 시험 카드의 3D 링크는 허용된 `LAB-A/B/C` 식별자만 동일 출처 fragment로 전달. 사진·비율·회원·치수 전달 없음.
- LAB-A 기본 네이비 셔츠, LAB-B 느슨한 네이비 형상, LAB-C 짧은 네이비 형상을 표시. 기존 2D 도식에서 실제 의복 패턴을 복원한 것이 아니라 같은 시험 의류 ID의 단순 3D 예시입니다.
- 좌측 기본 인체와 우측 시험 의류 착용 인체를 같은 치수·카메라로 비교. 의류 없음 선택 시 두 화면 일치.
- 드래그/한 손가락 포인터로 회전, 핀치/휠·확대/축소 버튼, 키보드로 조작. 두 뷰 동기화.
- 초기화로 치수·의류·회전·확대 복원. 페이지 이탈 시 form/메모리·GPU 버퍼·프로그램·캔버스 해제. bfcache 재진입은 새로 로드.
- 범위를 벗어난 치수·비율, WebGL 시작 불가·컨텍스트 상실에 오류 안내. 사진이나 치수를 저장소/URL/서버로 보내지 않음. 페이지 CSP는 `connect-src 'none'`.

## 기능별 완료 기준과 현재 상태

버튼·안내·자동 검사 성공만으로 제품 기능 완성을 선언하지 않습니다. 검증된 실제 데이터/렌더링 결과와 사용 가능한 흐름이 완료 기준입니다.

| 기능 | 완료 기준 | 현재 실제 상태 |
| --- | --- | --- |
| 기기 내 사진 참고 분석 | 사진에서 기준점/결과가 출력되고 삭제 가능 | 기존 기능 유지, 실기기 사용자 확인 이력 있음. 실측/사이즈 추정 아님 |
| 실제 판매 의류 자동 추천 | 승인된 현재 상품 이미지·가격·사이즈·출처·구매 URL·확인 시각과 조건 기반 추천이 출력 | **미완료**. 실제 공급원 미연결. 현재 규칙 엔진과 가상 시험 자료만 있음 |
| 실제 상품 비교 | 검증된 동일/유사 상품의 실제 정보·추천 사유·미확인 항목 비교 | **미완료**. 가상 시험 비교만 구현 |
| 자연스러운 AI 사진 피팅 | 권리가 확인된 실제 의류가 명시적 동의하에 인물 사진에 자연스럽게 합성된 결과와 품질 검증 | **미완료**. 현재 로컬 2D 도식 배치는 AI 합성이 아님 |
| 조작 가능한 로컬 3D 프로토타입 | 실제 3D 인체·시험 의류 픽셀 출력, 입력에 따른 형상·카메라 변화, 전후 비교 | **구현·브라우저 검증**. 단순 시각적 마네킹. 실제 iPad Safari 최종 확인 필요 |
| 실제 의류의 정확한 3D 피팅 | 허용된 상품별 3D 메시/패턴·사이즈·소재와 검증된 아바타·충돌/드레이프 결과 | **미완료**. 신체 스캔·정확한 의복 물리·실제 상품 매핑 없음 |

## 공식 상품·사진 피팅 연동과 승인

[기존 공식 공급원 조사·정정 및 피팅 비용 계획](PRODUCT-FITTING-PLAN.md)을 유지합니다. 네이버 쇼핑 검색 API 종료 사실을 반영한 계획이며, 기존 문서가 있다는 이유로 상품 연동 완료로 보고하지 않습니다.

초기 공급원은 권리자가 허용한 브랜드 CSV/JSON·상품 이미지 또는 승인된 eBay Browse/Awin 피드 1개가 후보입니다. 쿠팡은 파트너 승인·현행 조건, Amazon/Rakuten은 현행 인증·자격·사용 조건 검증이 필요합니다. 가입/키 발급·실제 수집은 실행하지 않습니다.

운영자 승인이 필요한 사항:
1. 실제 상품 자료·API/피드 계정과 접근·요금/쿼터·가격 갱신/출처/이미지 표시 권리.
2. 사진 합성을 위한 상품 이미지 변형·외부 AI 처리 권리, 사진 전송의 목적/수신자/국외 처리·보관/삭제·학습 제외와 별도 동의.
3. 실제 3D 의류 glTF/메시·재봉 패턴·사이즈별 치수·소재/물성 자료와 상업 이용·변형/배포 권리. 2D 상품 사진을 보유했다고 3D 복원 권리가 자동 확보되지 않음.
4. 정확한 아바타 모델/리깅·스캔 사용 시 상업 라이선스와 생체/치수 정보 처리·검증. 현재는 직접 작성한 기하 코드여서 별도 모델 라이선스/API 키가 없음.
5. 외부 추론·GPU·저장/전송 예산과 상한, 운영 DB/Production 배포는 각각 별도 승인. 무료 이용 정책과 공급자 비용 지불은 구분하며 사용자에게 자동 청구하지 않음.

## 비용·일정

현재 프로토타입은 외부 API·클라우드 GPU·모델 라이선스 추가 비용 $0이며 사용자 기기의 WebGL 자원을 사용합니다. 기존 호스팅 한도는 유지하며 무제한 무료 호스팅을 보장하지 않습니다. 새 서비스 가입·청구·유료 API·Cron 없음.

실제 AI 사진 피팅 후보의 조사 단가는 Google Virtual Try-On 약 $0.06/출력, FASHN/fal 약 $0.075/생성으로 1,000장 약 $60/$75(세금·재시도·저장/전송 별도)이며 [공식 출처와 제한](PRODUCT-FITTING-PLAN.md#5-가상-피팅-후보와-비용)을 다시 확인 후 승인해야 합니다. 자체 모델은 GPU·상업 라이선스·운영 비용이 필요하며 비상업 가중치를 무료 상업 사용으로 간주하지 않습니다.

이번 단계는 조작 가능한 3D 프로토타입. 다음은 iPad 실기기 확인과 인체/의류 모델 개선 2–3 작업일, 승인된 실제 상품 자료 1개 연결 2–3일, 실제 추천 검증 3–5일 추정입니다. 실제 3D 의류 1개 연결은 사용권/메시 수령 후 3–5일의 제한 시험이 가능하나 정확한 물리 피팅은 별도 연구·품질 목표·소재 데이터가 필요해 확정 일정을 제시하지 않습니다. 기존 베타 공개는 새 기능과 분리합니다.

## 증거와 제한

- geometry 단위 검사: 모든 메시가 유한한 실제 깊이·삼각형을 갖고 각 치수·형상·의류 변경이 정점을 바꾸는지 확인.
- KO/EN × 820×1180 / 1180×820 / 390×844 터치 Chromium: WebGL 픽셀 다양성(빈 화면 아님), 착용 전후/의류별 픽셀 차이, 의류 없음의 두 뷰 일치, 치수·회전·확대 변화, 드래그·실제 2점 터치 핀치, 초기화·유효성 오류·저장소 비기록·정적 요청만 확인.
- 홈 분석→시험 LAB-B→실제 3D 화면/선택 의류 연결, WebGL 미지원 오류, Production 연구실 비활성 별도 검사.
- 기존 홈·사진 분석·동의·2D·삭제 흐름 회귀 검사. 실제 배포 검사/최신 Preview는 PR #4 본문에 기록.
- [태블릿 아바타 전후](validation/avatar/avatar-ko-820.png), [모바일 아바타 전후](validation/avatar/avatar-ko-390.png), [영어 가로 화면](validation/avatar/avatar-en-1180.png). 모두 실제 3D 렌더링한 시험 화면이며 사진 합성이 아님.
- Linux Chromium 검사는 실제 iPad Safari 합격으로 대체하지 않음. 실기기 최종 검증 전 PR #4 병합 금지. main·Production·회원/Firebase/운영 DB 변경 없음.
