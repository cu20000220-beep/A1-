# 상품 선택 → 사진 참고 피팅 → 해당 판매처 연결 검증

2026-11-10, PR #4 `feature/product-fitting-lab`. main/Production 공개 및 실제 iPad Safari 최종 확인은 보류합니다.

## 실제로 달라진 동작

- 무료 규칙 기반 스타일 상담에서 앞선 종류·색상·용도·핏·예산과 명시적으로 입력한 사이즈를 이어서 사용합니다. 예를 들어 `남성 검정 출근 바지 20만원 이하 사이즈 M` → `좀 더 편한 핏으로`에서도 바지/검정/출근/20만원/M을 유지합니다. 기본 예산 10만원이 명시한 20만원을 덮어쓰지 않습니다. 지원하지 않는 제외/범위 조건은 확인을 요청하며 임의로 넓은 결과를 만들지 않습니다.
- 동의한 체형 참고 검색 제안은 화면에 표시됩니다. 제안을 선택해도 옷 조건만 상담 입력란에 채우며 사용자가 보내기를 눌러야 적용합니다. 사진·비율·사이즈 추정을 판매처 검색어에 넣지 않습니다.
- 허가된 상품의 **개별 상품 URL**이 기존 일반 검색 URL 보호에 막히는 충돌을 수정했습니다. 각 소유 화면은 검증한 동일 URL·유효기간·실제 클릭을 확인하며 변조 링크를 막습니다. 해당 상품 상세/구매 페이지로 연결하며 판매처의 로그인/옵션 선택/결제 과정은 판매처가 담당합니다.
- 상품 이미지의 표시권과 피팅 사용권을 분리했습니다. 운영자 검토 `fittingUseApproved=true`와 허용 이미지 도메인, 유효한 `fittingImageUrl`이 함께 있어야 사진 참고 피팅 버튼이 나타납니다. 기존 승인은 자동으로 승격되지 않습니다.
- 승인된 상품 선택 → 별도 내 사진 사용 동의 → 기존 얼굴 제외 분석 이미지에 상품 이미지 겹침 → 위치/크기/회전 조절 → 선택한 상품의 판매처 이동이 연결됩니다. 스타일리스트에서 이동할 때는 공개 상품 ID만 fragment로 전달하고 즉시 지운 뒤 재검증합니다. 사진/비율은 다른 페이지로 넘기지 않습니다.
- 이미지 서버가 anonymous CORS 또는 캔버스 처리를 허용하지 않으면 안내와 권한 있는 기기 이미지 대안을 제공합니다. 프록시·제한 우회·사진 전송을 하지 않습니다. 2D 겹침은 자연스러운 AI 착용 합성이 아닙니다.
- 기존 절차형 아바타 대신 로컬 **MakeHuman hm08 CC0 인체 메시**를 제공합니다. 사진 없이도 표시되며 직접 입력 치수와 별도 동의한 사진상 두 비율을 실제 정점에 반영합니다. 전후 화면, 시험 의류, 회전/확대와 초기화를 유지합니다. 얼굴/신체 복원, 정확한 치수, 실제 판매 의류의 3D 형상이나 의복 물리를 제공하는 기능은 아닙니다. 출처·고정 해시·변환 방법은 [HUMAN-MESH-LICENSE.md](HUMAN-MESH-LICENSE.md)에 기록했습니다.

## 검증 범위

- 전체 CI와 동일한 로컬 단위·권한·개인정보 검사: **278/278 통과**. 회원·운영 데이터 대신 격리된 시험 데이터만 사용했습니다.
- 신규 스타일 상담 브라우저 검사: 한국어 820px/영어 390px, 명시 조건/후속 질문/수동 수정/동의/철회/삭제/로그아웃/실제 상품 0개 상태 통과. 기존 Production 권한·개인정보 UI 검사도 통과했습니다. 기존 탐색 메뉴 8개에 맞춰 오래된 검사 기대값만 갱신했습니다.
- 신규 상품 피팅 브라우저 검사: 메모리의 **시험용 승인 레코드**로 KO820/EN390의 이미지 픽셀 변화, 별도 사진 동의, 개별 구매 링크, URL 변조 차단, 표시권만 있는 상품 차단, 이미지 응답 차단 안내를 확인했습니다. 실제 판매처 응답·이미지 CORS를 확보한 것으로 해석하지 않습니다. 시험 상품은 공개 파일에 추가하지 않았습니다.
- 인체 메시 단위 8개: 잘못된 자산 거부, 정상 정점/법선, 기본 형상과 수동 치수/서로 다른 사진 비율/시험 의류 형상 변화를 확인했습니다. 브라우저에서는 메시 표시·실제 픽셀·회전·확대와 외부 요청 0을 검사했습니다.
- 정적 빌드 **76개**, Preview 표시 파일 포함 공개 산출물 **77개** 검사 통과. 서버 비밀/직접 OpenAI 호출/운영 데이터는 산출물에 포함하지 않습니다.
- 브라우저 자동 검사는 Linux Chromium 터치 환경입니다. 실제 iPad Safari/ChatGPT 앱 내부 브라우저 검증 완료로 표현하지 않습니다.

재현: `node tests/stylist-needs-browser.cjs`, `node tests/catalog-fitting-browser.cjs` (Playwright/Chromium 필요). 실제 배포 주소와 최신 CI 결과는 PR #4에 기록합니다.
