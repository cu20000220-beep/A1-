# A1 자체 AI: 학습형 질문 분류와 추천 엔진

검증일: 2026-11-07. 검토 브랜치: `feature/a1-independent-stylist`. 무료 베타용 `feature/a1-unified-release`의 `a9f27888b2ef12974801da6a89e804068ba78c7c`에서 분리했습니다. 베타 PR #1, main, 기존 AI 브랜치를 변경하거나 운영 배포하지 않습니다.

## 이번에 실제 구현한 범위

사용자가 요청한 두 방향을 함께 구현합니다.

1. **A1 추천 엔진:** 취향·성별·카테고리·색상·상품 가격 예산·통화·배송지를 바탕으로 검증된 상품 후보를 필터링하고 점수로 정렬합니다. 추천 이유는 한국어·영어의 검토 가능한 문구로 표시합니다. 상품 저장소와 가격 비교·인증 모듈을 재사용합니다.
2. **직접 학습한 소형 모델:** 한국어·영어 질문을 코디·착용 참고·색상·상황·예산·관리·비교·할인·범위 밖의 9개 주제로 분류합니다. 문자/단어 특징의 다항 나이브 베이즈 가중치를 로컬 CPU에서 실제 학습하고, 같은 자료로 결과가 재현되는지 검사했습니다.

학습 대상은 질문의 주제입니다. 자유 문장을 생성하는 자체 대형 언어 모델이나 새 사진 인식 모델을 학습한 단계는 아닙니다. 상품의 착용감·사이즈·개인별 맞음 확률을 학습하거나 보장하지 않습니다. 무료 사진 분석은 기존 Google MediaPipe 모델을 기기 안에서 실행합니다.

동의한 두 가지 2D 사진 비율은 일반적인 참고 조언의 우선순위에만 사용합니다. 이 값으로 실제 옷의 사이즈·착용 적합성·건강·정상 체형을 판정하거나 상품 순위를 계산하지 않습니다. 실제 의류 실측과 검증된 착용 결과가 없기 때문입니다.

## 학습 자료와 실제 평가 결과

현재 자료는 이 저장소를 위해 AI 어시스턴트가 만든 **개발용 합성 문장**입니다. 실제 고객 대화·사진·웹 크롤링·전문가 검수 자료를 사용하지 않았습니다. 학습 144개와 평가 36개는 정규화 후 중복이 없지만, 같은 합성 출처이므로 실제 사용자 성능을 대표하지 않습니다.

**75%는 합성 개발 예제의 질문 분류 결과이며, 실제 추천 정확도나 사진 분석 정확도가 아닙니다.** 특히 범위 밖 분류가 부족하므로 모델 판단만 믿지 않습니다. 별도 패션 범위 검사가 금융·의료 등 무관한 질문을 먼저 거부하고, 패션 맥락이 확인되지 않으면 상품과 쇼핑 검색 연결을 반환하지 않습니다. 한정된 검사로 모든 새로운 표현을 정확히 이해한다는 보장도 하지 않습니다.

내부 분류 점수·margin은 보정된 확률이 아니며 사용자에게 정확도나 맞을 확률로 표시하지 않습니다. 원문·모델 가중치도 상담 API 응답에 포함하지 않습니다. 상세 혼동행렬·자료/모델 해시는 [평가 보고서](../training/a1-intents/evaluation.json), 데이터 출처와 재학습 절차는 [학습 자료 안내](../training/a1-intents/README.md)에 있습니다.

## 요청 처리와 기존 보호 장치

`POST /api/stylist`는 기존 Firebase 식별과 서버 구독 검증을 그대로 사용합니다. GENERAL은 스타일 상담, PREMIUM은 비교·할인 상담까지 허용합니다. FREE·만료·취소·환불·미납 회원에게 유료 권한을 열지 않습니다. 답변 직전의 권한·상품 유효성 재검사와 요청 횟수 제한도 유지합니다.

질문 분류 결과나 메시지에 쓴 등급이 권한을 바꾸지 않습니다. 가격 비교는 요청 의도와 검증된 구독을 따로 검사합니다. 상품명·가격·할인·재고·판매 URL은 모델이 생성하지 않고 기존 검증 저장소에서 조립합니다. 승인된 피드가 없으면 조언과 판매처 검색 링크만 제공하고, 상품 자료가 준비되지 않았다고 표시합니다. 오래된 자료·다른 사이즈·확인되지 않은 비용을 최저가로 표시하지 않는 기존 정책을 유지합니다.

자체 엔진은 기본 경로이며 외부 AI를 호출하거나 사용량 예산을 예약하지 않습니다. 기존 GPT 경로도 삭제하지 않습니다. 서버에서 `A1_STYLIST_ENGINE=openai`를 **추가로** 선택하고, 기존 `A1_AI_MODE=live`·운영 승인·정확한 모델·키·요금·일/월 상한·D1·회원 동의 등 모든 조건을 충족해야 호출 후보가 됩니다. 이번 작업에서는 이 설정을 변경하거나 실제 API를 호출하지 않았습니다. 브라우저가 엔진을 선택할 수 없습니다.

화면과 API의 `DEMO` 상태를 유지하고, 자체 엔진 시험 버전·합성 예제 학습·실사용 성능 미검증을 한국어·영어로 안내합니다. 표준 Pages Preview는 기존 격리 미들웨어가 회원·유료 API를 503으로 차단합니다. 로컬의 서명된 시험 계정과 격리 DB로 검증한 결과를 실제 운영 회원 검증과 혼동하지 않습니다.

## 개인정보와 재학습

사진은 외부 AI에 보내지 않습니다. 상담 원문과 두 비율은 기존처럼 메모리에서만 처리하고 학습 자료나 DB에 자동 저장하지 않습니다. 회원가입·구독·외부 AI 동의는 자체 모델 학습 동의를 대신하지 않습니다. 이번 변경은 새 DB 테이블이나 마이그레이션을 추가하지 않습니다.

학습 프로그램은 명시한 로컬 파일만 읽고 네트워크·결제·자동 배포를 실행하지 않습니다. 권리·출처·개인정보 검토·학습 목적 manifest와 학습/평가 분리를 검사합니다. 이메일·전화번호형 문자열·URL·사진/base64·키 등의 입력을 거부하지만, 이 패턴 검사로 모든 개인정보와 권리 문제를 판별할 수는 없습니다.

다음 단계의 실제 자료는 운영자가 권리를 보유한 패션 질문·정답·상품 태그를 전문가와 검토해 준비해야 합니다. 회원 피드백을 사용한다면 별도의 구체적인 학습 동의와 삭제·철회 처리 기준이 필요합니다. 실제 고객 자료는 공개 GitHub에 넣지 않습니다. 대표성 있는 별도 평가 자료로 한국어·영어·취향별 품질과 편향을 확인한 뒤 학습합니다.

현재 코드의 모델 ID·출처 안내는 합성 개발 버전에 맞춰져 있습니다. 실제 자료로 모델을 바꿀 때는 모델 버전·provenance·UI 안내·평가 기준·개인정보 검토를 함께 수정하고 별도 배포 승인을 받아야 합니다. 학습 CLI의 실행 성공은 운영 승인이나 품질 인증이 아닙니다.

서버 모델·합성 말뭉치는 `dist/`에서 제외하며 노출 검사도 추가했습니다. **이 GitHub 저장소 자체가 공개되어 있으므로 코드와 체크인한 합성 자료·가중치가 비밀이거나 복제 불가능하다는 뜻은 아닙니다.** 비밀키와 실제 회원 자료는 저장소에 두지 않습니다. 향후 실제 고객 자료로 학습한 가중치도 원문 정보를 포함할 위험이 있으므로 공개 저장소에 기본 커밋하지 않고, 별도 유출 평가와 비공개 모델 배포 경로를 검토해야 합니다.

## 비용과 배포 경계

이번 로컬 학습·테스트는 외부 AI/GPU/상품 API 비용 0원으로 실행했습니다. 자체 엔진에는 GPT 토큰 사용료가 없지만, 실제 서비스의 Cloudflare 요청/CPU·D1과 Firebase 무료 한도는 별도로 적용됩니다. 무료 CPU 예산 내 성능은 실제 격리 Preview에서 측정해야 하며 무제한 0원 운영을 보장하지 않습니다. 모델·학습 자료가 커지면 별도 학습 장비·저장소·운영 비용을 먼저 보고합니다.

이 브랜치는 별도 검토 대상입니다. 무료 베타 PR #1에는 추가하지 않으며 main·Production·운영 DB·실제 상품 API·GPT·결제·발송·Cron을 변경하지 않습니다. 다음 검토는 코드/학습 자료/권한 → 격리된 환경 성능과 기기 검증 → 실제 데이터 품질/개인정보 검토 → 운영자 배포 승인 순서입니다. 기존 베타의 배포 승인과 자체 AI 배포 승인은 구분합니다.
