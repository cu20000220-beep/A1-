# A1 FASHION 비교·추천 플랫폼: 사업 범위와 상품 공급원 승인

기준일: 2026-11-10. **검증된 실제 공개 상품은 현재 0개입니다.** 코드·양식·검사 fixture·공식 쇼핑몰 검색 링크를 실제 상품 확보나 서비스 완성으로 집계하지 않습니다. 공급원 접근과 실제 자료를 받기 전까지 첫 목표인 한 공급원 실제 의류 10개 이상은 미완료입니다.

## 확정한 서비스 역할

A1 FASHION은 사용자가 의류를 검색하고, 상품 조건·출처·가격과 체형 참고 정보를 비교해 판매처를 선택하도록 돕는 **비교·추천 플랫폼**입니다. 상품 판매자나 결제 대행자가 아닙니다. 주문·결제·배송·교환/환불은 사용자가 실제 판매처의 조건을 확인한 뒤 판매처에서 진행합니다. A1의 검색 링크가 판매처의 재고·진품·배송·반품 또는 최저가를 보증하지 않습니다.

결제·구독 체계가 검증되고 운영자가 별도 유료 전환을 승인하기 전까지 모든 이용자에게 기능을 무료로 제공합니다. FREE/GENERAL/PREMIUM의 향후 서버 권한 구조와 기존 기록을 보존하며 무료 베타에서 기능 잠금을 적용하지 않습니다. 개인 저장 기능은 무료 계정과 소유권 검증이 필요할 수 있지만 Preview는 회원·DB API를 격리합니다. 무료 이용 정책은 외부 공급자·GPU 비용이 자동으로 무료라는 뜻이 아니며, 비용이 필요한 동작을 승인 없이 켜지 않습니다.

## 현재 코드와 실제 연결의 구분

- 승인된 판매자 파일은 오프라인 검증·정규화·검토 해시를 거쳐 공개 가능한 상품 스냅샷으로 만들 수 있습니다. 공개 빌드와 브라우저는 승인/만료/내용을 재검증합니다. 계약·담당자·비밀키는 공개 스냅샷에 넣지 않습니다.
- 기존 공급원 어댑터·레지스트리는 연결 계약 또는 **오프라인 후보 정규화 준비**이며 실제 공급원 호출·다운로드·자동 수집을 의미하지 않습니다. 현재 등록된 공급원과 실제 상품 수는 공개 자료 기준으로 별도 집계해야 합니다.
- eBay의 기존 검색 어댑터는 제한된 discovery 후보를 반환하는 골격이며 실제 이미지·변형·세금/배송비가 검증된 오퍼를 자동 생성하는 완성 연동이 아닙니다. Awin도 승인된 실제 피드와 매핑이 필요합니다.
- Preview `/api/*`의 `preview_isolated` 보호를 제거해 운영 회원/DB/외부 API에 연결하지 않습니다. 정적 승인 스냅샷을 이용하는 브라우저 검색·추천·비교 경로와 향후 서버 권한 경로를 구분합니다.
- 자료가 없으면 **실제 상품 없음**과 공식 검색 대안을 표시합니다. 공식 몰로 이동하는 링크 두 개를 상품 두 개로 세지 않습니다. 판매처의 검색 결과·실제 판매 상태는 별도로 확인해야 합니다.

## 동일 상품·변형 비교 기준

단순히 상품명이 비슷하거나 사진이 비슷하다는 이유로 같은 상품이라고 판정하지 않습니다. 판매자 레코드 ID·내부 SKU·A1의 표시용 그룹 ID도 판매처 간 동일 상품의 증거가 아닙니다.

정확한 비교 후보는 출처가 검증된 **GTIN 또는 제조사 MPN**과 함께 브랜드·색상·단일 `offerSize`·`sizeSystem`·`condition`을 대조합니다. GTIN은 체크 숫자를 검증하지만 실제 제조사 발급 여부와 올바른 변형 매핑은 자료/운영자 확인이 필요합니다. 제조사 MPN과 판매자 내부 SKU를 혼동하지 않고 식별자의 의미 있는 대소문자를 임의로 지우지 않습니다. M 표기만 같아도 국가/브랜드의 사이즈 체계가 다르면 같은 변형으로 확정하지 않습니다.

같은 판매자·정확한 구매 URL·변형·통화·배송국·구매 조건이 중복되면 가장 최근 확인 자료를 사용하며 과거의 싼 가격을 선택하지 않습니다. URL이 다른 중복은 자동 통합을 보장하지 않습니다. 같은 시각에 금액/식별자가 충돌하면 잠정 최저가에서 제외합니다.

필수 식별자가 부족한 자료는 후보/유사 상품 비교로 구분합니다. 여러 사이즈를 가진 상품 행에서 개별 오퍼 사이즈를 선택·확인하지 않은 채 한 변형의 최저가를 계산하지 않습니다. 새 상품과 중고, 다른 색상/변형은 같은 최저가 집합에 섞지 않습니다.

## 가격·배송·재고와 잠정 최저가

가격은 원 통화·원 단위를 보존합니다. 첫 비교는 동일 통화만 사용하며 확인되지 않은 환율로 통화를 바꾸지 않습니다. 배송 국가가 다르면 그 국가에 대해 확인된 비용만 사용합니다.

- `shipping`, `tax`, `duties`의 미확인은 `null`이며 0원이나 무료 배송으로 대체하지 않습니다. 명시적 `costDestination`과 배송 가능 국가를 검증합니다. 판매자 국가가 한국이라는 사실로 국내 배송이나 세금 0원을 추론하지 않습니다.
- 상품 수량 1개·선택한 배송 국가에 대한 무조건 적용 금액을 기준으로 합니다. 회원·카드·쿠폰·최소 구매액 조건이 붙은 가격/비용은 조건을 표시하고 일반 최저가/확정 총액 집합에서 제외합니다. `purchaseConditionsVerified=true`로 확인한 자료만 사용하며 `purchaseConditions=null`만으로 추가 조건 없음을 추론하지 않습니다. 확인 false/미제공은 미확인으로 합계 순위에서 제외합니다.
- 실제 `in_stock`과 확인 시각·만료 시각을 확인합니다. 품절·재고 미확인·배송 불가/미확인 자료를 구매 가능한 최저가 승자로 만들지 않습니다.
- 상품/가격 확인 후 **24시간 이내**이고 공급원 권리·보관 만료도 지나지 않은 자료만 잠정 가격 순위에 사용합니다. 더 짧은 공급원 유효 기간은 그대로 적용합니다.
- 같은 정확한 변형과 배송 조건에 대해 **서로 다른 검증 판매자 두 곳 이상**이 있고 가격·배송비·세금·관세와 필수 조건이 확인된 경우에만 잠정 최저가를 표시합니다. 한 판매자만 있거나 비용/조건이 불명확하면 잠정 최저가를 표시하지 않습니다.
- 결과는 **검증한 비교 가능 판매처 중 잠정값**입니다. 전 세계·전체 쇼핑몰·실시간 최저가 보장이 아니며, 판매처의 최종 가격/배송·재고·반품 조건을 사용자가 확인해야 합니다.

## 광고·제휴와 추천 순서

광고/협찬·제휴 관계가 있으면 별도 `commercialApproved` 승인과 사용자에게 보이는 고지가 필요합니다. 광고/협찬 상품은 별도 광고 영역에서 구분하고 일반 추천으로 위장하지 않습니다. 광고가 아닌 제휴 상품은 관계를 구매 링크 옆에 고지하고 일반 조건 점수로만 정렬합니다. `affiliate-feed` 또는 알려진 제휴 추적 파라미터가 있는 자료는 제휴 고지가 없으면 공개 검증에서 거부합니다. 제휴 링크·광고 여부·수수료율 때문에 일반 검색의 조건 점수나 가격 비교 순서를 올리지 않습니다. 공급원의 광고 자료 이용 허가는 A1이 비용을 청구하거나 외부 유료 서비스를 켜는 승인과 별개입니다.

## 실제 상품 피팅의 선행 조건

현재 사진상 두 비율을 반영한 단순 3D와 시험 의류/로컬 도식 배치 기능은 보존하지만, 이것을 실제 판매 상품의 피팅이라고 표시하지 않습니다. 사진 한 장의 두 비율로 정확한 신체 표면·허리둘레·깊이·사이즈를 복원했다고 주장하지 않습니다.

실제 상품의 미리보기에는 검증된 상품 ID와 사용할 수 있는 의류 이미지·형상 자료가 먼저 필요합니다. 일반 공개 표시권을 이미지 합성·배경 제거·변형·AI 처리·3D 복원 권리로 확대 해석하지 않습니다. 실제 상품별 3D 메시/패턴·소재와 검증된 아바타/물리 결과가 없으면 정밀한 3D 착용·착용감 보장을 제공하지 않습니다. 자연스러운 AI 합성과 단순 2D 시각적 배치를 별도 기능으로 안내합니다.

## 최소 운영자 승인과 비용 경계

실제 상품 10개를 위한 최소 결정은 다음과 같습니다.

1. **공급원과 읽기 전용 접근:** 판매자 파일 또는 공식 API/제휴 피드 한 곳, 계정별 사용 자격·필요한 심사/약관·허용 필드·호출 한도·출처 확인.
2. **공개 표시·유지 권리:** 상품 정보·이미지를 A1에서 표시할 권리, 허용 판매/이미지 도메인, 갱신·보관·철회/삭제 조건과 검토 증빙. 승인 파일과 공개 상품 내용의 해시 확인.
3. **상업 관계가 있는 경우:** 광고·제휴 고지·추적/이미지 사용 조건과 별도 표시 승인. 일반 추천 점수 우대 없음.

외부 사진 처리, 유료 생성형 API·GPU·저장/전송, 실제 의류 이미지 변형·합성은 **후속 별도 승인**입니다. 계정·지역·계약·쿼터를 확인하지 않은 상태에서 가입비·보증금·API/GPU 단가 또는 무제한 무료 운영을 만들지 않습니다. 정확한 견적/조건과 비용 상한이 필요하며, 이번 작업은 가입·키 발급·결제·유료 호출을 활성화하지 않습니다. 고객에게 기능이 무료라는 원칙과 공급자 비용 승인 절차를 구분합니다.

## 자료 수령 이후의 순서와 일정

아래는 공급원 접근/권리 확인과 실제 자료 수령 **이후**의 개발 추정입니다. 승인 심사·공급자 응답·법률/기기 검증 대기 기간은 포함하지 않으며 서비스 완료일을 약속하지 않습니다.

| 단계 | 예상 범위 | 완료 증거 |
| --- | --- | --- |
| 한 공급원 실제 의류 10개 | 자료/권리 확보 후 2–3 작업일 | 실제 상품 사진·가격/통화·사이즈·판매처·구매 URL·출처·확인/만료 시각과 검색 결과 |
| 조건 추천·동일/유사 비교 | 그 다음 3–5 작업일 | 추천 이유·사이즈표 주의·정확한 변형 구분·미확인 비용 처리·규칙 상담 연결 |
| 실제 상품 한 개의 시각적 미리보기 | 이미지 변형권·사용 가능한 자료 확보 후 2–3 작업일 | 해당 실제 상품 이미지로 출력된 결과와 참고용 표시·동의/삭제 검증 |
| 현실적인 3D·자연스러운 AI 합성 | 모델/의류·개인정보·라이선스·비용 조건 확보 후 재산정 | 실제 렌더링/합성 품질·권리·비용·실기기 검사 |

현재는 실제 상품이 없으므로 실제 의류 검색·잠정 최저가·실제 상품 피팅의 완료를 선언하지 않습니다. main 병합·Production 배포, 운영 Firebase/DB·회원·구독 기록 변경은 별도 승인 없는 이번 작업의 범위가 아닙니다.
