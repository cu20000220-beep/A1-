# A1 FASHION 글로벌 확장 검증 보고

검증일: 2026-11-05. 대상은 기존 저장소의 `feature/global-fashion-platform` 브랜치입니다. 새 프로젝트를 만들거나 운영 회원을 삭제하지 않았습니다. 아래 결과는 로컬 검증 결과이며 운영 배포 성공을 뜻하지 않습니다.

## 구현한 기능

- 기존 한국어·영어와 디자인을 재사용한 글로벌 쇼핑, 멤버십, 가격 비교, 관심 상품, 프로모션 알림, 계정의 여섯 화면.
- 한국·미국·일본·영국·유럽 판매처 검색 연결, 배송 목적지와 KRW/USD/EUR/GBP/JPY 선택, 성별·브랜드·카테고리·스타일·가격·사이즈 검색 조건. 실제 가격 필터와 배송 가능 여부는 판매처에서 확인합니다.
- FREE/GENERAL/PREMIUM 서버 권한. 서명된 회원 인증과 현재 DB의 유효 결제 기록을 함께 검사합니다. 기존 등급 없는 유료 기록은 기존 추천 기능에 대응하는 GENERAL로 해석하며 PREMIUM으로 올리지 않습니다. 운영 이전 SQL은 승인 전 적용하지 않습니다.
- 동일 식별자·브랜드·색상·사이즈·상태 비교, 미확인 비용·품절·오래된 가격·만료된 자료·잘못된 환율의 최저가 배제. 가격·환율 출처 및 확인 시각, 프로모션 기간을 표시하는 DEMO 화면.
- 회원별 서버 관심 목록과 목표 가격, 추천 예시 찜 저장·삭제. 과거 브라우저 찜 목록을 읽거나 자동 이전하지 않습니다.
- 이메일/SMS 독립 수신 동의와 철회, 설정·연락처·이력 삭제, 모의 템플릿·이력·중복 방지. 구독 만료와 요청 한도 초과 후에도 본인 철회·삭제가 가능합니다.
- 회원 탈퇴 시 비밀번호 재확인 후 해당 회원의 글로벌 개인정보를 먼저 삭제합니다. 삭제 실패 시 Firebase 계정을 먼저 삭제하지 않습니다. 금융 구독 기록의 보관은 별도입니다.
- eBay 승인 조건 검사 어댑터와 Awin 준비 어댑터, 수동 모의 Worker, 검토용 D1 마이그레이션 두 개. 실제 전송 코드는 없는 HARD DRY_RUN입니다.

## 현재 0원 범위와 추가 비용

이번 검증은 로컬 모델·모의 상품·가짜 이벤트·로컬 DB/서명으로 실행했습니다. 실제 상품·환율·이메일·SMS 유료 API, 시험 결제·시험 문자는 호출하지 않았습니다. 준비 번역에는 번역 API 비용이 없습니다. 기존 Firebase/Cloudflare 무료 한도 안에서 기본 회원·정적 서비스 운영이 가능하지만 무제한 운영을 보장하지 않습니다.

대중화 시 요청/CPU·DB 읽기/쓰기·이력 보관, 상품/환율 공급 계약, 발송 도메인·이메일 발송량, SMS 국가·분할·번호·발신 등록, 결제 수수료와 운영/법적 검토가 비용 항목입니다. 구독료는 정하지 않았습니다. 확인된 무료 한도와 후보 비교는 [공식 자료 조사](GLOBAL-RESEARCH.md)에 있습니다.

## 실제 운영 전 남은 승인과 구현

실제 상품 비교·가격 감시에는 eBay 운영 접근 또는 Awin 퍼블리셔/광고주 승인이 필요합니다. eBay 검색 후보를 정확한 상품으로 검증하는 상세 어댑터와 Awin 피드 매핑, 허용된 이미지·저장·갱신 정책도 필요합니다. 현재 외부 연결은 검색 링크이며 실제 상품 자동 연동으로 표시하지 않습니다.

운영 데이터 매핑 시 SQL의 `*_minor` 금액을 통화별 최소 단위에서 엔진의 표시 단위로 변환해야 합니다. KRW/JPY는 0자리, USD/EUR/GBP는 2자리이며, 미확인 값을 0으로 바꾸면 안 됩니다. 프로모션 종류는 DB와 엔진의 다섯 값으로 정렬했습니다. 시각은 UTC epoch milliseconds입니다. 이 승인된 저장소/공급자 통합은 실제 수집을 시작하기 전에 별도 구현·검증합니다.

실제 알림에는 발송 도메인 인증, 검증된 수신 연락처, 동의 증빙/국가·언어 스냅샷, 서명된 간편 수신 거부, 반송·차단 처리, 국가별 광고 문안·발신 등록·개인정보 국외 이전 검토와 비용 상한이 필요합니다. 현재 모의 링크는 실제 운영 수신 거부 기능을 대신하지 않습니다. 원본 사진·체형 분석 정보는 알림 데이터에 포함하지 않습니다.

예약 Worker는 수동 구조이며 Cron, 실제 피드 갱신·운영 큐, 정해진 시각의 요약 전달과 실제 비용 원장은 설치하지 않았습니다. 지역별 연락처 인증과 운영 발송은 별도 구현 대상입니다. 실제 iPad Safari 기기와 운영 계정/발송의 검증도 로컬 Chromium 결과와 구분합니다.

운영 승인 순서는 **코드/PR 검토 → 기존 회원 GENERAL 이전 정책 → 대상 D1·백업·검토 SQL → main 병합과 기본 배포 → 공급자별 상품 연결 → 이메일/SMS 각각 승인 → 예약 실행 승인 → 가격/환불 정책 확정 후 결제 별도 승인**입니다. 세부 조건은 [운영 승인 안내](GLOBAL-OPERATIONS.md)에 있습니다. 이 작업은 운영 병합·DB 변경·결제·실제 발송을 실행하지 않습니다.
