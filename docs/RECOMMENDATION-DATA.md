# 추천 데이터와 출처

무료 추천은 확인한 상품 정보와 기기 내 체형 비율을 규칙으로 비교합니다. 소재·핏·계절·실측에서 판매처 근거가 없는 값은 미확인으로 다룹니다. 계절을 선택하면 판매처의 계절 표기와 반소매·카디건 등 확인된 특성에 근거한 코디 제안을 구분해 표시합니다.

## 사용 중인 자료

- 무신사와 29CM의 기존 공식 페이지 관측 10개를 재사용합니다. 상품별 공식 URL, 확인 시각과 판매처 표기는 `assets/observed-products.json`에 있습니다. 과거에 확인한 가격은 확인 당시 가격으로 표시하며 재고와 현재 판매가는 판매처에서 확인합니다.
- `catalog/source-review.json`은 기존 사실 관측과 검토 대상을 기록합니다. W컨셉, 네이버 쇼핑, 쿠팡, ZARA, H&M, UNIQLO, ASOS의 수집·저장·학습 권한은 미확인입니다. 공식 쇼핑몰 검색 링크는 상품 데이터 승인 근거가 아닙니다.
- `catalog/source-approvals.json`에는 승인된 상품 피드가 아직 없습니다. 새 API나 피드의 저장·표시 범위, 유효 기한과 승인 근거를 검토한 뒤 기존 가져오기 도구로 확인합니다. 상품 후보에 포함된 권한 주장은 승인 기록을 대신할 수 없습니다.

## 갱신과 검증

새 확인 가격이나 재고가 도착하면 판매처 옵션과 확인 시각을 대조해 스냅숏을 다시 검토합니다. 검토한 입력과 결과 해시를 승인 기록에 반영하며, 지난 승인 또는 만료된 값으로 거래를 추천하지 않습니다. 해당 지역의 검증된 상품이 없으면 공식 쇼핑몰 검색 링크를 제공합니다.

이번 단계는 상품 지식 검색과 규칙 기반 정렬입니다. 사진과 체형 비율은 기기 내 맞춤 추천에만 사용합니다. 별도 학습 이용 허락이 있는 데이터와 평가셋이 확보되면 학습 데이터, 범위, 성능을 검토할 수 있습니다.

`node --test tests/curated-recommendations.cjs`로 다섯 신체 비율, 계절 근거, 누락값, 가격 갱신과 출처 추적을 재현할 수 있습니다.
