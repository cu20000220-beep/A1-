# 체형 참고 검색·유니클로·사진 피팅 검토

2026-11-10 / PR #4 `feature/product-fitting-lab`. 기존 국내 검색·체형 분석·무료 상담·2D/3D 코드를 재사용했습니다. main 병합·Production 배포는 하지 않습니다.

## 판매처 연결과 상품 데이터의 구분

이번에는 상품 자료 승인을 기다리며 일반 검색 링크까지 막지 않습니다. 무신사·29CM·네이버쇼핑·쿠팡의 공식 검색과 **유니클로 한국 공식 검색창**을 연결합니다. 구매·결제는 판매처에서 진행합니다. 링크 제공과 상품 이미지/가격 수집·복제·재배포·이미지 변형 권한은 별개이며, 이번에 쇼핑몰 상품 자료를 수집하거나 복제하지 않았습니다.

유니클로의 검증된 주소는 `https://www.uniqlo.com/kr/ko/search`, 홈은 `https://www.uniqlo.com/kr/ko/`입니다. 검색어 자동 입력 매개변수는 검증되지 않아 생성하지 않습니다. **검색어 복사 → 공식 검색창에 붙여넣기** 방식으로 표시합니다. 정확한 HTTPS 호스트/경로만 허용하며 앱 브라우저·CAPTCHA·지역 제한을 우회하지 않습니다. 예산은 해석·표시하고 판매처에서 직접 필터를 설정하도록 안내합니다.

실제 공개 등록 상품은 여전히 **0개**입니다. 공식 검색 링크를 개별 상품 확보로 세지 않으며 이미지·가격·재고·실시간 최저가를 만들어 표시하지 않습니다.

## 체형에서 검색으로 이어지는 흐름

1. 사진을 기기에서 분석합니다. 결과의 **체형 분석을 참고해 옷 찾기**를 누릅니다.
2. 사진 비율을 로컬 스타일 조언에 쓰는 별도 동의를 선택하고 **조건으로 스타일 조언 받기**를 누릅니다.
3. 체형 참고 검색 제안에서 표시된 의류 종류/핏과 주의사항을 확인하고 **이 조건으로 옷 찾기**를 선택합니다.
4. 적용된 검색어를 확인한 뒤 무신사 등의 공식 검색을 직접 누릅니다. 유니클로는 검색어 복사와 공식 검색창을 사용합니다.

어깨/골반 기준점 비율과 다리/몸통 비율은 사진상 참고값입니다. 두 비율로 허리·가슴 치수나 정확한 사이즈를 추정하지 않습니다. 제안은 참고 규칙이며 사용자가 이미 지정한 색상·핏·종류·예산을 임의로 바꾸지 않습니다. 원문·원본 사진·신체 수치는 URL이나 서버로 보내지 않습니다. 검색어 변경은 사용자 선택 후에만 발생합니다. 동의 철회·분석 삭제·새 분석은 제안을 지우고 자동 적용했던 조건을 원래 검색어로 되돌립니다.

## 실제 의류 사진으로 로컬 2D 미리보기

분석 결과에서 기존 **내 사진으로 가상 피팅하기** 버튼을 누르면 시험 의류 선택 없이 사진 업로드 영역에 들어갑니다. **내 의류 사진으로 미리보기**에서 이용 권한을 확인하고 의류 사진 JPG/PNG/WebP(12MB 이하)를 선택합니다. 별도로 분석 사진 사용에 동의한 뒤 **의류 사진을 겹쳐 보기**를 누릅니다.

단순 SVG만 올리던 기존 기능에 실제 래스터 사진의 색과 질감을 사용할 수 있게 했습니다. 위치·크기·회전·투명도·착용 전후 보기·간단한 밝은 배경 제거·삭제를 지원합니다. 옷만 있는 투명 PNG가 가장 적합하며, 사람/배경이 포함된 사진은 그 부분도 겹쳐집니다. 밝은 배경 제거는 가장자리에서 연결된 밝은 픽셀만 지우는 간단한 처리이며 흰 의류에는 사용하지 않습니다.

전체 얼굴 사진과 분석 전 미리보기는 기존대로 분석 후 지웁니다. 동일한 어깨 위쪽을 자른 분석 이미지의 **기준점 선 없는 사본**만 숨긴 메모리 canvas로 유지하고 동의한 피팅 출력에 사용합니다. 원본을 서버/저장소에 보관하지 않습니다. 의류 이미지도 최대 1600px로 줄이며 임시 URL은 디코딩 직후 해제합니다. 파일 시그니처를 확인해 SVG 위장 입력을 거부합니다. 교체·동의 철회·지우기·분석 삭제·페이지 이탈과 비동기 취소를 검증합니다.

이 기능은 **실제 사진을 겹치는 2D 참고 화면**입니다. 자연스러운 AI 착용 합성, 원래 옷 제거, 팔/머리 가림, 주름 생성, 정확한 사이즈·착용감 예측은 구현하지 않았습니다. 판매 중인 의류를 자동 가져와 피팅하는 기능도 아닙니다.

## 3D 개선 범위

분리된 타원형 팔다리와 소매를 연속 표면으로 바꾸고 손·턱·넥라인·밑단을 보완했습니다. 픽셀 단위 주광/보조광/윤곽광, 천 표면과 부드러운 바닥 음영을 적용했습니다. 사진 비율 적용·수동 치수·의류 변경·회전/확대/핀치를 유지합니다. 더 부드러운 시각적 미리보기이며 실제 사람 복원·실제 상품 3D·의복 물리·실사 AI 피팅의 완성이 아닙니다.
