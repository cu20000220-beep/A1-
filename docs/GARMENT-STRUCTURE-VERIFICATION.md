# 예시 3D 의류 구조 수정

PR #4 `feature/product-fitting-lab`, 2026-11-10. 실제 상품 3D 모델·실사 피팅을 완성한 변경이 아닙니다.

## 원인과 수정 범위

기존 인체의 변형·사진 동의·터치 렌더러는 유지했습니다. 기존 상의는 몸통 타원 링과 별도 소매 튜브로 만들어 어깨와 진동선이 이어지지 않았습니다. 작은 목 타원과 장식 띠로 앞뒤 목파임을 표현했고, 몸체 단면의 최대 반경으로 폭·깊이를 함께 늘려 원통형 실루엣과 팔 관통이 생겼습니다.

`assets/avatar-geometry.js`의 정상 인체 모델 경로에서만 이 상의를 **하나의 연결된 의류 표면**으로 바꿨습니다. 이미 사용 중인 CC0 인체의 어깨·상완·몸통 토폴로지에서 범용 반소매 영역을 잘라 목·양 소맷단·밑단을 엽니다. 절단 경계 정점을 공유해 소매가 몸통에서 떨어지지 않습니다. 앞목을 뒤보다 낮게 하되 목 부위에만 파임을 적용해 어깨선을 보존합니다. 소맷단·밑단을 정렬하고 최종 표면 법선을 다시 계산했습니다. 별도 박스·튜브 장식을 덧붙이지 않았습니다.

인체와 의류가 같은 변형 정점·사진 참고 비율을 사용합니다. 신체 바깥쪽 여유와 표면 평활화를 적용하고, 좁은 몸통과 팔처럼 반대쪽 신체 표면이 가까운 곳은 여유를 제한합니다. 신체를 줄이거나 옮겨 관통을 숨기지 않습니다. 인체 자산이 없는 경우의 기존 호환용 기본 형상은 유지하며 자산 로딩 실패를 안내합니다.

화면에는 **‘예시 3D 착용 이미지’ / ‘Example 3D garment preview’**와 연구 중이라는 한계를 표시합니다. `assets/avatar-lab.js` 및 세 진입 HTML의 자산 버전만 함께 갱신했습니다. 기존 로컬 의류 사진 2D 미리보기·분석·동의·삭제는 재개발하지 않았습니다.

## 검증

- `node --test tests/avatar-geometry.cjs`: **10/10 통과**. 새 검사는 실제 삼각형에서 연결 성분 1개, 열린 경계 4개, 비정상 간선·분기·퇴화 면 없음, 목파임·어깨 보존, 유효 법선을 확인합니다. 의류 선택이 인체 정점을 바꾸지 않는지도 확인합니다.
- 기본/넓은/좁은 체형 × 의류 3종의 정점·경계·면 중심 **1,464개 표본**을 전체 인체 삼각형과 독립 비교했습니다. 처음 발견한 좁은 체형의 최대 8.5mm 관통을 보정한 후 모든 표본이 신체 밖에 있었습니다. 검사 허용 오차를 완화하지 않았습니다. 전 표면·모든 입력값의 무관통이나 자기 충돌 해결을 보장하는 검사는 아닙니다.
- `node tests/garment-structure-browser.cjs`: 한국어 820px·영어 390px 통과. 의류 3종의 실제 픽셀, 정면·측면·후면, 수동 치수·사진 비율 변경, 터치 확대·초기화, 예시 표시를 검사하고 화면을 직접 검토했습니다. 환경별 동일 출처 GET 9개, API/외부 요청 0개, JS·콘솔·CSP 오류 0개였습니다. [정확한 소스 해시와 결과](validation/garment-structure/browser-result.json)를 기록했습니다.
- `node tests/local-photo-fitting-browser.cjs`: 기존 한국어 390px·영어 820px 회귀 통과. 기기 내 실제 래스터 픽셀·별도 의류 권리/사진 동의·위치/크기/회전·전후 보기·교체/철회/취소/삭제와 외부 전송 없음 확인.
- 정적 빌드 및 공개 산출물 검사 통과. 증거 문서·화면은 공개 사이트 빌드에 포함하지 않습니다. 최신 커밋의 GitHub CI·Preview 주소는 PR #4에 기록합니다.

자동 브라우저는 Linux Chromium 터치 환경입니다. 실제 iPad Safari/ChatGPT 앱 내부 브라우저 검증으로 표현하지 않습니다.

## 남은 품질 한계와 보호 조건

범용 체형을 따라 만든 반소매 예시입니다. 실제 상품 패턴·3D 모델·원단·주름·봉제선·의복 물리·정확한 사이즈·실사 AI 합성은 구현하지 않았습니다. 극단 치수나 임의 입력에서 국소 겹침이 남을 수 있습니다. 3D를 완성된 실제 상품 피팅으로 표시하지 않고 연구 중으로 유지합니다.

모든 소비자 무료 정책과 Preview API 격리를 유지합니다. main 병합·Production 배포·운영 DB/Firebase/회원/구독 변경·유료 API·외부 사진 전송은 실행하지 않습니다. PR #4는 실제 iPad 최종 확인 전까지 미병합 상태로 유지합니다.
