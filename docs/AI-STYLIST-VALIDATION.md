## 이번에 구현한 기능

한국어·영어 스타일 상담 화면, 남성·여성·유니섹스 컬렉션, 취향·상품당 예산·카테고리·통화·배송 국가 선택과 짧은 대화 문맥을 지원합니다. 준비 번역과 별도 서버 조언 사전으로 다른 언어를 추가할 수 있는 구조를 유지했습니다. 기존 무료 분석에서 상담 창을 열면 원본 사진 대신 검증된 비율 두 숫자만 일회성 메모리 메시지로 가져옵니다. 수치를 실제 상담에 포함할 동의와 외부 AI 전송 동의는 자동 선택하지 않습니다.

GENERAL은 스타일 상담과 판매처 검색, PREMIUM은 검증된 동일 변형의 가격 비교와 현재 할인 정보에 접근합니다. 서명된 인증과 유효한 서버 구독 행을 확인하고, GPT 호출 직전 및 응답 후에도 권한을 다시 확인합니다. 무료 가입·브라우저 플래그·채팅 속 “프리미엄 회원” 주장은 권한이 아닙니다.

GPT는 주제·허용된 스타일 조언·검증된 상품 ID를 고르는 계획 계층입니다. 화면의 상담 문구는 검토한 조언에서 조립하며 상품·가격·할인·URL은 공식 서버 자료에서만 가져옵니다. 자유롭게 상품이나 가격을 만들어 말하는 범용 챗봇이 아닙니다. 모델이 알려지지 않은 상품이나 임의 가격/링크 필드를 내보내면 답변을 거부합니다. 상품 자료가 없을 때는 가상의 상품 대신 데이터 준비 상태와 쇼핑몰 검색 링크를 안내합니다.

기존 D1의 승인된 공식 상품을 읽는 어댑터는 상품 식별자·색상·사이즈·상태·재고·배송·약관·출처·보관 기한을 검증합니다. 통화 최소 단위를 올바르게 변환하고, 미확인 비용은 null로 남깁니다. AI 조회에서는 확인된 동일 통화만 사용하며 임의 환율을 만들지 않습니다. 응답 대기 중 만료된 상품·할인은 최신 조회로 다시 검사합니다. 신규 공식 피드 수집·제휴 승인 자체를 완료한 것은 아닙니다.

OpenAI Responses 호출은 Cloudflare Pages Functions 서버에만 있으며, 기본값은 비용 없는 규칙 기반 DEMO입니다. 실제 호출은 명시적인 서버 승인, 고정 모델·서버 Secret, 양수 예산·이용 한도, 검토된 D1 테이블/트리거, 유효 구독과 해당 요청의 외부 AI 동의가 모두 필요합니다. API 키만 입력해 활성화되지 않습니다.

요청 전에 비용을 원자적으로 예약하고 사용자별 일일 횟수·전체 일/월 상한을 검사합니다. 최대 출력 600토큰·외부 대기 12초이며 자동 재시도·외부 도구·이미지·다른 모델 fallback이 없습니다. 실패·시간 초과·잘못된 응답도 예약 비용을 돌려주지 않습니다. 사용 기록에는 해시 식별자·집계만 저장하고 대화·분석값을 저장하지 않습니다. 탈퇴 시 본인 AI 기록을 삭제하고 익명 전체 비용 합계는 보존합니다.

## 운영비와 남은 승인

현재 검증은 **GPT 비용 0원**이며 실제 상품·결제·알림 API를 활성화하지 않았습니다. 현재 OpenAI 가격 페이지는 개발 환경의 접속 제한으로 검증하지 못했습니다. 입력 100만 토큰 US$0.40·출력 US$1.60, 상담당 2,000/500토큰이라는 **계산 가정**에서는 1,000회가 US$1.60입니다. 현재 공식 단가나 실제 상담 토큰을 확인한 견적이 아니며 세금·환전·Cloudflare/D1·상품 피드 비용은 별도입니다. 비용 예약은 이 평균보다 보수적입니다.

실제 운영 전에는 고정 모델의 계정 사용 가능 여부와 최신 단가, API 별도 청구·월/일 한도, 서버 Secret, 대상 D1 백업과 `0004_ai_stylist_usage.sql`, 외부 처리·보관/삭제·동의 문안, 공급자별 상품 사용 및 외부 AI 가공 권한을 승인해야 합니다. `store:false`는 공급자 전체 보관을 0일로 만드는 보장이 아닙니다. 실제 GPT 품질·현재 요금·계약·무료 인프라 CPU 한도는 승인된 소량 시험에서 추가 확인합니다.

승인 순서와 정확한 서버 설정 이름, 비용 계산·중단 방법은 [운영비·활성화 안내](AI-STYLIST-OPERATIONS.md)에 정리했습니다. 이번 작업으로 운영 배포·회원 이전·DB 마이그레이션·실제 GPT·이메일/SMS·정기 청구를 시작하지 않습니다.
