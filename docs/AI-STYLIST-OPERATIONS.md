# A1 AI 스타일리스트: 운영비와 활성화 승인

조사일: 2026-11-05. 기존 A1 FASHION 저장소·Cloudflare Pages·Firebase 회원 식별자를 유지하는 확장입니다. 새 인증 프로젝트, 운영 회원 이전·삭제, 실제 결제, 시험 GPT 호출을 시작하는 작업이 아닙니다. 이 문서는 현재 준비 범위와 운영자가 승인해야 할 사항을 구분합니다.

## 기본 운영 상태

2026-11-07 자체 AI 검토 브랜치는 [A1 자체 AI 보고서](A1-OWNED-AI.md)의 학습형 질문 분류·추천 엔진을 기본으로 사용합니다. 아래 GPT 운영 절차는 보존된 외부 API 경로에 대한 안내입니다. 실제 GPT를 선택하려면 서버에서 `A1_STYLIST_ENGINE=openai`를 추가로 지정해야 하며, 이 값만으로 기존 승인·예산·동의 검사를 통과하지 않습니다. 합성 예제로 학습한 자체 엔진은 시험 버전이고 실사용 성능 검증이나 무료 회원 권한 확대를 의미하지 않습니다.

실제 GPT API 호출은 기본 비활성화합니다. API 키가 없거나 승인·비용·사용량 설정이 준비되지 않아도 기존 무료 사이트와 기기 내 사진 분석은 계속 작동해야 합니다. 모의 답변은 DEMO로 표시하며, 실제 GPT가 응답한 것처럼 안내하지 않습니다. 무료 체형 분석과 GPT 상담의 이용 권한도 구분합니다.

GENERAL은 유효한 서버 구독 기록이 있을 때 스타일 상담과 허용된 쇼핑몰 검색 연결을 이용합니다. PREMIUM은 가격 비교·확인된 할인 추천을 추가로 이용합니다. 브라우저 값이나 이전의 성공 응답, 메시지에서 주장한 구독 등급은 권한 근거가 아닙니다. 매 요청에서 기존 Firebase 인증과 현재 구독 기록을 검사하고, FREE·만료·환불·미납·취소 또는 결제 확인 없는 계정은 유료 API에서 거부합니다.

## GPT가 담당하는 범위

GPT는 사용자 질문과 허용된 취향 정보를 바탕으로 스타일 상담의 주제·조언·검증된 상품 식별자를 선택합니다. 화면의 상품명·가격·할인율·판매 URL을 모델이 자유롭게 만들어 내도록 맡기지 않습니다. 구조화된 출력과 서버 검증을 함께 사용하며, 서버가 보유한 허용 목록 밖의 식별자나 필드를 반환하면 결과를 거부합니다. 모델에 보이는 상품 문구와 사용자 메시지도 신뢰할 수 없는 데이터이며, 시스템 지시나 권한 변경으로 취급하지 않습니다.

상품 카드와 할인 정보는 공식 API/피드의 검증된 서버 자료에서 조립합니다. 자료에는 출처·갱신 시각·유효기간·통화·상품 변형이 있어야 합니다. 유사 디자인, 다른 색상·사이즈·상태를 같은 상품의 최저가로 묶지 않습니다. 가격·배송비·세금·환율이 불명확하면 확인 불가로 표시하고 0원으로 대체하지 않습니다. 자료가 없을 때는 “검증된 상품 데이터 준비 중”으로 안내하고, 검색 링크는 개별 상품 자동 연동과 구분합니다.

현재 AI 상품 조회는 선택한 통화로 확인된 상품만 읽습니다. 다른 통화의 상품을 임의 환산하지 않으며, 실제 환율 공급원 승인·연결 전에는 국가 간 환산 비교를 보장하지 않습니다. GPT를 기다리는 중 구독·가격·재고·프로모션·보관 유효기간이 바뀔 수 있으므로 응답 직전에 권한과 상품 자료를 다시 확인합니다. 만료된 선택을 다른 가짜 상품으로 교체하지 않습니다.

기존 참고용 의류 예시나 DEMO 가격은 실제 재고·가격의 근거가 아닙니다. 상품 공급자 승인 없이 수집·크롤링하지 않습니다. eBay 운영 접근, Awin 퍼블리셔/광고주 승인과 정확한 피드 매핑·이미지/보관/갱신 조건은 [글로벌 연동 조사](GLOBAL-RESEARCH.md)의 별도 승인 대상입니다. GPT 연결 승인이 상품 피드 이용 승인을 대신하지 않습니다.

공급자별 계약이 상품 문구·가격을 외부 AI 입력으로 제공하고 가공하는 사용까지 허용하는지도 확인해야 합니다. 사이트 표시·이미지 재사용 승인을 외부 AI 처리 허용으로 확대 해석하지 않습니다. `A1_AI_CATALOG_APPROVED`는 해당 범위의 공급자·데이터를 운영자가 검토한 뒤에만 설정합니다.

스타일 조언은 의학적 체형 판정, 정확한 신체 치수나 실제 옷 사이즈·착용 적합성의 보장이 아닙니다. 이번 구성은 기존 GPT 모델을 안전하게 사용하는 상담 계층이며, 자체 대규모 모델 학습·파인튜닝을 완료했다는 의미가 아닙니다.

## 확인한 OpenAI 인터페이스

공식 `openai-node` 저장소의 조사 당시 커밋 [`5b12ca825dea1b151a0924843456b2f012c46bfb`](https://github.com/openai/openai-node/tree/5b12ca825dea1b151a0924843456b2f012c46bfb)를 직접 읽었습니다. SDK를 설치하거나 실제 OpenAI 서비스에 요청하지 않았습니다.

| 항목 | 공식 소스에서 확인한 사실 | A1 적용 원칙 |
| --- | --- | --- |
| Responses API | 공식 SDK는 `POST /v1/responses`를 사용하고 Responses를 주요 API로 설명합니다. | Pages Functions의 서버 어댑터가 고정된 OpenAI HTTPS 엔드포인트만 호출합니다. 임의 URL·브라우저 직접 호출을 허용하지 않습니다. |
| Structured Outputs | `text.format`에 `type: 'json_schema'`, `name`, `schema`, `strict: true`를 지정할 수 있습니다. | 허용된 조언/상품 식별자만 받는 제한된 구조를 사용하고 서버에서도 다시 검증합니다. 스키마 지원은 사실의 정확성을 자동 보증하지 않습니다. |
| 응답 저장 | `store`를 생략하면 기본값은 true이며, 명시적으로 false를 지정할 수 있습니다. | `store: false`를 명시합니다. 이 값만으로 모든 공급자 보관·로그가 0일이 된다고 설명하지 않습니다. |
| 출력 상한 | `max_output_tokens`는 보이는 출력과 reasoning token을 포함합니다. | 짧은 출력 상한을 지정하고, 이 전체 상한을 비용 예약에 포함합니다. 도구 호출과 이미지·파일 입력은 사용하지 않습니다. |
| 재시도·시간 제한 | SDK는 기본 2회 재시도와 10분 제한을 설명합니다. 시간 초과도 기본 재시도 대상입니다. | SDK를 쓰면 `maxRetries: 0`과 짧은 timeout을 명시합니다. 직접 fetch 어댑터도 자동 재시도·리다이렉트를 금지하고 AbortController로 제한합니다. |
| 사용량 | 응답은 `usage.input_tokens`, `usage.output_tokens`, `usage.total_tokens`를 제공합니다. | 실제 사용량을 검증하되, 사용량 누락·시간 초과·잘못된 응답을 비용 0으로 처리하지 않습니다. |

직접 확인한 소스는 [README](https://github.com/openai/openai-node/blob/5b12ca825dea1b151a0924843456b2f012c46bfb/README.md), [Responses 타입과 경로](https://github.com/openai/openai-node/blob/5b12ca825dea1b151a0924843456b2f012c46bfb/src/resources/responses/responses.ts), [공유 모델 타입](https://github.com/openai/openai-node/blob/5b12ca825dea1b151a0924843456b2f012c46bfb/src/resources/shared.ts)입니다. 이 소스의 모델 목록에 `gpt-4.1-mini-2025-04-14`, `gpt-5-mini-2025-08-07` 등이 있지만, 목록에 있다는 이유만으로 현재 운영 계정의 사용 가능 여부·가격·품질을 보장하지 않습니다.

저비용 후보는 고정 버전의 소형 모델부터 검토하되, 정확한 허용 모델은 서버 코드와 승인 기록을 맞춰 정합니다. 별칭이 자동으로 다른 모델을 가리키거나 더 비싼 모델로 fallback하지 않도록 합니다. 모델·요금·출력 상한을 바꾸면 예산 예약과 회귀 테스트도 다시 검토합니다.

## 예상 API 운영비

현재 작업 환경은 `openai.com` 등 OpenAI 문서/가격 호스트의 직접 접속을 차단합니다. [공식 가격 페이지](https://openai.com/api/pricing/) 요청은 네트워크 정책의 403으로 실패했으며, 우회하지 않았습니다. 따라서 **현재 공식 단가를 확인한 견적은 아직 없습니다.** 아래 숫자는 예산 계산 방법을 설명하기 위한 가정이며, 특정 모델의 현재 판매 가격이나 승인된 운영 설정이 아닙니다.

일반 텍스트 요청의 기본 계산식은 다음과 같습니다.

`월 예상 API 비용(USD) = 요청 수 × (평균 입력 토큰 × 입력 100만 토큰 단가 + 평균 출력 토큰 × 출력 100만 토큰 단가) ÷ 1,000,000`

입력에는 시스템 지시, 대화 문맥, 사용자 취향, 허용된 분석 수치와 상품 근거 자료가 모두 포함됩니다. 출력에는 과금 대상 reasoning token이 포함될 수 있습니다. 캐시 할인·무료 크레딧·Batch 할인을 당연히 받을 것으로 계산하지 않습니다. 세금·환전·인프라·상품 피드 비용도 별도입니다.

**계산 가정:** 입력 100만 토큰당 US$0.40, 출력 100만 토큰당 US$1.60, 요청당 입력 2,000토큰·출력 500토큰. 이 단가는 현재 공식 요금을 검증한 값이 아니라 예시입니다.

| 월 상담 요청 | 위 가정의 API 비용 | 별도 조건 |
| --- | --- | --- |
| 1,000회 | US$1.60 | 동일한 평균 토큰 가정, 세금·인프라 제외 |
| 10,000회 | US$16.00 | 상담 길이·상품 근거 수가 늘면 증가 |
| 100,000회 | US$160.00 | 서버·DB·공급자 한도와 운영 비용도 재검토 |

실제 첫 운영 예산은 이 표를 그대로 적용하지 않습니다. 운영자가 선택한 모델의 최신 공식 단가와 계정의 지역·서비스 등급·과금 조건을 확인한 뒤, 소수 사용자의 실제 토큰 측정치를 기준으로 다시 산정해야 합니다. ChatGPT 개인 구독료와 OpenAI API 사용료는 별도이며, ChatGPT 유료 계정이 API 호출 비용을 포함한다고 가정하지 않습니다.

## 비용 상한과 장애 처리

실제 호출 전 서버는 입력 전체의 보수적인 상한과 최대 출력 토큰을 기준으로 비용을 먼저 예약합니다. 회원별 일일 요청 수, 서비스 전체 일일·월간 비용 상한을 원자적으로 검사하며 여러 동시 요청이 같은 남은 예산을 중복 소비하지 못하게 합니다. 요금·상한이 없거나 0이면 실제 호출을 허용하지 않는 것이 기본값입니다. API 키의 존재만으로 활성화하지 않습니다.

시간 초과·네트워크 오류·429·5xx·출력 형식 오류는 공급자에서 이미 처리·과금됐을 가능성이 있으므로 예약한 비용을 자동 반환하지 않습니다. 알려진 사용량이 적더라도 초기에 예약액을 보수적으로 유지할 수 있으며, 이는 화면에 보이는 평균 예상 비용보다 더 빨리 A1 한도가 소진될 수 있다는 뜻입니다. 정확한 공급자 청구서와 A1 내부 제한의 역할을 구분합니다.

OpenAI 프로젝트 예산/알림은 A1 서버의 동시성 안전한 차단 장치를 대신하지 않습니다. 공급자에서 제공하는 실제 제한의 성격과 적용 시점도 계정 소유자가 확인해야 합니다. 원시 오류, API 키, 인증 헤더·대화·회원 정보는 사용자 응답과 로그에 노출하지 않습니다. 모델 거절·중단·비정상/과대 응답은 안전한 안내로 처리하고 다른 유료 모델로 자동 재시도하지 않습니다.

## 사진·분석·대화 개인정보

이번 채팅은 사진 업로드 API를 만들지 않습니다. 이미지 URL·파일·base64·원본 사진·인체 기준점 전체를 GPT 요청에 넣지 않습니다. 무료 사진 분석은 기존처럼 기기 안에서 실행합니다. 사용자가 수치 공유에 별도로 동의한 경우에만 제한된 참고 비율과 취향·예산을 사용할 수 있으며, 공유하지 않아도 분석 결과는 무료로 볼 수 있습니다.

자유 입력의 URL도 전송 전에 거부합니다. 상품 링크를 붙여 넣어 승인되지 않은 자료를 조회하는 기능은 제공하지 않으며, 찾는 옷을 글로 설명하거나 국가·컬렉션·카테고리 조건을 고릅니다. 기존 분석 화면과 상담 화면 사이에는 같은 출처·지정 창·일회성 난수로 확인한 연결을 통해 두 숫자만 메모리로 전달합니다. 사진·비율을 URL이나 브라우저 저장소에 넣지 않고, 상담에 사용할 동의를 자동 선택하지 않습니다.

외부 AI에 상담 텍스트를 전달하는 동의와 체형 참고 수치를 함께 전달하는 동의는 별도이며 기본값은 꺼짐입니다. 동의한 이후에도 보낼 정보의 범위를 알려야 합니다. 회원 DB의 이메일·사용자 ID·비밀번호·인증 토큰을 모델 프롬프트에 붙이지 않습니다. 다만 사용자가 자유 입력에 직접 적은 연락처·주소·민감정보가 저절로 제거되는 것은 아니므로 비밀번호·연락처 등을 쓰지 않도록 안내하고 입력 검증을 적용합니다.

A1은 상담 원문·수치·상품 근거 프롬프트를 사용량 집계용 DB에 저장하지 않습니다. 브라우저 대화는 메모리에만 보관하고 지우기·로그아웃·페이지 이탈 시 해제합니다. 서버 사용량 기록에 필요한 회원 식별자는 해시 등 최소 정보로 제한하며, 삭제 요청과 거래/예산 남용 방지에 필요한 최소 기록 보관 기준을 운영 전에 확정합니다.

회원 탈퇴는 기존 비밀번호 재확인 이후 본인에게 연결된 AI 사용 예약·집계도 삭제하며, 다른 회원과 익명 서비스 전체 비용 합계는 유지합니다. 이 삭제에 실패하면 Firebase 계정을 먼저 없애지 않습니다. 동의를 끄거나 대화를 지우면 화면 요청과 메모리를 정리하지만, 이미 외부로 전송된 요청을 회수하거나 발생한 공급자 비용을 취소할 수 있다는 뜻은 아닙니다.

## 승인 이후 설정할 서버 값

다음은 적용 계획이며 현재 운영에 입력하거나 활성화한 설정이 아닙니다. 키를 정적 빌드 변수로 공개하지 않습니다.

| 서버 설정 | 조건과 기본 상태 |
| --- | --- |
| `OPENAI_API_KEY` | Cloudflare 서버 Secret 전용. 키만 있어도 호출되지 않습니다. |
| `A1_STYLIST_ENGINE` | 기본은 A1 자체 엔진. `openai`를 명시해야 아래 GPT 활성화 조건을 검토합니다. 운영 승인 전 변경하지 않습니다. |
| `A1_AI_MODE`, `A1_AI_LIVE_APPROVED` | 각각 `live`, `true`가 명시되어야 실제 호출 후보가 됩니다. 기본은 DEMO입니다. |
| `A1_AI_MODEL` | 현재 허용된 고정 버전은 `gpt-4.1-mini-2025-04-14`입니다. 계정 사용 가능 여부·요금 확인과 승인 전 설정하지 않습니다. |
| `A1_AI_DAILY_USER_LIMIT` | 회원별 UTC 일일 실제 요청 예약 수. 기본 0. |
| `A1_AI_DAILY_BUDGET_MICRO_USD`, `A1_AI_MONTHLY_BUDGET_MICRO_USD` | 서비스 전체 UTC 일/월 예약 비용 상한. 기본 0. 1 USD는 1,000,000 micro-USD입니다. |
| `A1_AI_INPUT_MICRO_USD_PER_MILLION_TOKENS`, `A1_AI_OUTPUT_MICRO_USD_PER_MILLION_TOKENS` | 운영자가 검증한 해당 모델의 100만 토큰당 요금을 micro-USD 정수로 입력합니다. 임의 기본 단가가 없습니다. |
| `MEMBERSHIP_DB` | 기존 D1 바인딩을 유지합니다. 검토용 `0004_ai_stylist_usage.sql`의 테이블과 원자적 집계 트리거가 모두 있어야 비용 예약이 가능합니다. 운영 적용은 별도 승인입니다. |
| `ENABLE_LIVE_CATALOG`, `GLOBAL_CATALOG_APPROVED`, `A1_AI_CATALOG_APPROVED` | 세 값 모두 `true`여야 기존 D1의 승인된 공식 상품을 AI 근거로 읽습니다. 이 설정이 상품 피드 수집 작업이나 제휴 승인을 만들어 주지는 않습니다. |

실제 요청에는 검증된 구독과 외부 AI 전송 동의가 추가로 필요합니다. 출력 상한은 600토큰, 외부 대기는 최대 12초이며 자동 재시도는 없습니다. 입력 전체의 UTF-8 바이트와 추가 여유분으로 보수적 비용을 예약합니다. 이 한도는 요청을 예약한 UTC 날짜를 기준으로 하며 공급자 청구서의 세금·환전·정산 시점과 구분합니다. 무료 모의 상담도 기존 회원별 시간당 요청 제한을 받지만 OpenAI 비용 예약·호출은 하지 않습니다.

`store: false`는 Responses 응답의 재조회 저장을 끄는 설정입니다. OpenAI의 오남용 모니터링·로그·법적 보관, 국외 처리, 처리자 계약과 별도 보관 정책 전체를 없애는 설정이라고 해석하지 않습니다. [공식 데이터 안내](https://developers.openai.com/api/docs/guides/your-data)와 실제 계약에서 보관·삭제·데이터 이용·국외 이전, 적용 가능한 ZDR/지역 처리 자격을 운영자가 검토해야 합니다. 이번 환경에서 해당 정책 페이지의 최신 전체 내용이나 계정의 특약을 직접 검증하지 않았습니다.

## 기존 무료 운영과 추가 비용

키 없는 정적 사이트, 기존 회원가입·기기 내 분석, 준비된 번역, DEMO 상담과 로컬 테스트에는 GPT 사용료가 발생하지 않습니다. 이것이 기존 인프라나 실제 회원 서비스의 무제한 무료 사용을 뜻하지는 않습니다. Cloudflare/Firebase의 실제 무료 한도는 별도로 적용됩니다.

Cloudflare 무료 Worker/Functions의 CPU 예산은 기존 [공식 조사](GLOBAL-RESEARCH.md)에 정리되어 있습니다. GPT 응답 대기 시간과 CPU 시간은 구분되며, RSA 검증·프롬프트 구성·상품 필터·JSON 검사·해시에 드는 CPU와 D1 읽기/쓰기·저장량을 실제 Preview에서 측정해야 합니다. 로컬 workerd 테스트 성공은 무료 CPU 한도 내 운영을 보장하지 않습니다. 초과 시 기능·배치/자료 크기를 줄이거나 유료 플랜을 별도 승인합니다.

규모가 커지면 OpenAI 토큰, Cloudflare 요청/CPU와 D1 사용량, 공식 상품 피드·환율 계약, 관측/보안·운영 인력이 비용 항목입니다. GPT 상담 승인으로 이메일·SMS·정기 결제·제휴 유료 서비스를 활성화하지 않습니다. 기존 알림과 결제는 각각의 승인 상태를 유지합니다.

## 실제 GPT 활성화를 위한 정확한 승인 단계

1. **코드와 모의 기능 검토:** PR의 채팅 화면, 권한·개인정보·환각/주입 방어·예산 동시성·장애 테스트와 기존 로그인/분석 회귀 결과를 확인합니다. 이 단계에서는 실제 호출을 하지 않습니다.
2. **모델과 단가 승인:** 계정에서 사용 가능한 정확한 모델 버전, 최신 공식 입력/출력 단가, 과금되는 토큰·서비스 등급·도구 비용과 API 별도 청구를 확인합니다. 허용되지 않은 모델 fallback은 켜지 않습니다.
3. **예산과 키 승인:** 회원별 일일 횟수, 서비스 전체 일일·월간 상한, 입력/출력 크기·예약 기준·오류 시 예약 유지 정책을 승인합니다. 최소 권한의 프로젝트 키는 Cloudflare 서버 Secret에만 등록합니다. 키를 GitHub·브라우저·채팅에 붙여 넣지 않습니다.
4. **DB 변경 승인:** 기존 운영 DB와 회원을 유지한 채 대상 DB·백업/복구·검토된 사용량 SQL을 승인합니다. 로컬 검증과 운영 적용은 구분하고 자동 마이그레이션을 하지 않습니다.
5. **데이터와 개인정보 승인:** 텍스트·수치의 각각의 동의 문안, 국외 처리·보관/삭제 조건을 확인합니다. 실제 상품 추천을 켜려면 공급자·제휴·이미지·가격 갱신 조건도 별도로 승인합니다. 상품 자료가 없으면 상품을 만들어 내지 않습니다.
6. **제한된 운영 검증 승인:** 먼저 키 없는 Preview에서 기존 기능·DEMO·오류 처리를 확인합니다. 실제 시험 호출을 하려면 대상 환경·최대 횟수·비용·중단 방법을 명시한 별도 승인을 받습니다. 모의 테스트의 통과를 실제 과금 호출 승인으로 해석하지 않습니다.
7. **실제 호출 활성화 승인:** 위 조건이 모두 충족된 뒤에만 별도의 서버 활성화 상태를 켭니다. 운영자는 사용량·실제 요금·차단/오류 비율을 확인하고 즉시 비활성화할 수 있어야 합니다. 키 입력만으로 호출이 시작되지 않도록 합니다.

운영자의 현재 요청은 기능·테스트·비용 보고와 PR 제출까지입니다. **실제 GPT 호출, 실제 결제·문자·이메일, 운영 DB 적용과 운영 배포를 실행한 상태가 아닙니다.**
