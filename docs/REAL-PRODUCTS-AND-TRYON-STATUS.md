# 실제 상품 연결과 피팅의 현재 상태

2026-11-17, PR #4 `feature/product-fitting-lab`. 시작점 `6ad6908`.

## 사용자에게 보이지 않던 실제 원인

1. 공개 승인 피드 `approved-products.json`과 공급원 승인 목록은 각각 0개다. 버튼만으로 상품을 만들 수 없으며 이 목록을 가짜 자료로 채우지 않는다.
2. `product-lab.js`의 분석 후 추천은 `fixtures ? rank(...) : []`였다. 실제 승인 자료가 들어와도 이 경로에는 나오지 않았다. 기존 카탈로그 검증·검색·점수·사유·광고 분리·비교를 연결했다. 허가된 상품 이미지는 기존 `A1CatalogFitting.open(id)`를 거쳐 동일 사진의 로컬 2D로 전달한다.
3. 스타일 스튜디오는 상품 카탈로그·비교·선택 이미지 피팅 모듈을 로드하지 않았다. 의존성 순서를 수정했다. 검토된 상품 이미지 출처만 두 연구실의 `img-src`에 전달하며 외부 script/connect/API는 허용하지 않는다.
4. “3D 아바타에서 시험 의류 보기”는 의류 ID를 적용하지 않고 기본 GLB만 열었다. 현재 샘플에 없는 호환 의류를 입힌다고 안내하던 문구를 `3D 샘플 · 선택한 의류 미적용`으로 바로잡았다.
5. 정상 상품 상세 URL도 기존 Preview의 일반 쇼핑 검색 전용 클릭 보호가 막았다. 검증된 컴포넌트 안의 상품 링크만 자체적인 정확한 URL·현재 스냅샷·실제 클릭 검사에 맡긴다. 임의 도메인·변조 URL·합성 클릭을 허용하지 않는다.

## 지금 실제로 추가한 상품 자료

무신사·29CM·유니클로 한국의 **실제 공식 상품 페이지 후보 10개**를 수동 열람한 공개 사실·개별 링크로 기록했다. 승인 피드 상품이나 이미지 라이선스로 위장하지 않는다.

- [공개 자료](../assets/observed-products.json): 상품명·브랜드·표시된 사이즈·확인 시각·출처·개별 상품 URL. 정가 등 관측 가격 4개, 현재 가격 미확인 6개.
- 자료 갱신 표기가 오래됐거나 가격이 노출되지 않은 경우 현재 가격을 `null`로 둔다. 과거 인덱스 가격을 현재 가격으로 채우지 않는다. 할인 자격이 불명확하면 할인 최저가를 보장하지 않는다.
- 옵션별 재고는 10개 모두 `unknown`이다. 판매 중지 페이지로 이동한 별도 후보는 제외했다. “판매 중인 10개를 실시간 보증했다”는 뜻이 아니다.
- 외부 상품 사진 복제 0개, 피팅 이미지 이용권 확인 0개다. `imageUrl:null`, 이미지·피팅 권한은 `unverified`이며 실제 의류 사진인 것처럼 그린 도식을 넣지 않는다.
- 이 자료는 승인 상품 피드와 별도로 메인 검색·무료 규칙 상담·사진 분석 후 추천에서 표시한다. 가격 미확인은 예산 충족 미확정 영역에 분리한다. 다른 통화로 임의 환산하거나 서로 다른 상품을 동일 상품 최저가로 비교하지 않는다.
- 비율 사용 동의 후 기존 `A1ShoppingQuery.bodySuggestions`의 종류·핏 조건을 사용자가 선택하면 실제 관측 상품 후보를 다시 필터링한다. 사진 수치·신체 치수는 구매 URL로 전송하지 않으며 정확한 사이즈/착용 성공 확률을 만들지 않는다.
- 구매는 상품 상세 페이지로 직접 연결한다. 앱 내 브라우저에서 판매처가 제한하면 상품 링크 복사와 Safari 안내를 제공한다. 보안 제한·CAPTCHA를 우회하지 않는다.

이것은 수동 확인한 제한된 상품 후보 묶음이다. 전체 쇼핑몰 실시간 수집·자동 가격 갱신·승인 API 피드가 연결된 것으로 표현하지 않는다. 자동 갱신/Cron은 켜지 않았다.

## 피팅: 작동하는 부분과 미완료 부분

| 기능 | 실제 상태 |
| --- | --- |
| 승인된 이미지의 상품 선택 → 기존 분석 사진 2D | 연결 오류 수정. 이용권·재고·만료·CORS·개인 사진 별도 동의 후 기존 엔진 사용. 비공개 승인 응답 fixture로 실제 픽셀·비교·삭제 검증 |
| 관측 상품 후보 10개의 자동 피팅 | 미지원. 이 자료에는 피팅용 이미지·권리 확인이 없어 피팅 버튼이나 결과를 만들지 않음 |
| 기기의 의류 사진 → 로컬 2D | 기존 기능 유지. 사진 전체를 겹치므로 사람·배경이 포함된 사진은 그 부분도 겹침. 자연스러운 착용 합성이 아님 |
| 기본 GLB → 선택한 실제 상품 3D 착용 | 미지원. 실제 상품 GLB·rig·체형 대응 의류가 없음 |
| 업로드한 사람과 같은 실사 3D 아바타 생성 | 미구현. 기본 GLB는 별도 stock 인체이며 사진의 사람으로 생성한 것이 아님 |
| 실제 사진 기반 AI 착용 합성 | **미활성·미검증, 실제 호출 0건** |

`server/virtual-tryon.mjs`에 공식 FASHN v1.6의 서버 전용 연결부를 준비했다. 기본 비활성, 실제 비밀키·명시적 모드/승인·유한한 비용 한도·사진 당사자의 외부 처리 동의·의류 이용권이 모두 없으면 요청하지 않는다. 한 번에 한 출력, 동일 처리기의 동시 예산 예약, POST 자동 재시도 금지, 시간/응답 크기 제한, 고정 제공사 호스트, 오류·키·사진 로그 방지, base64 결과만 수용하는 검사를 추가했다.

**이 코드는 공개 AI 피팅 기능의 완성이 아니다.** 현재 UI나 Preview API에 공개 엔드포인트를 연결하지 않았다. 예산 예약은 단일 처리기 안에서만 원자적이며 공개 운영에는 영속적인 계정/전체 예산 통제와 사용자별 권한·동의 검증이 더 필요하다. 원본 얼굴 사진은 기존 분석 후 폐기 정책을 유지한다. 얼굴까지 사용하는 새 외부 처리를 제공하려면 그 목적·수신자·수명에 대한 별도 동의와 입력 설계를 먼저 적용해야 한다.

공식 문서 확인:

- [FASHN API 설정](https://docs.fashn.ai/getting-started/api-setup)
- [v1.6 API](https://docs.fashn.ai/api-reference/tryon-v1-6)
- [요금](https://help.fashn.ai/plans-and-pricing/api-pricing): 기본 v1.6 1출력 약 $0.075, API 최소 구매 안내 $7.50/100크레딧. 다른 모델의 비용은 같다고 가정하지 않음
- [보관·개인정보](https://docs.fashn.ai/api-overview/data-retention-privacy): base64 출력도 무보관이 아니다. 요청 기록이 자동 삭제되지 않는 조건까지 사용자에게 고지해야 함

현재 `FASHN_API_KEY`가 없으며, API 루트의 무인증 HEAD 연결 1회가 환경 관리형 프록시의 **CONNECT 403**으로 차단됐다. 우회/반복 호출하지 않았다. 실제 계정의 키(환경 Secret), `api.fashn.ai` 네트워크 허용 설정, 시험 총 예산이 필요하다. 운영자의 일반 허가만으로 계정·키·네트워크 설정이나 이용자 각자의 사진 동의가 생성되지는 않는다. 결제·계정 가입·크레딧 구매·실제 AI 호출은 하지 않았다.

## 검증 범위와 출시 판단

전체 오프라인 단위·권한·개인정보·비용 통제 검사는 **346개**다. FASHN 검사는 모의 응답으로만 실행하며 실제 합성 품질이나 제공사 연결 성공을 뜻하지 않는다.

- `tests/product-discovery-flow-browser.cjs`: 메인/상담 한국어·영어 모바일, 실제 공개 후보 10개, 가격 미확인 분리·필터·빈 자료·재시도·삭제 경합·정확한 상품 URL 및 복사/Safari 대안.
- `tests/product-lab-catalog-browser.cjs`: 세 진입점의 승인 응답 fixture로 사진·추천·이유·비교·선택 이미지 2D·동의/권한/만료/삭제를 검증. 실제 공개 관측 후보의 동의 기반 체형 참고 조건 적용도 별도 검사.
- [실제 상품 후보 화면](validation/real-products/official-product-candidates.png), [체형 참고 조건 후보 화면](validation/real-products/body-reference-candidates.png). 승인 fixture 사진을 실제 상품 피팅 결과로 발표하지 않는다.

브라우저는 Linux Chromium 터치 모사다. 실제 iPad Safari·판매처 서버의 구매 성공·실제 AI 합성은 미검증이다. Preview URL·최신 커밋·GitHub CI는 PR #4에 기록한다. **전체 의류 추천+실사 AI/3D 피팅 서비스 출시는 NO-GO**이며, 현재 결과를 그 서비스의 완성이라고 보고하지 않는다.

모든 소비자 무료 베타를 유지한다. main 병합·Production 배포·운영 Firebase/DB/회원/구독 데이터 변경·운영 환경 변수 변경·유료 API 활성화를 하지 않는다. Preview API503 보호는 그대로다.
