## 사용자 기능과 실제 연결 상태

- FREE: 기존 Firebase 회원 화면과 기기 내 MediaPipe 체형 참고 분석. 원본 사진을 서버/GPT로 보내지 않습니다.
- GENERAL: 유효한 서버 구독 기록이 있을 때 스타일 추천, 국내외 검색 연결, 관심 상품과 AI 스타일 상담.
- PREMIUM: GENERAL에 더해 동일 변형의 확인된 판매처 가격 비교, 목표 가격, 프로모션 모의 조건·설정과 AI 비교/할인 상담.
- 한국·미국·일본·영국·유럽, 한국어·영어, 국가/배송지와 KRW/USD/EUR/GBP/JPY, 남성·여성·유니섹스 및 기존 검색 필터를 유지합니다.
- HOME, AI STYLE STUDIO, GLOBAL SHOPPING, AI STYLIST, PRICE COMPARISON, MEMBERSHIP, MY ACCOUNT 메뉴를 연결하며 언어 선택을 유지합니다. 저장소에 별도 제공된 브랜드 원본 로고가 없어 기존 문자 워드마크를 유지합니다.
- 실제 피드가 없으면 검색 링크와 자료 부재 안내를 사용합니다. 가상 비교는 DEMO, 알림은 DRY RUN이며 실제 최저가·발송처럼 표시하지 않습니다.
- GPT 기본값은 **DEMO 규칙 기반 상담**입니다. 실제 GPT는 명시적 서버 승인·키·고정 모델·검증 요금·일/월 예산·회원 권한·외부 전송 동의가 모두 있어야 호출할 수 있습니다. 이번 작업에서는 실제 호출하지 않았습니다.

모델 출력은 허용된 스타일 조언 ID와 검증된 상품 ID로 제한하고 상품명·가격·재고·할인·판매 URL은 서버 자료로 조립합니다. 외부 AI 동의와 분석 비율 사용 동의는 별개이며 원본 사진·파일·전체 기준점을 받지 않습니다. 대화와 두 참고 비율은 브라우저 메모리에서 정리하며 사용량 DB에는 원문·이메일·사진·수치를 저장하지 않습니다. 목적지 근거 없는 비용, 미확인 환율·재고와 오래된 가격은 최저가로 확정하지 않습니다.

## 통합 중 보완한 보안

구독 검사는 브라우저 표시나 JWT의 임의 paid 주장 대신 서명 검증과 현재 DB 기록으로 수행합니다. 글로벌의 최종 조회 중 만료 차단을 유지하며 AI와 기존 추천 경로에서도 비동기 요청 본문·최종 인증/상품 조회 동안 만료·취소된 권한을 재사용하지 않도록 수정했습니다. 이 기존 API 오류의 신규 회귀 검사는 수정 전 9개 중 8개 실패, 수정 후 9개 모두 통과했습니다. AI 예산은 원자적으로 예약하고 실제 호출 직전 UTC 일/월이 바뀌면 이전 기간 예약으로 호출하지 않습니다. 오류·시간 초과는 재시도하거나 불확실한 비용을 환급하지 않습니다.

마케팅 동의·철회는 회원/구독 가입과 분리하고 본인 데이터만 접근합니다. 회원 탈퇴는 재인증 후 글로벌 개인정보와 AI 회원별 사용 기록을 먼저 정리하며 실패 시 Firebase 삭제를 중단합니다. 다른 회원과 익명 전체 비용 합계는 지우지 않고 거래 기록은 별도 보관 검토 대상입니다.

## D1 적용 순서와 기존 회원 영향

운영 DB의 대상·현재 스키마·마이그레이션 이력은 이 환경에서 조회하지 못했습니다. 로컬 통과는 운영 적용 완료를 뜻하지 않습니다.

1. 기존 설치: 현재 이력에 따라 미적용 SQL만 `0001_membership_tiers.sql` → `0002_global_catalog_and_alerts.sql` → `0003_global_consent_context.sql` → `0004_ai_stylist_usage.sql` 순서로 검토합니다. 순서를 바꾸거나 ALTER를 중복 실행하지 않습니다.
2. 완전히 빈 로컬/승인된 시험 DB: `server/schema.sql`은 글로벌 0003까지 포함하므로 그 다음 AI 0004만 적용합니다. 기존 DB의 이전 절차로 전체 schema를 덮어 쓰지 않습니다.
3. 적용 전 승인된 대상의 백업/복구 지점을 확보하고 내보낸 SQL·스키마·행 수·시각과 적용 이력을 검토합니다. 복구는 격리 DB에서 먼저 확인합니다. 실제 운영 백업 생성·SQL 적용·바인딩 변경도 이 작업에서 실행하지 않았습니다.
4. 기존 유효 유료 기록은 GENERAL 호환이며 PREMIUM 자동 승격이 없습니다. 과거 동의에 국가/문안 증빙이 없으면 null로 남깁니다. 회원·찜·동의를 삭제하거나 결제/시험 구독을 생성하지 않습니다.

같은 Firebase 프로젝트와 `(issuer, subject)`를 유지하므로 재가입·비밀번호 변경이 필요하지 않습니다. 이번 작업은 운영 회원 데이터를 변경하지 않았습니다. D1/구독이 준비되지 않으면 유료 기능이 잠기며 기존 인증·무료 분석은 별도로 유지됩니다.

## 정확한 Cloudflare 설정과 안전한 Preview

기존 프로젝트 **a1fashion**, Git 저장소·Production 브랜치 **main**, Framework **None**, Root **저장소 루트**, Build **node scripts/build-site.cjs**, Output **dist**를 유지합니다. 기존 Production Firebase 변수와 승인 도메인을 교체하지 않습니다.

Preview 확인은 다음 조건을 먼저 확인해야 합니다.

1. Cloudflare의 a1fashion → Settings에서 환경별 설정을 확인하고 `MEMBERSHIP_DB`가 운영 DB를 가리키지 않는지 확인합니다. 환경 선택 메뉴의 위치는 대시보드 버전에 따라 다르며, 사용자가 제공한 현재 화면과 변수 추가 창에는 선택 메뉴가 보이지 않았습니다. Production/Preview 범위를 확인하지 못한 채 기존 변수를 지우거나 DB를 추가하지 않습니다. 승인된 격리 시험 DB가 없으면 바인딩하지 않습니다.
2. Preview에 운영 `FIREBASE_PROJECT_ID`·`FIREBASE_WEB_API_KEY`를 재사용하지 않습니다. D1이 없어도 같은 Firebase 키로 실제 가입·인증 메일·재설정·탈퇴가 가능하므로 격리 인증 환경이 없으면 두 값도 미설정으로 두고 잠금 화면·무료 분석만 검사합니다. 기존 Production 값은 그대로 둡니다.
3. GPT는 DEMO, 실제 상품 승인 플래그는 미설정/false, 이메일/SMS는 모의, 청구·Cron은 비활성으로 유지합니다. Preview에 운영 비밀키·회원 데이터·실제 구독을 복제하지 않습니다.
4. 격리 확인 후 통합 브랜치의 Preview만 배포하고 성공 체크의 실제 URL에서 페이지·메뉴·번역·무료 분석·보호 기능 잠금을 확인합니다. 전체 인증/유료 기능은 로컬 대역 또는 별도로 승인된 격리 인증/DB로 검사합니다.

현재 관리 환경은 GitHub API와 Cloudflare/Pages 호스트 접근이 제한되고 Cloudflare 연결 자격 증명이 없습니다. 따라서 원격 바인딩 확인·공개 Preview 검증은 아직 완료하지 못했으며 URL을 추측해 제공하지 않습니다. 최종 커밋에 `[CF-Pages-Skip]`을 사용해 격리 확인 전 자동 Pages 빌드를 건너뜁니다. GitHub PR 생성 결과와 실제 가능한 비교 링크는 완료 보고에 기록합니다.

### Preview API 차단 보호

표준 Pages Preview 주소인 `*.a1fashion.pages.dev`에서는 `functions/api/_middleware.js`가 모든 API를 503 `preview_isolated`로 차단합니다. 회원 가입·로그인·메일·재설정·탈퇴, 구독·상품·알림·GPT API가 환경 변수·DB·원격 서비스나 다음 핸들러를 사용하기 전에 종료됩니다. 추가 환경 변수·키·DB가 필요하지 않고 브라우저 값이나 설정 플래그로 해제할 수 없습니다. 실제 운영 주소 `a1fashion.pages.dev`와 로컬 테스트의 기존 인증/권한 검사는 그대로 유지합니다.

이 보호는 **수정이 포함된 커밋을 빌드한** Preview에서 적용됩니다. 이전 배포가 자동 수정되는 것은 아닙니다. 화면·언어·무료 기기 내 분석을 확인하는 제한된 Preview를 위한 것이며 실제 바인딩 분리가 확인됐다는 뜻이 아닙니다. 표준 Pages Preview 이외의 사용자 지정 미리보기 도메인을 자동 보호한다고 가정하지 않습니다. 별도 승인 전 새 Preview 도메인을 연결하지 않습니다. Preview의 실제 회원/구독 기능은 잠금 상태이며, 전체 인증·유료 API 검증은 로컬 대역을 사용합니다. 공통 메뉴 아래에 한·영 미리보기 안내를 표시하며 운영 화면에는 표시하지 않습니다.

## 운영 승인과 복구

PR/Preview 승인과 운영 승인은 별개입니다. main 병합은 Git 통합 자동 배포를 시작할 수 있으므로 다음은 각각 검토 후 승인합니다.

1. 이 PR의 정확한 커밋과 비활성 기능·회원 영향, Preview 격리/실제 결과를 검토합니다.
2. 필요한 경우 **대상 D1·백업/복구·정확한 미적용 SQL**을 별도로 승인합니다. DB 적용 실패 시 진행을 중단하며 유료 기능을 열지 않습니다.
3. **main 병합 및 운영 배포**를 승인한 뒤 기존 프로젝트에 배포합니다. 인증 설정·무료 분석·언어·잠금·동의/탈퇴의 안전 상태를 확인합니다. 실제 회원 생성·삭제/메일 시험은 그 대상과 영향도 별도 확인합니다.
4. 실패하면 Cloudflare Deployments에서 사전에 기록한 정상 Production 배포로 rollback합니다. 코드 복구가 DB를 되돌리는 것은 아니므로 SQL에 문제가 있으면 쓰기/유료 기능을 중지하고 승인된 복구 계획을 적용합니다. 이번 추가 SQL은 기존 회원 삭제를 포함하지 않으며 운영에서 DROP/자동 역마이그레이션을 하지 않습니다. Git 복구는 별도 revert PR로 검토하며 강제 push를 하지 않습니다.

배포 승인만으로 GPT/피드/유료 서비스/정기 결제/이메일/SMS/Cron을 켜지 않습니다. 실제 GPT는 모델/현행 단가·요청 수/일월 상한·개인정보/국외 처리·서버 Secret·제한된 시험 호출을 각각 검토하고 승인합니다.

## 무료 범위, 비용과 미완성 연결

이번 개발·로컬 검사·번역·기기 내 분석·규칙 기반 DEMO에는 GPT·유료 상품 API·메시지 비용이 없습니다. Cloudflare/Firebase 무료 한도는 실제 계정 기준이며 무제한 무료를 보장하지 않습니다. 실제 서버 DEMO도 유효 구독과 D1 설정이 필요하고 가입만으로 유료 권한을 부여하지 않습니다.

남은 실제 연결은 eBay/Awin 등 공식 API·광고주/피드 승인과 매핑·수집/보관/갱신, 신뢰 가능한 환율, 결제 가격·약관·제공자와 검증된 웹훅, 발송 도메인/번호·동의·수신 거부/반송·차단 목록, 국가별 광고성 메시지 법적 확인, 예약 감시/실제 큐입니다. 스크레이핑으로 대체하지 않습니다.

추가 비용은 GPT 토큰, 인프라/DB 한도 초과, 상품/환율 계약, 도메인·이메일·SMS, 결제 수수료 등에서 발생할 수 있습니다. 실제 최신 모델 단가는 확인되지 않았으므로 [AI 운영 보고서](AI-STYLIST-OPERATIONS.md)의 가정 예시를 현재 견적으로 사용하지 않습니다. 실제 비용과 승인 단계는 이 보고서 및 [글로벌 운영 보고서](GLOBAL-OPERATIONS.md)를 함께 검토합니다.
