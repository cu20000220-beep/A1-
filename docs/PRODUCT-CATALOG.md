# 상품 추천과 외부 쇼핑몰 연결

> 2026-11-09 재조사: 네이버 쇼핑 검색 API는 공식 종료 공지상 2026-07-31 종료·API HUB 대체 없음입니다. 과거 API 후보/25,000회 안내로 신규 연동하지 마세요. 현재 무료 베타 정책과 상품·피팅 확장 설계는 [PRODUCT-FITTING-PLAN.md](PRODUCT-FITTING-PLAN.md)를 우선합니다. 기존 구독 잠금 설명은 과거 기록입니다.

## 현재 운영 방향

A1은 사진 분석 결과에 따른 스타일 큐레이션과 외부 판매처 연결을 제공하는 서비스입니다. 의류 직접 판매·주문 후 매입·배송·재판매 계획은 보류했습니다. 현재 실제 자사 의류는 등록되지 않았습니다.

**사진 업로드와 체형 참고 분석 결과는 무료, 의류 추천과 외부 쇼핑몰 연결은 유료 구독자 전용**입니다. 기간형 무료 체험을 운영하지 않습니다. 월 구독료는 아직 미정이며 실제 회원가입·구독 결제·정기 청구는 연결하지 않았습니다. 서버에 인증/구독 설정이 없으면 추천 기능은 잠깁니다. 무료 분석 결과는 이 설정 없이 이용할 수 있습니다.

향후 고객이 A1에 내는 비용은 스타일 큐레이션 이용료입니다. 옷 구매 수수료나 배송비를 받는 기능은 아닙니다. 유료 출시 전 가격·반복 제공할 혜택·해지/환불 정책·운영/결제 제공자 요건을 정해야 합니다. 상품 주문·결제·배송·상품 반품은 선택한 판매처의 정책을 따르며, A1 구독의 취소·환불·회원정보 처리는 A1이 별도로 준비해야 합니다.

## 현재 추천 자료의 범위

- 서버 카탈로그는 **12개의 예시 스타일**입니다. 실제 재고나 외부몰 판매 상품 목록이 아닙니다. 예시 가격과 사진이 실제 판매 상품을 나타낸다고 안내하지 않습니다.
- AI는 사진 속 인체 기준점을 추정합니다. 추천과 검색어 생성은 분석된 비율 두 개·취향·예산에 적용한 명시적인 규칙입니다. 생성형 AI의 실제 상품 분석이나 의류 합성으로 표시하지 않습니다.
- 구독 확인 후 표시하는 외부몰 버튼은 쿠팡·Temu·네이버쇼핑의 **검색 결과 링크**입니다. 상품 API·개별 상품 자동 수집·실시간 가격 비교·제휴 계약·주문 연동이 아닙니다.
- 외부몰 URL에는 일반 의류 검색어만 넣습니다. 사진·파일 이름·신체 비율/수치·체형 표현·회원 식별자·제휴 추적값은 넣지 않습니다.
- 예산 조건은 A1 예시 카탈로그에 적용합니다. 외부몰 검색에는 자동 적용하지 않으며 판매처에서 가격 필터와 재고를 확인하도록 안내합니다.

실제 공급원이 준비되기 전에는 예시 카탈로그와 검색 링크를 실제 상품 자동 매칭으로 설명하지 않습니다. 실제 제공 가치와 공급원이 확인되기 전 유료 가입을 활성화하지 않습니다.

## 추천 데이터의 접근과 개인정보

공개 정적 파일은 무료 분석과 잠금 화면만 제공합니다. 추천 카탈로그·규칙·판매처 검색 URL 생성은 서버로 옮겼습니다. 서버는 인증된 회원과 DB의 유효한 결제 기록을 매 요청마다 검증합니다. 클라이언트 저장소의 결제 표시나 유효하지 않은 체험 기록은 허용 근거가 아닙니다. [서버 연결 안내](../server/README.md)를 참고하세요.

사진과 전체 기준점은 기기 밖으로 보내지 않습니다. 구독자가 추천을 요청할 때만 어깨/골반·다리/몸통 간격 비율 두 값과 컬렉션·스타일·예산을 A1 서버에 전달하며 데이터베이스에 저장하지 않습니다. 공개 소스 저장소를 비공개로 바꾼 것은 아니며, 안전한 접근 경계는 서버 인증과 DB 구독 검증입니다.

## 실제 외부 상품 자동 매칭에 필요한 것

1. 상품명·가격·판매 URL·분류·사용 가능한 사진을 제공하는 공식 API/피드 또는 판매처가 허용한 상품 목록
2. 이용 조건·이미지 사용·가격 갱신·품절 처리·저장 허용 여부 확인
3. 필요한 계정 승인과 인증키를 안전하게 보관할 서버 환경. 공개 HTML/JavaScript/GitHub 파일에는 비밀키를 넣지 않음
4. 확인된 상품의 핏·기장 등 특성을 이용한 추천. 근거 없는 상품 사양·가격·재고·제휴 관계를 생성하지 않음

로그인 우회, 비공식 스크레이퍼, 검증되지 않은 무료 API는 사용하지 않습니다.

## 조사한 공식 상품 API 후보

- 네이버 공식 자료: https://github.com/naver/naver-openapi-guide/blob/master/ko/service-apis/search/shopping/shopping.md
- 검토한 공식 저장소 리비전: `617252106233bb2a2591b6388a4b4ad2e0fd5dc3` (2026-10-20)
- 문서상 `GET https://openapi.naver.com/v1/search/shop.json`, 앱 등록과 Client ID/Secret 필요, 상품명/링크/이미지/가격/판매처/분류 반환
- 현재 가격·약관·응답 장기 저장 허용은 별도 확인 전입니다. 현 시점 완전 무료라고 보장하지 않으며 인증키가 없어 실제 상품 호출도 검증하지 않았습니다.
- 쿠팡/Temu는 접근 가능한 공식 자료에서 무인증 무료 상품 피드를 확인하지 못했습니다. API가 없다고 단정하지 않으며 공식 개발자/제휴 포털 확인이 필요합니다.

외부 검색 URL의 형식과 개인정보 미포함을 테스트합니다. 현재 실행 환경은 쇼핑몰 직접 접속이 정책으로 차단되어 판매처의 실제 검색 화면을 검증하지 못했습니다. 이것을 판매처 장애로 설명하지 않습니다.

## 향후 허용된 상품 피드의 데이터 계약

```json
{
  "id": "stable-product-id",
  "source": "external",
  "sellerName": "확인된 판매처",
  "name": "실제 상품명",
  "gender": "여성 | 남성 | 유니섹스",
  "category": "상의 | 하의 | 아우터 | 원피스 | 액세서리",
  "style": "미니멀 | 캐주얼 | 클래식 | 스트리트",
  "price": 59000,
  "currency": "KRW",
  "productUrl": "https://confirmed-retailer.example/product",
  "photo": "사용 권한이 있는 이미지 경로",
  "photoSource": "권리자/허용 근거",
  "garmentTags": ["확인된 핏 또는 기장"],
  "availability": "available | soldOut | unknown",
  "updatedAt": "ISO 8601 갱신 시각"
}
```

이 계약은 향후 설계입니다. 현재 보호된 응답은 `source: example`만 사용하며 실제 상품·개별 판매 URL·관리자 업로드·실시간 피드를 제공하지 않습니다. 실제 외부 피드를 도입할 때에는 검증된 판매 URL/사진 정책과 응답 표시도 함께 확장해야 합니다.
