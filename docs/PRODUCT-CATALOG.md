# 자사 상품 등록과 외부 상품 연동

## 현재 상태

- A1 별도 자사 쇼핑몰은 필요하지 않습니다. A1에 직접 상품 사진과 정보를 게시할 수 있습니다.
- 현재 상품 카탈로그는 예시 상품입니다. 실제 자사 재고나 외부몰 판매 상품이 아닙니다.
- AI는 사진 속 기준점을 추정합니다. 등록된 상품의 추천과 외부몰 검색어 생성은 분석값·취향·예산을 이용한 명시적인 규칙입니다.
- 외부몰 버튼은 쿠팡·Temu·네이버쇼핑의 **검색 결과 링크**입니다. 상품 API 연결·개별 상품 수집·자동 가격 비교·제휴 계약이 아닙니다.
- 외부몰에는 일반 의류 검색어만 전달합니다. 사진, 파일 이름, 신체 비율/수치, 체형 표현, 식별자, 제휴 추적값은 URL에 넣지 않습니다.
- 예산 필터가 외부몰 검색에 자동 적용되는 것으로 표시하지 않습니다. 판매처에서 직접 가격 필터와 재고를 확인하도록 안내합니다.

## 자사 상품을 지금 무료로 게시하는 방법

모델 사진의 사용 권한을 확인하고, 사진·상품명·가격·분류·색상·사이즈·설명을 이 대화에 전달하면 사이트 파일로 등록한 뒤 검토·승인 후 게시할 수 있습니다. 실제 사진과 상품 설명이 서로 일치해야 합니다. 구매/결제 연결은 현재 범위에 포함하지 않습니다.

현재 GitHub Pages는 정적 호스팅이므로, 사이트의 사진 선택창만으로 운영자 인증·공유 상품 영구 저장이 이뤄지지는 않습니다. 기기에서만 저장되는 임시 초안을 전체 고객에게 게시된 상품이라고 표시하지 않습니다. 직접 사용하는 영구 상품관리 화면은 인증과 안전한 저장 기능을 별도로 정해야 합니다. 향후 무료 서비스를 검토하더라도 무료 플랜·과금 조건·계정 권한을 먼저 확인합니다.

## 실제 외부 상품 자동 매칭에 필요한 것

1. 상품명·실제 가격·판매 링크·분류·사용 가능한 사진을 제공하는 공식 API/피드 또는 판매처가 허용한 상품 목록
2. 이용 조건·이미지 사용·가격 갱신·품절 처리·저장 허용 여부 확인
3. 필요한 계정 승인과 인증키를 안전하게 보관할 실행 환경. 공개 HTML/JavaScript/GitHub 파일에는 비밀키를 넣지 않음
4. 수집된 실제 상품에 핏·기장 등 확인된 특성을 붙여 추천하며, 근거 없는 상품 사양을 AI가 만들어내지 않음

실제 공급원이 없을 때 검색 결과 링크를 상품 단위 자동 매칭으로 바꾸어 설명하지 않습니다. 로그인 우회, 비공식 스크레이퍼, 검증되지 않은 무료 API는 사용하지 않습니다.

## 조사한 공식 상품 API 후보

- 공식 네이버 자료: https://github.com/naver/naver-openapi-guide/blob/master/ko/service-apis/search/shopping/shopping.md
- 검토한 공식 저장소 리비전: `617252106233bb2a2591b6388a4b4ad2e0fd5dc3` (2026-10-20)
- 문서상 `GET https://openapi.naver.com/v1/search/shop.json`, 앱 등록과 Client ID/Secret 필요, 상품명/링크/이미지/가격/판매처/분류 반환
- 현재 가격·약관·응답 장기 저장 허용은 별도 확인 전이며, 현 시점 완전 무료라고 보장하지 않음. 인증키도 없으므로 실제 상품 호출은 검증하지 못함
- 쿠팡/Temu는 접근 가능한 공식 자료에서 무인증 무료 상품 피드를 확인하지 못함. 공식 API가 없다는 뜻으로 단정하지 않으며 제휴/개발자 포털 확인이 필요

외부 검색 링크는 URL 생성과 개인 정보 미포함을 검증했습니다. 현재 실행 환경은 해당 쇼핑몰에 대한 직접 접속이 네트워크 정책으로 차단되어, 판매처의 실제 검색 화면은 검증하지 못했습니다. 이는 판매처가 장애라는 의미는 아닙니다.

## 실제 상품을 위한 데이터 계약

```json
{
  "id": "stable-product-id",
  "source": "own | external | example",
  "sellerName": "확인된 판매처",
  "name": "실제 상품명",
  "gender": "여성 | 남성 | 유니섹스",
  "category": "상의 | 하의 | 아우터 | 원피스 | 액세서리",
  "style": "미니멀 | 캐주얼 | 클래식 | 스트리트",
  "price": 59000,
  "currency": "KRW",
  "productUrl": null,
  "photo": "사용 권한이 있는 이미지 경로",
  "photoSource": "권리자/허용 근거",
  "garmentTags": ["확인된 핏 또는 기장"],
  "availability": "available | soldOut | unknown",
  "updatedAt": "ISO 8601 갱신 시각"
}
```

자사 상품은 외부 판매 링크가 없어도 상세 정보를 표시할 수 있습니다. 실제 외부 상품은 확인된 HTTPS 판매 페이지를 연결하고 제휴 여부를 실제 계약에 맞게 표시해야 합니다. 이 계약은 다음 등록 작업을 위한 설계이며, 현재 관리자 업로드나 실시간 상품 피드가 구현됐다는 의미는 아닙니다.
