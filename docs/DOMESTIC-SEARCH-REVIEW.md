## 이번 변경과 발표 예시

입력 예시: **남성 검정 와이드 슬랙스 출근용 5만원 이하**.

1. 검색하면 의류 종류·색상·핏·용도·컬렉션·예산을 화면에서 확인합니다.
2. 무신사·29CM·네이버쇼핑·쿠팡의 공식 검색을 사용자가 직접 클릭합니다. 링크에는 고정 의류 어휘로 만든 `남성 검정 와이드 슬랙스 출근용`만 들어갑니다.
3. **예산은 해석·표시하지만 판매처 가격 필터에 자동 적용하지 않습니다.** 판매처에서 직접 설정하도록 안내합니다.
4. 같은 조건으로 무료 규칙 스타일 조언을 받을 수 있습니다. 독립 스타일리스트도 같은 파서와 공식 검색 링크를 재사용합니다. 실제 GPT 호출은 없습니다.
5. 사진 비율은 별도 동의 후 로컬 조언에만 사용합니다. 동의 전후 외부 검색 URL은 같으며 원본 사진·신체 수치·원문·회원 정보는 URL에 추가하지 않습니다. 분석 삭제 시 동의와 로컬 조언을 지웁니다.

추가 지원: 하객·일상·운동 목적, 세미와이드·오버핏·루즈핏·일자·슬림·레귤러, 티셔츠와 셔츠 구분, `3만5천원 이하`·`35,000원 이하`·`5만원 미만`. 운동 목적은 기존 상품 추천 enum을 변경하지 않고 검색 목적과 구분합니다. `5만원 이상`, 가격 범위, 제외 조건은 잘못된 상한/색상으로 확정하지 않고 수정 안내를 표시합니다.
