# PR #4 홈 분석 결과 → 연구실 연결 수정

## 원인

기존 PR #4는 `/product-lab.html`에만 연구 화면을 만들고 홈 `index.html`의 분석 결과에 진입 버튼을 연결하지 않았습니다. 기능 플래그나 iPad 전용 CSS가 버튼을 숨긴 문제가 아니라 화면 연결 자체의 누락입니다. 따라서 사용자 미확인 5개 항목을 기능 고장으로 분류하지 않습니다.

## 수정

- 표준 Preview에서만 분석 완료 결과 안에 추천·비교·로컬 2D 시험 버튼과 개발 중인 비활성 3D 버튼 표시.
- 클릭하면 같은 출처의 정적 연구실 HTML에서 연구 섹션만 가져와 **현재 문서**에 표시. 기존 분석 영역·사진 캔버스를 복제하거나 새 페이지로 사진을 전달하지 않음.
- 원본 사진·비율·조건을 URL, 브라우저 저장소, POST, 서버·외부 서비스로 전송하지 않음. GET은 정적 템플릿만 요청하며 credentials omit 및 redirect error 적용.
- 기존 결과·조건은 현재 문서 메모리로 유지. 비율의 추천 사용 동의와 이미지의 2D 사용 동의는 각각 기본 해제. 연구실 버튼 이동이 동의를 켜거나 기존 선택을 재설정하지 않음.
- 최초 비교 영역은 비교에 추가하라는 안내. 3D는 실행 불가, AI 착용 합성은 미구현으로 명시. 준비 중인 실제 상품과 수동으로 켜는 가상 시험 자료를 분리.
- 템플릿 읽기 실패 시 오류 안내 후 재시도 가능. 삭제·사진 교체 시 기존 분석 삭제 이벤트로 진입 버튼과 연구 상태·동의를 초기화.
- Production에서는 진입 모듈이 즉시 종료하고 연구실은 비활성. 서버 무료 베타·등급/개인 소유권·API 미들웨어는 변경하지 않음.

수정 파일: `index.html`, `product-lab.html`, `assets/lab-entry.js`, `assets/product-lab.js`, `assets/product-lab.css`, 정적 빌드 허용 목록. 새 브라우저 검사 `tests/lab-entry-browser.cjs`.

## 실제 iPad Safari 수동 확인

최종 고정 Preview는 PR #4 본문 참조. **홈 `/#ai-studio`부터 시작**하면 사용자 진입 연결을 검사할 수 있습니다. `/product-lab.html`은 연구실 직접 주소로 유지됩니다.

1. Safari 앱 주소창에 Preview 홈 주소 직접 입력. 전신 사진 선택 → 무료로 사진 분석하기.
2. 분석 결과 아래 `내 체형에 맞는 의류 추천 보기`, `추천 의류 비교하기`, `내 사진으로 가상 피팅하기 · 2D 시험`과 비활성 `3D 아바타 피팅 · 개발 중`이 보이는지 확인.
3. `내 체형에 맞는 의류 추천 보기` → 조건 화면과 기본 실제 상품 자료 없음 안내 확인. 실제 상품을 표시한 것으로 판단하지 않음.
4. `격리된 가상 상품 3개로 흐름 시험` → 가상 카드 3개·시험 금액·점수·이유·주의사항 확인. 조건이 있는 경우 일치하지 않는 카드가 제외될 수 있으므로 기본 조건으로 3개를 확인.
5. 카드 2개의 `비교에 추가` → 결과의 `추천 의류 비교하기` → 비교 표 확인. 선택한 조건과 동의는 유지되는지 확인.
6. 카드의 `2D 배치 대상으로 선택` → 결과의 `내 사진으로 가상 피팅하기 · 2D 시험` → 이미지 사용 동의 전 `로컬 2D 배치 보기`가 배치하지 않는지 확인.
7. 이미지 사용 동의 체크 → `로컬 2D 배치 보기` → 의류 위치·크기 슬라이더 조절. 단순 도식 배치이며 실제 AI 착용·실측·3D가 아님.
8. 동의 해제하면 배치 이미지 제거. `사진·분석·조건·배치 모두 지우기`로 사진·분석·시험 결과·동의가 지워지고 분석 결과 진입 버튼도 숨겨지는지 확인.
9. 한/영 및 세로/가로 모두 반복. 기존 `분석 비율로 A1 AI 상담하기`의 별도 동의·현재 탭 이동도 확인.

## 자동 검사 범위와 제한

- 홈부터 시작하는 KO/EN × 820×1180 / 1180×820 / 390×844 터치 Chromium 6개 흐름: 진입 버튼 표시·클릭, 원본 분석 캔버스 유지, 중복 분석 폼 없음, 기본 실제 상품 없음, 가상 의류 3개, 점수/이유/비교, 조건·동의 유지, 2D 개별 동의, 실제 픽셀의 위치/크기 변경, 철회·삭제, 저장소에 사진/비율 없음, 동일 출처 정적 GET만 허용.
- 기존 연구실 직접 진입 KO/EN × 390/820 4개 및 기존 분석→추천→스타일리스트→판매처 이동 4개 회귀 검사.
- 로컬 브라우저 검사는 자세 추정 fixture와 실제 기존 분석 계산/UI를 사용. 실제 배포의 MediaPipe 모델 검사는 최종 PR 본문에 별도 기록.
- 실제 iPad Safari는 개발 환경에서 실행할 수 없으므로 자동 검사로 합격 판정하지 않음. 사용자 실기기 검증 전 PR #4 병합 금지.

PR #3 → 통합 브랜치가 먼저이며, 그 후 PR #4의 base 조정·충돌/검사 재확인. 이번에는 어느 PR도 병합하지 않습니다. main/Production/회원·구독/Firebase/운영 DB·Cloudflare 운영 설정·유료 기능을 변경하지 않습니다.
