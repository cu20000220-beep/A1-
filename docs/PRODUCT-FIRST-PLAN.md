# A1 FASHION 상품 검색 우선 개발 계획

## 우선순위와 현재 상태

A1은 의류 탐색·추천·비교를 우선하는 쇼핑 서비스입니다. 연구용 아바타나 진입 버튼이 보인다는 사실을 실제 상품 검색·추천·피팅 완성으로 보고하지 않습니다. 기존 PR #4와 사진 분석·한영·무료 정책·개인정보 보호 코드는 보존하며, 추가 아바타 개발은 실제 상품 공급원 확보와 탐색 흐름보다 우선하지 않습니다.

저장소를 읽기 전용으로 조사한 결과 **승인된 실제 판매 상품은 0개**입니다. 운영 Firebase·DB·회원·구독 자료는 조회하거나 변경하지 않았습니다.

| 자료/기능 | 실제 상태 |
| --- | --- |
| `server/catalog-data.mjs` | 12개 예시 스타일. 실제 판매 상품·재고·현재 가격 아님 |
| 연구실 LAB-A/B/C | 가상 시험 의류 3개. 실제 상품 URL 없음 |
| 승인된 상품 JSON/CSV/SQL seed | 저장소에서 발견되지 않음 |
| eBay Browse 어댑터 | 승인 게이트가 있는 후보 탐색 골격. 반환되는 제목/ID만으로 실제 상품 카드 완성 불가 |
| Awin 어댑터 | 계약/매핑 인터페이스만 있으며 활성화되지 않음 |
| 규칙 추천·DEMO 상담 | 브라우저에서 사용 가능한 규칙 로직. 실제 생성형 AI·실제 상품 확보를 뜻하지 않음 |
| 사진 분석 | 기기 내 MediaPipe 기준점·사진상 비율 두 값. 실측 cm·정확한 사이즈 아님 |
| 3D·2D 연구 기능 | 단순 참고 아바타·가상 의류 도식 배치. 실제 의류의 자연스러운 AI 합성·물리 피팅 아님 |

## 첫 완료 목표: 한 공급원의 실제 의류 10개 이상

첫 완료 기준은 **권한이 확인된 단일 공급원의 실제 판매 의류 10개 이상을 A1 화면에서 검증 가능한 정보와 함께 검색할 수 있는 것**입니다. 예시 스타일·DEMO API·합성 상품·가상 시험 금액으로 수량을 채우지 않습니다.

각 상품은 최소한 다음 필드를 가져야 합니다.

- 공급원·공급원 상품 ID·판매처·이름·브랜드·가능하면 변형/SKU/GTIN.
- 표시 권한이 있는 실제 의류 이미지와 원 출처. 이미지가 없다면 사진을 가진 상품으로 완료 처리하지 않음.
- 실제 확인한 가격·통화·판매 상태와 확인 시각 `checkedAt`, 만료 시각 `expiresAt`. 배송/세금 미확인은 별도 표시.
- 확인된 사이즈 표기·선택 가능한 사이즈. 사이즈표/의류 실측을 확보하지 못하면 해당 정보 없음으로 표시하고 정확한 사이즈 추천을 하지 않음.
- HTTPS 공식 상품 구매 URL·상품/이미지 표시 권리·필드별 출처·허용된 보관/갱신 기간.

완료 검사는 공급자 자료와 화면 값을 대조하고, 실제 개별 상품 페이지가 맞는지 확인해야 합니다. 홈페이지·공식 검색 링크를 개별 상품 검증으로 대신하지 않습니다. 만료·품절·출처/권리 미확인 상품은 숨기거나 상태를 정확히 표시합니다. 서로 다른 통화는 승인된 환율 자료 없이 최저가로 비교하지 않습니다.

### 기존 구현의 갭

`server/catalog-repository.mjs`는 승인된 출처·판매 URL·재고·가격·보관/갱신·약관을 검증하는 읽기 전용 구조를 갖고 있습니다. 그러나 현재 공개 상품 응답에는 실제 이미지 URL과 사이즈표/실측표 데이터 계약이 없습니다. `server/product-matching.mjs`와 `assets/product-matching.js`의 점수·이유·주의사항은 재사용하되, 상품 사진/권리·사이즈표 정보를 추가로 연결해야 합니다. 현재 골격이 있다는 사실은 실제 상품이 있다는 뜻이 아닙니다.

## Preview의 안전한 실제 데이터 연결 경로

가장 작은 초기 경로는 **승인된 브랜드 자료 → 공개 가능한 로컬 상품 스냅샷 → 출처/권리/갱신 검증 → 브라우저 내 검색·정렬**입니다.

1. 운영자가 사용권이 확인된 상품 자료와 이미지 조건을 승인합니다.
2. 비밀키·회원/주문 자료가 없는 공개용 필드만 정규화합니다.
3. 상품별 공식 구매 URL·이미지 출처/표시권·현재 가격/통화·사이즈·확인/만료 시각을 검증합니다.
4. 승인된 자료만 개발 브랜치의 별도 공개 스냅샷으로 패키징합니다. 브라우저가 임의로 넣은 `sourceVerified:true`를 승인 근거로 삼지 않습니다.
5. 정적 스냅샷을 기기 내에서 검색하며 Preview의 `/api/*` 격리와 운영 DB 보호를 유지합니다.

**승인 자료가 현재 없으므로 이 실제 상품 스냅샷과 10개 상품 연결은 아직 미완료입니다.** 만료 시각을 코드 실행 시각으로 자동 갱신해 오래된 가격을 최신처럼 보이게 하지 않습니다. 이미지 복사가 허용되지 않으면 마음대로 저장하지 않으며, 외부 이미지 요청이 필요한 경우 이용 조건·방문자 네트워크 정보 노출 범위를 검토해야 합니다.

## 이번 검색 중심 변경의 범위

홈의 우선 화면은 실제 옷을 찾는 검색 입력입니다. 입력을 제한된 의류 조건으로 정규화해 공식 쇼핑몰 검색 링크를 대안으로 제공합니다. 상품 카드처럼 가짜 이름·사진·가격·재고를 만들지 않으며, **공식 쇼핑몰에서 검색할 링크**라는 사실과 A1이 확보한 실제 상품 수 0개를 구분합니다.

개인 사진·분석 비율·자유 입력의 개인정보를 판매처 URL로 보내지 않습니다. 허용된 의류 카테고리·색상·성별 등의 토큰만 사용하고, 사용자의 직접 클릭으로 HTTPS 허용 판매처로 이동합니다. 가격 상한이 링크 검색어로 제공되더라도 해당 몰에서 실제 필터/결과 가격을 다시 확인해야 하며 A1이 상품 가격을 검증했다고 표시하지 않습니다. 검색어 복사·공식 홈·Safari 안내를 유지합니다.

기존 무료 규칙 상담을 이 검색 흐름과 연결해 조건을 설명하고 검색을 이어갈 수 있도록 합니다. 생성형 모델이 실시간으로 옷을 찾거나 판단하는 것으로 안내하지 않습니다. 실제 상품 데이터가 없는 동안 상담 결과 역시 실제 상품 추천 완료가 아닌 조건/검색 안내입니다.

### 아바타 조사 방향

현재 아바타는 기하학적 인체·의류를 조합한 참고 모델로, 실제 인체의 일체형 표면·관절·의복을 충분히 재현하지 못합니다. [MakeHuman](https://www.makehumancommunity.org/) 계열을 검토할 수 있습니다. 코어에서 내보낸 모델의 CC0 범위와 프로그램 자체 라이선스는 구분하며, 추가 의류·머리카락·텍스처·커뮤니티 자산은 **자산별 라이선스를 따로 확인**해야 합니다. 코어 출력 정책을 모든 외부 자산에 확대 적용하지 않고, 무료 다운로드를 비용/상업 사용권 보장으로 해석하지 않습니다. 새 모델을 도입하거나 추가 아바타를 개발하는 것은 현재 1순위가 아닙니다.

## 단계별 일정과 승인 요청

아래는 자료 수령·권리 확인 후의 개발 추정치이며 승인 대기·공급자의 접근 심사·기기 검증 기간을 포함하지 않습니다.

- 현재: 검색 중심 첫 화면과 안전한 공식 검색 대안·무료 규칙 상담 연결. 실제 상품 확보와 별도로 보고합니다.
- 승인 자료 수령 후 2–3 작업일: 단일 공급원 10개 이상 정규화·이미지/가격/사이즈/URL 검증·로컬 검색.
- 다음 3–5 작업일: 실제 상품 기반 조건 점수·추천 이유·비교·사이즈표 경고와 상담 연결 검증.
- 이미지 변형권 확보 후 2–3 작업일: 실제 상품 1개의 로컬 이미지 미리보기 제한 시험. 자연스러운 AI 착용 완료로 보고하지 않음.
- 아바타 모델 개선·자연스러운 AI 합성·정밀 3D 피팅은 별도 자산/권리/개인정보/비용 검토 후 재산정합니다.

지금 필요한 운영자 결정은 **실제 상품 10개 이상을 제공할 권리자/공급원과 사용권 자료**입니다. 브랜드 자료 또는 승인된 API/피드 중 하나를 정하고, 계정·키·유료 비용이 필요한 경우 그 항목과 상한을 별도로 승인해야 합니다. 아직 승인 자료가 없으므로 실제 상품 검색의 첫 완료 목표는 달성했다고 표현하지 않습니다. main 병합·Production 배포·운영 DB/Firebase/회원·구독 기록 변경과 유료 AI/결제/외부 사진 처리는 실행하지 않습니다.

## 이번 사용자 결정과 실제 구현

사용자는 승인된 자료가 없고 **공식 API·제휴 접근 검토가 필요함**을 확인했습니다. 이는 계정 생성·키 발급·가입금 결제·Production 연동 승인과 다르므로 실행하지 않았습니다.

기존 PR #4의 홈 `main` 첫 섹션을 옷 검색으로 변경했습니다. 예를 들어 `남성 검정 슬랙스 5만원 이하`에서 남성/검정/슬랙스와 KRW 50,000 예산을 해석합니다. 판매처에는 허용된 의류 종류·컬렉션·색상만 보냅니다. **예산 상한은 전달하거나 자동 필터링하지 않으며 사용자가 판매처에서 설정해야 한다고 표시**합니다. 실제 상품 추천/가격 검증 완료가 아닙니다.

같은 첫 화면에서 기존 무료 규칙 상담을 검색 조건과 연결했습니다. 사진 비율은 기본 해제된 별도 동의 후에만 조언에 사용합니다. 상품별 추천/비교는 실제 자료가 없으므로 미완료입니다. 기존 독립 스타일리스트도 Preview에서는 규칙 상담으로 동작하며, 지원하지 않는다는 오래된 Preview 배너를 실제 기능에 맞게 정정했습니다. 생성형 GPT는 호출하지 않습니다.

### 비용·접근 검토 보충

- [eBay API 호출 한도](https://developer.ebay.com/develop/api/buy/api_call_limits)는 Browse 일반 메서드 기본 5,000회/일을 설명합니다. 계정별 실제 자격·할당량·약관을 확인해야 하며 무료·무제한 API 권한이 자동으로 생기지 않습니다. [API 라이선스](https://developer.ebay.com/support/api-license-agreement)의 게시 중단 자료 삭제·표시/갱신·변형 제한도 확인해야 합니다.
- [Awin GB FAQ](https://www.awin.com/gb/faqs)는 publisher 가입 보증금/가입비 없음으로 안내하지만, 다른 지역 공식 FAQ·과거 안내에는 보증금이 있습니다. 적용 국가·역할·현재 가입 화면에서 확정 전 비용 0을 보장하지 않습니다. 광고주 요금제와 publisher 접근 조건도 구분합니다. 가입·결제는 하지 않았습니다.
- eBay 상품 이미지의 열람/표시권이나 Awin 광고 자료 사용권은 AI 합성·3D 변형권을 자동으로 포함하지 않습니다. 첫 10개 검색은 표시권부터, 실제 상품 피팅은 별도 이미지 변형권부터 승인해야 합니다.

### 현재 검증 가능한 실제 상품 수

**0개.** 상품 사진·가격·사이즈·개별 구매 URL·갱신 시각을 갖춘 실제 의류가 없으므로 이 항목의 검증 통과를 주장하지 않습니다. 공식 검색 링크는 실제 상품 레코드 수에 포함하지 않으며, LAB·테스트 SQLite·외부 문서의 예시도 집계하지 않습니다.
