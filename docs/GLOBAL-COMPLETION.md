# 글로벌 쇼핑·구독·가격 비교·알림 마무리

최종 배포 준비 검토와 추가 만료 오류 수정은 [배포 준비 검토서](GLOBAL-RELEASE-REVIEW.md)에 기록했습니다. 아래의 142개 검증은 후속 마무리 당시의 기록이며, 최종 검토에서는 회귀 검사 1개를 추가했습니다.

검증일: 2026-11-06. 기존 글로벌 확장 커밋 `9e01a6d`를 확인하고 그 위의 미완료 연결과 오류만 보완했습니다. 작업 브랜치는 `feature/global-shopping-completion`입니다. 별도 단계로 보존된 GPT 스타일리스트 커밋은 이 브랜치에 포함하지 않았습니다. 기존 Firebase 회원 식별자와 Cloudflare Pages 프로젝트·빌드 설정을 유지하며 운영 DB를 변경하지 않았습니다.

## 이번에 추가한 경로

- `POST /api/global/products`: GENERAL 이상. 승인된 기존 상품 저장소를 읽고 현재 가격·출처·확인 시각을 표시합니다. 기본값은 비활성/빈 자료 안내이며 DEMO 상품으로 대체하지 않습니다.
- `POST /api/global/comparison`: PREMIUM. 기존 `demo-tee`는 명시적 DEMO로 유지하고, 실제 상품의 정확한 판매 offer ID는 공식 저장 자료로만 비교합니다. 여러 변형을 가진 일반 상품 ID는 임의로 선택하지 않습니다.
- `POST /api/global/simulate`: PREMIUM. 본인 조건으로 모의 이벤트를 평가하고 `sent:false`인 기록만 생성합니다. 같은 기간·채널·이벤트를 동시에 여러 번 실행하거나 이력을 지워도 다시 생성되지 않습니다.
- `GET /api/global/consents`: 로그인한 본인의 동의·철회 이력. 구독 만료 후에도 조회·철회·삭제가 가능하며 철회와 삭제는 요청 한도로 차단하지 않습니다.

새 경로도 기존 인증·출처·입력 크기·요청 한도·비공개 캐시 정책을 사용합니다. 상품/이벤트/수신자/다른 회원 ID를 임의 요청으로 주입해 권한을 얻을 수 없습니다.

## 저장 상품의 승인·가격 조건

`ENABLE_LIVE_CATALOG=true`와 `GLOBAL_CATALOG_APPROVED=true`를 운영자가 승인한 경우에만 기존 D1의 공식 상품을 읽습니다. 이 설정은 실제 API 호출이나 피드 수집을 시작하지 않습니다. 기본값에서는 상품 DB도 조회하지 않습니다. 판매처 설정·공식 출처·약관·보관/갱신 조건·상품 URL·식별자·재고·배송국·확인 시각이 유효해야 합니다.

금액은 SQL 최소 단위에서 KRW/JPY 0자리, USD/EUR/GBP 2자리로 변환합니다. 배송 가능 국가라는 사실만으로 해당 국가의 비용을 안다고 간주하지 않습니다. 저장 자료의 `payload_json.costDestination`이 목적지와 일치하거나 `costsApplyToAllDestinations:true`라는 확인된 범위가 있어야 일반 배송비·세금·관세 열을 사용합니다. `costsByDestinationMinor[국가]`의 목적지별 `shipping`·`tax`·`duties` 값은 각각 우선하며 명시적 null은 미확인으로 유지합니다. 공급자 매핑은 이 근거를 실제 확인한 자료에서만 채워야 합니다.

서로 다른 통화의 판매처도 표시할 수 있지만, 승인된 실제 환율이 없으면 환산 총액과 최저가의 근거로 사용하지 않습니다. 처리 도중 가격·프로모션·보관 기간이 만료되거나 구독이 취소되면 가격 배지와 유료 결과를 다시 차단합니다.

## 추가 보완한 오류

- 찜 목록 100개에 도달해도 기존 항목은 갱신할 수 있고, 동시 신규 저장으로 100개를 넘을 수 없습니다.
- 설정 저장 중 동의를 철회해도 알림 켜짐·전화번호가 뒤늦게 복구되지 않습니다.
- 미리보기 저장도 그 순간의 유효 PREMIUM과 채널 동의를 검사합니다.
- 오래된 문안 버전·구독 만료·요청 한도 초과가 수신 철회를 막지 않습니다.
- 로그아웃 뒤 늦게 도착한 상품 조회·모의 실행 응답이 이전 회원 정보를 다시 표시하지 않습니다.

## 남은 작업과 승인

1. **코드 검토와 운영 적용:** 현재는 검토용 브랜치입니다. 운영자가 범위를 확인한 뒤 기존 프로젝트에 적용합니다. 운영 D1은 대상 확인·백업·검토 SQL 승인 후에만 변경합니다. 기존 DB에는 0001 → 0002 → 새 0003 순서를 확인하고, 새 DB용 전체 스키마와 ALTER 마이그레이션을 중복 적용하지 않습니다.
2. **실제 상품 자료:** eBay 운영 접근·Awin 퍼블리셔/광고주별 권한, 정확한 피드 매핑·이미지·보관·갱신 조건, 목적지별 비용과 실제 환율 공급원을 승인해야 합니다. 현재 읽기 경로가 실제 상품 수집 승인을 대신하지 않습니다.
3. **실제 알림:** 발송 도메인·주소/번호 소유 확인·국가별 발신 등록·동의 증빙/보관·간편 수신 거부·반송/차단·빈도·비용 상한과 제공자 연결을 승인해야 합니다. 키나 플래그만으로 이번 모의 어댑터가 실제 발송으로 바뀌지 않습니다.
4. **자동 실행과 결제:** 실제 피드 갱신·예약 Worker·발송 큐·요약 지정 시각·실제 사용량 원장과 구독 가격·환불/해지·결제 제공자는 별도 운영 단계입니다. 무료 모의 실행을 넘어서는 활성화는 진행하지 않았습니다.

현재 테스트와 모의 알림에는 외부 API·메시지 비용이 없습니다. 대중화 시 Cloudflare 요청/CPU·D1 저장/읽기/쓰기, 상품/환율 계약, 이메일·국가별 SMS·도메인/발신 등록·결제 수수료는 별도입니다. 검토한 무료 한도와 공급자 비교는 [기존 조사](GLOBAL-RESEARCH.md), 상세 운영 승인 순서는 [운영 안내](GLOBAL-OPERATIONS.md)에 있습니다. GPT 스타일리스트는 이번 단계의 구현·활성화 대상에 포함하지 않았습니다.
