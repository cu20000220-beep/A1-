# PR #4 시험 의류·2D 결과 표시 개선

## 재현 결과와 원인

사용자 보고 시점의 Preview `cc97e374`에서 실제 MediaPipe 모델 분석과 홈→연구실 흐름을 확인했습니다. 기본 조건의 카드 3개는 DOM에 생성되고 SVG 3개 모두 `naturalWidth=400`, `naturalHeight=500`으로 정상 해독됐으며 JS 오류는 없었습니다. 하지만 820×1180 화면에서 시험 버튼 직후 카드 영역 top=1230.875px, 이미지 top=1367.375px로 **화면 바깥 아래쪽**에 있었습니다. 이전 테스트는 카드 수만 확인하고 다음 버튼을 자동 스크롤해 눌렀으므로 사용자가 실제로 볼 수 있는지는 검증하지 못했습니다.

별도로 통화를 USD로 선택하면 KRW인 시험 자료가 전부 제외되고, 시험 버튼을 다시 켜도 같은 조건이 적용되어 빈 결과가 유지되는 것을 재현했습니다. 이것은 실제 상품 공급원 미연결과 다른 문제입니다. 실제 사용자의 당시 조건·Safari 내부 상태는 기록하지 않으므로 모든 기기 증상을 단일 원인으로 확정하지는 않습니다.

2D 기능은 의류 선택·개별 동의·표시 버튼을 사용자가 따로 찾아야 했고, 선택 후 다음 영역 또는 그린 결과로 화면이 이동하지 않았습니다. 결과가 화면 아래에 있어 설명만 보이는 경로가 있었습니다. 실제 AI 생성이나 3D 구현 오류는 아닙니다.

## 수정 범위

- 시험 의류를 켜면 카드 영역이 헤더 아래 실제 화면에 보이도록 즉시 이동. 카드를 크게 표시하고 SVG 크기·오류 처리를 명시.
- 조건 때문에 일부/전체 시험 자료가 제외되면 KRW·예산·사이즈·디자인 조건을 안내. 사용자가 명시적으로 `시험 조건으로 3개 모두 보기`를 눌러 기본 시험 조건을 적용할 수 있음. 기존 비율 동의는 유지하며 새 동의를 만들지 않음.
- 의류 선택 → 사진 사용 동의 영역으로 이동 → 사용자가 동의 체크하면 큰 2D 결과를 표시하고 결과로 이동. 별도 표시 버튼은 재실행 수단으로 유지. 의류 변경 시 이미지 사용 동의 재확인.
- 결과는 캡션·워터마크로 로컬 2D 도식임을 표시. 약 화면 높이 70%의 캔버스와 위치/크기 조절·2D 결과만 삭제·전체 삭제 제공.
- 피팅 진입 시 선택이 없으면 의류 목록으로 안내. 사진·선택·동의 부족을 각각 설명. 이미지 오류/10초 준비 실패 시 재시도 안내와 다시 불러오기 제공. 늦게 실패한 이전 작업은 삭제/철회 상태를 되돌리지 않음.
- 언어 KO/EN, 동일 문서 사진·조건 유지, Preview 전용 진입, API 격리와 무료 정책은 유지. 실제 판매 상품·AI 착용 합성·3D는 별도 후속 개발.

변경 파일: `assets/product-lab.js`, `assets/product-lab.css`, `assets/lab-entry.js`, `index.html`, `product-lab.html`, 기존 진입 검사 보강 및 `tests/lab-visibility-recovery-browser.cjs` 추가. 서버·회원·DB·환경 설정 변경 없음.

## 검증

- 전체 Node 테스트 232개 및 정적 빌드/공개 산출물 노출 검사.
- KO/EN × 820×1180 / 1180×820 / 390×844 홈 진입 6개: 카드 3개·모든 SVG 해독·별도 테스트 스크롤 없이 첫 의류 이미지가 뷰포트 안에 위치·큰 결과 캔버스 표시. 원본과 결과의 실제 RGB 픽셀을 하단 워터마크 영역을 제외하고 비교해 의류가 사진 픽셀을 바꾸는지 검사.
- KO/EN 오류/복구 2개: USD 조건의 빈 목록 → 명시적 시험 조건 복원 → 이미지 404의 카드별 오류/재시도 → 이미지 복구·2D 결과 → 실제 터치 입력으로 위치/크기 픽셀 변경 → 2D만 삭제.
- 기존 연구실 직접 진입 4개, 기존 분석→추천→스타일리스트→판매처 이동 4개 회귀 흐름. 실제 배포 모델·최종 Preview는 PR 본문에 기록.
- 브라우저 검사는 Linux 터치 Chromium이며 실제 iPad Safari 실행 결과가 아님. WebKit/iPad 실기기 최종 확인은 남아 있으며 그 전 PR #4 병합 금지.
