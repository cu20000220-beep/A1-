# 공식 상품 사진과 기존 로컬 2D 연결

2026-11-18, PR #4 `feature/product-fitting-lab`. 기준 커밋 `9419048`.

## 운영자 지시와 실제 자료

운영자는 2026-11-18 상품 사진 복제와 가상 피팅 적용을 명시적으로 승인했다. 이번 작업은 이를 `operator-attestation`으로 기록하며 이용 권한이 없다고 가정하지 않는다. 판매처와 별도 계약을 체결하거나 판매처가 직접 확인한 것처럼 기록하지도 않는다. 개인 사진 사용 동의는 상품 이미지 이용 승인과 별개다.

무신사·29CM 공식 상품 페이지가 직접 연결하는 대표 이미지 **9개**의 URL을 확인했다. 상품 ID·옵션과 출처 관계를 [원본 조사 기록](validation/product-images/official-image-sources.json)에 남겼다. 유니클로 한 항목은 요청 색상과 공개 본문이 일치하는지 미확인이라 다른 색상 사진을 대신 붙이지 않았다. 기존 가격·사이즈·재고·공급원 승인 피드는 변경하지 않았다.

`assets/product-images.json`은 승인 근거, 이미지 원본 URL, 상품 URL과 ID, 참조/로컬 복제 여부, 확인 시각을 분리한다. 현재 9개 모두 `remote-reference`이고 바이트·해시·크기는 `null`이다. 이미지 검토 기록의 유효 기간은 현재 발행 후 7일로 제한한다. 만료된 자료는 재검토하기 전 피팅에 쓰지 않는다. 원본 파일을 실제로 확보하면 `local-copy`와 파일 해시·크기·치수를 기록할 수 있으며 빌드가 로컬 바이트 해시를 확인한다.

## 사용자가 실행하는 흐름

공식 상품 후보 카드 사진 로드 → **내 사진에 이 상품 2D 배치** → 사진이 없으면 기존 분석 화면 → 사진 분석 → 선택한 상품 이미지 준비 → **내 사진 사용 동의** → 겹쳐보기 → 위치·크기·회전·투명도 조절/전후 비교 → **판매처에서 상품 확인**.

- 메인·분석 후 추천·무료 규칙 상담의 공통 카드를 연결했다. 상담 페이지에는 인물 사진이 없으므로 공개 상품 ID만 fragment로 전달한 뒤 도착 즉시 제거·재검증한다.
- 동일 페이지에서 기존 얼굴 제외 canvas를 재사용하므로 분석 사진을 다시 고르지 않는다. 상품을 먼저 선택한 경우 사진 교체/분석 후에도 공개 선택은 유지하되 개인 사진 동의는 기본 미동의다.
- 실제 상품 사진을 기존 로컬 2D 엔진에 연결한다. 의류 종류·이미지 비율에 맞는 참고 초기 배치를 적용하고 수동 보정을 유지한다. 자연스러운 AI 착용 합성·실제 의류 3D 메시·정확한 사이즈 판정은 아니다. 사진에 모델·배경이 있으면 같이 겹칠 수 있다.
- 현재 재고 `unknown`을 `in_stock`으로 바꾸지 않는다. 미확인 가격을 만들지 않으며 판매처 링크는 정확한 해당 상품 상세 페이지다. 이미지 미리보기 허용과 구매 재고 확인을 구분한다.
- 카드 이미지 표시와 canvas 가공은 서로 다른 브라우저 정책이다. 일반 이미지는 no-referrer로 표시하고 2D용 이미지는 anonymous CORS가 성공한 경우에만 canvas로 읽는다. 실패하면 이유와 기기에서 의류 사진 선택 대안을 표시하며 프록시 우회나 외부 합성으로 전환하지 않는다.
- 이미지가 로드되지 않으면 버튼을 활성화하지 않는다. 이미지 자료가 없거나 잘못돼도 실제 상품 사실·공식 링크는 계속 표시한다.

## 환경 네트워크에서 확인한 제한

현재 Codex 환경의 강제 허용 호스트 목록에 `image.msscdn.net`과 `img.29cm.co.kr`가 없어 각각 정상 이미지 요청이 관리형 프록시 **CONNECT 403**으로 거부됐다. 판매처의 저작권 거절·상품 접근 권한 거부로 확인된 것이 아니다. 별도 웹 열람 도구의 원본 이미지 열기도 성공하지 않았다. 반복 요청·보안 우회·다른 서버를 통한 다운로드는 하지 않았다.

따라서 **파일 복제 0개**, 실제 판매처 사진 픽셀·CORS·착용 결과는 아직 미검증이다. 사이트 방문자의 브라우저는 위 공식 원본 URL을 정상적으로 읽도록 구현했으며, 그 브라우저에서 표시/가공이 허용되는지는 실제 응답에 따라 처리한다. 해당 두 호스트를 Codex 환경 설정의 허용 목록에 추가하면 원본 다운로드·해시·색상/구성 확인과 로컬 복제 검증을 이어갈 수 있다. 현재 제공된 도구에는 이 설정을 직접 바꾸는 기능이 없다. Cloudflare 운영 설정과는 다른 설정이다.

## 검증과 보호

- 단위·권한·개인정보·비용 통제 검사 **355개 통과**.
- `tests/product-images-flow-browser.cjs` **8개 통과**: KO820/EN390 선택·같은 사진 2D·실제 픽셀 변화·조절5개·비교·철회/삭제, 상품 먼저 선택/공개 ID 제거, CORS 거부, 이미지404, 자료 누락, 지연 삭제, 구매 URL 변조/합성 클릭 거부.
- [브라우저 검사 기록](validation/product-images/private-fixture-browser.json)은 명시적인 비공개 raster fixture를 정확한 공식 이미지 URL에 응답한 검사다. 그 사진은 다른 의류이며 실제 판매처 사진 피팅의 증거로 발표하지 않는다. 실제 iPad Safari·실제 CDN 다운로드를 통과했다고 표현하지 않는다.
- 기존 메타데이터 전용 검색·상담 8개, 승인 feed fixture 추천·비교·2D 8개도 통과했다. 메타데이터 전용 검사는 빈 이미지 manifest를 명시하고 새 사진 경로는 별도 검사한다.
- 빌드116파일·공개 노출 검사117파일 통과. CSP는 검증된 두 CDN의 img-src만 확장한다. 외부 script/connect/API/사진 업로드 권한을 추가하지 않는다.

모든 사용자 무료 정책과 Preview `/api/*`503 격리를 유지한다. 서버 구독 권한 검사를 바꾸지 않는다. 사용자 사진·분석값은 외부 서버·URL·로그·영구 저장소에 전송하지 않는다. main/Production/운영 Firebase·DB·회원·구독 기록·결제·유료 AI는 변경/활성화하지 않는다. PR #4는 실제 iPad 확인 전 Draft·미병합을 유지한다.
