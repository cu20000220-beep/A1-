# 비교·추천 플랫폼 변경 검증 (2026-11-10)

PR #4 `feature/product-fitting-lab`에서 기존 검색·사진 분석·무료 상담을 보존하고 공급원 정규화와 동일 상품 판매처 비교를 확장했습니다. 실제 공개 상품과 승인 공급원은 각각 **0개**입니다. 아래 합성 자료 검사는 실제 상품 확보·가격 확인·라이브 연동 완료 증거가 아닙니다.

## 구현된 범위

- 판매자/브랜드 파일, 이미 적법하게 확보한 공식 API 응답/제휴 피드의 오프라인 어댑터. 명시적 매핑만 허용하며 후보 준비는 등록/승인이 아닙니다.
- 기존 비공개 승인 manifest·원본/정규화 해시·도메인·유효 기간 검증을 유지합니다. 실제 자료·권리가 없으면 공개 카탈로그를 채우지 않습니다.
- GTIN 또는 제조사 MPN과 브랜드·색상·단일 사이즈·사이즈 체계·상품 상태를 이용한 보수적인 동일 변형 비교. 판매처와 정확한 구매 URL이 같은 중복만 최신 자료로 정리합니다.
- 상품 가격·배송비·세금·관세·배송국·재고·확인 시각·구매 조건 표시. 미확인 비용/조건·품절·다른 통화·24시간 지난 가격은 합계 순위에서 제외합니다. 비교 가능한 서로 다른 판매처 두 곳 이상일 때만 해당 집합의 예상 최소 합계를 표시합니다.
- 광고 영역과 일반 추천을 분리하고 제휴 링크는 고지합니다. 제휴 피드와 알려진 추적 링크는 명시적 제휴 승인/고지가 없으면 공개 검증에서 거부합니다. 광고비·수수료 때문에 일반 추천 점수를 올리지 않습니다.
- 무료 규칙 상담은 같은 검증 스냅샷과 비교 규칙을 재사용합니다. 사진 비율 사용 동의와 직접 입력 사이즈표 차이 비교를 유지하며, 사진에서 신체 치수/정확한 사이즈를 만들어내지 않습니다.

## 출시 판단과 승인 경계

개발용 Preview 검토는 가능하지만 **실제 상품 비교 서비스 출시는 NO-GO**입니다. 한 공급원의 적법한 접근·정보/이미지 표시권·최신 실제 상품 10개 이상을 확보해야 합니다. 다중 판매처 비교에는 같은 변형을 판매하는 두 판매처의 실제 자료도 필요합니다. [공급원별 조건과 최소 운영자 승인](BUSINESS-MODEL-AND-SOURCES.md), [양식·권리·갱신/철회 절차](SELLER-PRODUCT-PERMISSION.md), [어댑터 실행 계약](SOURCE-ADAPTERS.md)을 참조하세요.

외부 API 자동 호출·Cron·계정/키 발급·결제·유료 AI·외부 사진 처리는 활성화하지 않았습니다. 기존 시험 의류·로컬 2D/3D는 실제 상품 피팅과 구분하고, 실제 이미지 변형/AI 합성/3D 착용은 별도 권리·자료·비용 검토 후 진행합니다. Preview API 격리, 기존 운영 환경, 회원/구독/Firebase 데이터는 유지합니다. main 병합·Production 배포·PR #4 병합은 실행하지 않습니다.
