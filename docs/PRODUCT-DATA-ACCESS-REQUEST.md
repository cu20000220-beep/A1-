# 실제 상품·개별 구매 링크 연결에 필요한 자료

A1은 판매/결제를 하지 않고 상품을 비교·추천해 해당 상품의 판매처 페이지로 연결합니다. **검색 페이지로 보내는 대안과 개별 상품 추천·구매 연결은 구분합니다.** 현재 공개 카탈로그는 0개이며 실제 상품 10개 확보는 미완료입니다.

## 확인된 공급원 경로

- **무신사:** [공식 큐레이터](https://www.musinsa.com/curator/intro/pro)는 승인형 상품 링크 공유 경로입니다. 공개 문서만으로 상품 카탈로그 피드·비교 사이트 재게시·피팅 이미지 변형권을 확보한 것으로 볼 수 없습니다. [공식 제휴/이미지 문의](https://www.musinsa.com/app/company/partner)에 해당 사용 범위와 읽기 전용 자료를 문의할 수 있습니다. 판매자용 주문/상품 API를 전체 쇼핑 카탈로그 API로 사용하지 않습니다.
- **유니클로 한국:** [공식 이용약관](https://faq-kr.uniqlo.com/pkb_Home_UQ_KR?id=kA0Ie000000TO0f) 제21·22조는 권한 없는 정보 복제와 사진 등의 영리적 사용에 관한 제한을 명시합니다. 한국 쇼핑몰의 공개 상품 API/피드 접근권은 미확인입니다. [공식 문의](https://faq-kr.uniqlo.com/contactus)를 통해 데이터/이미지 제휴 담당 부서와 범위를 확인해야 합니다. 해외 프로그램 승인을 한국 자료 사용권으로 간주하지 않습니다.
- **가장 먼저 검토할 대체 피드:** [Awin YesStyle Global 63156](https://ui.awin.com/merchant-profile/63156)은 의류·업데이트 상품 피드를 안내합니다. 브랜드의 [공식 배송 안내](https://www.yesstyle.com/en/help/section.html/hsi.732)에 한국이 있으나 개별 의류의 배송과 A1의 광고주/피드 승인은 별도입니다. Publisher·광고주 승인 후 [공식 피드](https://help.awin.com/apidocs/retail-publisher-productapidocumentation-1)를 사용할 수 있는지 확인합니다. 제공된 이미지의 표시권과 피팅/변형권은 자동으로 같지 않습니다.

일반 링크와 상품 정보·이미지를 복제해 A1 화면에서 표시하거나 피팅에 사용하는 행위는 같은 범위가 아닙니다. 승인되지 않은 크롤링, 로그인/접근 제한 우회, 비공식 유료 스크레이퍼, 가짜 상품으로 빈 목록을 채우는 방식을 사용하지 않습니다.

## 보내기 전 검토할 문의 초안 (아직 전송하지 않음)

> A1 FASHION은 무료 베타 의류 비교·추천 플랫폼입니다. 상품 주문·결제는 귀사 판매처에서 진행하며 A1은 소비자의 선택 상품을 해당 상품 상세/구매 페이지로 직접 연결하려 합니다.
>
> 귀사가 허용하는 읽기 전용 상품 API, 제휴 피드 또는 제공 파일로 먼저 의류 10개를 검증하고 싶습니다. 상품 ID·이름·브랜드·가격/통화·색상·사이즈 옵션/사이즈표·재고·한국 배송 가능 여부/배송비·공식 개별 구매 URL·이미지·갱신 시각을 제공받을 수 있는지 문의합니다.
>
> A1 내 상품 정보/이미지 표시, 출처·브랜드 표기, 조건별 추천·비교, 개별 링크 연결, 갱신/캐시/철회·삭제 및 제휴 고지의 허용 조건을 알려주세요. 별도로, 상품 이미지를 사용자의 브라우저 안에서 2D 참고 배치하는 사용과 향후 AI/3D 변형·합성 사용을 각각 허용하는지도 확인 부탁드립니다. 단순 이미지 표시 허가를 변형 허가로 해석하지 않겠습니다.
>
> 고객 사진과 신체 수치는 귀사 또는 외부 AI에 전송하지 않습니다. 외부 비용이 필요한 계약/접근은 사전 견적과 승인 없이 활성화하지 않습니다.

## 첫 실제 상품 10개의 성공 기준

한 공급원의 승인이 있으면 실제 의류 10개부터 시작합니다. 같은 상품을 판매하는 두 판매처를 미리 확보해야만 첫 상품을 표시하도록 막지는 않습니다. 각 상품의 이미지·가격/통화·사이즈·판매처·확인 시각·유효기간·**개별 상품 URL**을 검증합니다. 검색/홈 주소를 개별 구매 URL로 등록하지 않습니다.

등록 상품에서 조건별 추천 → 상품 후보/확인 가능한 판매처 비교 → 허가 및 브라우저 CORS 조건을 충족하는 이미지의 로컬 미리보기 → **동일 상품의 판매처 페이지로 한 번에 이동**을 확인합니다. 결제 세션·주문·결제 대행을 만들지 않습니다. 이미지 CORS가 허용되지 않으면 프록시로 우회하지 않고 안내와 기기 사진 대안을 제공합니다.

동일 상품 가격 비교에는 같은 변형의 두 판매처 자료가 필요하지만, 단일 공급원 상품 추천·개별 구매 연결은 별도로 검증할 수 있습니다. 실제 상품별 3D 메시/패턴이 없으면 정밀 3D 착용을 제공한다고 표시하지 않습니다.

## 운영자가 승인할 최소 사항

첫 공급원 선택과 위 데이터/이미지 사용 범위 문의·신청, 운영자 명의의 계정/담당자 정보 제공, 승인된 자료·표시/피팅 범위·갱신/삭제 조건 확인이 필요합니다. Awin의 공개 영국 FAQ는 Publisher 가입/예치금 무료로 안내하지만 한국 운영자에게 적용되는 가입 화면·계약 조건은 최종 확인해야 합니다. 비용·새 계정 신청·외부 사진 처리·유료 API는 이번 작업에서 실행하지 않습니다. 비밀키는 클라이언트나 공개 저장소에 넣지 않습니다.
