# 7일 체험 / 구독 정책 준비

사용자가 확정한 정책은 **체험 시작 후 7일(168시간), 이후에는 유료 구독 필요**입니다. 월 구독료와 혜택은 아직 미정입니다. 체험 종료는 이용권 만료를 뜻하며 자동 결제를 실행하지 않습니다.

`membership-policy.mjs`는 서버의 인증된 회원 기록과 서버 시간을 받아 접근 허용 여부를 계산하는 순수 정책 코드입니다. 현재 정적 사이트나 Cloudflare에 배포된 회원/결제 시스템이 아닙니다. 브라우저에서는 가져올 수 없고 `scripts/build-site.cjs`의 정적 출력에도 포함되지 않습니다.

실제 적용 전에 필요한 연결:

1. 회원 인증을 검증한 뒤 서버에서 확인한 userId로만 회원 기록 조회
2. 최초 체험 시작 시 서버 UTC 시간을 저장. userId 고유 제약과 `trialStartedAt IS NULL` 조건부 갱신으로 한 번만 기록하고 재시도/만료/기기 변경 시 보존
3. 유효한 체험 또는 서버가 검증한 활성 구독·결제 기간이 있어야 보호된 서비스에 접근 허용
4. 결제 제공자의 검증된 결과로만 구독 상태 갱신. 브라우저의 paid 플래그·클라이언트 시간·요청 본문을 회원 기록으로 신뢰하지 않음
5. 가격·청구 주기·갱신·해지·환불 조건에 동의한 뒤에만 결제 요청. 체험 만료 자체로 청구하지 않음

코드의 7일 경계, 반복 체험 시작, 잘못된 시간/회원, 만료·미결제, 입력 비변경을 `node tests/membership-policy.cjs`로 검증합니다. 데이터베이스의 동시성 보호와 실제 인증/결제 검증은 이 순수 함수 테스트만으로 확인한 것으로 설명하지 않습니다.

현재 공개 미리보기의 실행 파일은 정적 파일이며 이를 브라우저에서 숨기는 것만으로 안전한 유료회원 제한이 되지 않습니다. 실제 유료 기능에는 서버가 검증하는 이용권 경계가 필요합니다. Cloudflare Pages 주소를 만드는 작업과 회원·구독 시스템을 연결하는 작업은 별개입니다.
