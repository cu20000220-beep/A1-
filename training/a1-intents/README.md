# A1 소형 패션 질문 분류 모델 — 개발용 학습 데이터

이 폴더는 A1 자체 엔진의 **실제 오프라인 학습/재학습 경로**를 시험하는 작은 개발용 말뭉치입니다. `train.jsonl` 144개와 `eval.jsonl` 36개는 이 저장소를 위해 AI 어시스턴트가 생성한 한국어·영어 합성 예제입니다. 실제 고객 대화·사진·웹 수집 자료·전문가 검수 라벨이 아닙니다. 사용자 사진·대화를 이 폴더에 자동 저장하거나 학습에 사용하는 코드가 없습니다.

## 학습하는 것과 범위

9개 질문 주제(outfit, fit, color, occasion, budget, care, compare, discount, out_of_scope)를 문자 n-gram/단어 특징의 **다항 나이브 베이즈**로 분류합니다. 클래스별 관측 빈도로 가중치를 실제 계산하며, 라벨을 바꾸어 재학습하면 가중치와 예측이 달라집니다. 공유 `server/a1-intents.mjs`가 학습·추론의 정규화와 특징 추출을 함께 제공합니다.

이 모델은 문장을 생성하는 대형 언어 모델, 사진 분석 모델, 상품·체형별 착용 적합성/사이즈 예측 모델이 아닙니다. 상품·가격·재고·할인은 기존 검증 상품 저장소가 근거이며 분류 모델이 생성하지 않습니다. 불충분한 특징이나 작은 점수 차이는 `topic:null`로 기권합니다. 내부 margin은 보정된 확률이나 정확도가 아니며 사용자에게 ‘맞을 확률’로 보여주면 안 됩니다.

## 실제 개발용 평가

학습/평가 예제는 정규화 후 중복이 없도록 검사합니다. 동일 합성 출처의 작은 예제 평가이므로 실제 사용자·운영 품질을 대표하는 독립 검증이 아닙니다. 이 예제 점수를 서비스 정확도로 광고하거나 운영 GO 근거로 사용하지 않습니다.

## 재현과 운영 경계

`node scripts/train-a1-intents.mjs`는 로컬 JSONL과 manifest만 읽어 `server/models/a1-intent-v1.json` 및 이 폴더의 `evaluation.json`을 만듭니다. CPU만 사용하고 네트워크·DB·유료 API·자동 배포를 사용하지 않습니다. `--check`는 체크인된 결과가 같은 입력의 결정적인 재학습 결과와 일치하는지만 검사합니다. 날짜를 바꿔 결과를 꾸미지 않습니다.

다른 명시적 로컬 경로는 `--train`, `--eval`, `--manifest`, `--out`, `--report`로 지정할 수 있습니다. 미래 실제 자료는 공개 저장소에 넣지 않습니다. 실제 말뭉치는 외부 보관하고 권리·개인정보 검토와 학습 목적 승인이 확인된 manifest가 필요합니다. 실제 피드백은 별도 학습 동의가 검증되어야 하며 `consented-feedback` 출처는 `consentVerified:true` 없이 거부됩니다. 회원가입·구독·외부 AI 동의는 자체 학습 동의를 대신하지 않습니다.

manifest의 현재 승인 값은 **합성 예제를 로컬 개발에 사용한다는 범위**입니다. 독립 전문가 검증·실제 고객 동의·운영 승인으로 해석하지 않습니다. `approvedForProduction:false` 및 모델의 `productionValidated:false`를 유지합니다. 미래 운영 데이터로 재학습하더라도 별도 성능·편향·개인정보 평가와 배포 승인이 필요합니다.

학습 프로그램은 이메일·긴 전화번호형 문자열·URL·이미지/base64·API 키 등 명백한 잘못된 입력을 거부하며 거부한 원문을 오류에 출력하지 않습니다. 이러한 패턴 검사가 모든 개인정보나 권리 문제를 판별하는 것은 아닙니다. 원본 사진이나 전체 인체 기준점은 학습 입력으로 받지 않습니다. 모델·학습 자료·평가 보고서는 정적 `dist/` 자산으로 복사하지 않습니다.
