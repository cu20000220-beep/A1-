# Price monitor: manual dry-run only

Cloudflare Pages Functions handle requests; they do not receive Workers Cron Triggers. A future scheduled monitor would be a separate Worker using an operator-approved D1 binding and only official, approved feed adapters. This repository keeps its handler disabled: there is no `scheduled()` export, no cron entry, no public execution endpoint, no provider credentials, and no deployment command or automatic D1 migration.

`runMonitor()` is a dependency-injected manual simulation. The caller must already authenticate the operator. It accepts at most 20 named, approved official sources, loads stored fixture snapshots, evaluates candidates, rechecks each member's current PREMIUM entitlement and separate channel consent, atomically claims idempotency keys, and records dry-run results. Search-link-only retailers cannot be monitored. Notification candidates allowlist product, price, event and provenance fields; they discard source-row photos, body-analysis data and unrelated contacts. Notification adapters contain no SMTP/SMS/network delivery implementation, so flags or keys alone cannot activate messages.

Start with manual, low-frequency runs on stored approved data. Before considering a Cron Trigger, confirm the account's current free request/CPU/D1 read-write limits, source API rate limits, official feed retention policy, daily/weekly digest scheduling, quiet hours/time zones, and hard delivery volume/cost caps. Source terms determine cleanup; no universal retention period is assumed. `cleanupPlan` is a report, not a deletion job.

Real delivery requires a separately reviewed implementation and operator approval: verified sending domain, provider terms/free quota, verified ownership of recipients, opt-out link or country-appropriate SMS procedure, suppression/bounce processing, monthly volume/budget caps, and revocation checks at dispatch. The simulation repository must provide trusted current contexts and atomically enforce idempotency; this scaffold does not install a production D1 queue, refresh feeds, increment billing counters or deliver end-of-day/week digests. Country-prefix and E.164 checks validate basic formatting only and never verify phone ownership or message eligibility. Marketing consent must remain independent of registration and subscription. Body photos, landmarks, and analysis ratios never belong in a feed or alert payload.
